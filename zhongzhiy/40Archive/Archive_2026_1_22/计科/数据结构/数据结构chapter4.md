## 2. 树（Tree）

### 2.1 递归定义（逻辑结构）

- 树是 n(n≥0) 个元素的集合：  
    **有且仅有一个根 Root（无前驱）**；  
    其余结点**有且仅有一个前驱（双亲）**，可以有 0 个或多个后继（孩子）。
    
- 非空树 T = {root} ∪ T1 ∪ T2 ∪ … ∪ Tm，Ti 是互不相交的子树。
    
- **树的本质**：层次化 + 分支关系。
    

### 2.2 树的术语（必须会背/会用）

- 结点、根
    
- 结点的度 d(v)：孩子数
    
- 叶子：度=0
    
- 分支结点：度≠0
    
- 内部结点：除根与叶子外的分支结点
    
- 树的度：结点度的最大值（k 叉树）
    
- 孩子/双亲/兄弟/堂兄弟
    
- 祖先/子孙
    
- 层次 L(v)：根为第1层
    
- 深度/高度：最大层次
    
- 有序树 vs 无序树
    
- 路径与路径长度：路径上分支数 = 结点数−1。
    

### 2.3 树的性质

1. **结点总数 n = 所有结点度之和 + 1**。
    
2. k 叉树第 i 层最多结点数： (k^{i-1})。
    
3. 深度为 h 的 k 叉树最多结点：  
    $$  
    1+k+k^2+\cdots+k^{h-1}=\frac{k^h-1}{k-1}  
    $$ 
    
4. 有 n 个结点的 k 叉树**最小深度**：  
    $$ 
    \lceil \log_k (n(k-1)+1)\rceil  
    $$ 
    
5. 最大深度？（极端链状）= n。
    

### 2.4 树的基本操作（ADT 级别）

- Create / Root / Parent / Left_Child / Right_Sibling
    
- Traverse（遍历，最重要）
    
- Depth
    
- Insert / Delete 等。

## 3. 二叉树（Binary Tree）

### 3.1 定义

- 二叉树是 n(n≥0) 个结点的集合：  
    要么空；要么由根 + **左子树、右子树（互不相交，且仍是二叉树）组成。
    

### 3.2 二叉树性质（高频）

1. 第 i 层最多 (2^{i-1}) 个结点。
    
2. 深度 k 最多 (2^k-1) 个结点。
    
3. 任意二叉树：叶子数 (n_0 = n_2 + 1)（n2：度为2的结点数）。
    
4. **满二叉树**：深度 k 且结点数 = (2^k-1)。
    
5. **完全二叉树**：除最后一层外全满，最后一层从左到右连续。
    
6. 完全二叉树深度：  
    [  
    \lceil \log_2(n+1)\rceil = \lfloor \log_2 n\rfloor +1  
    ]  
    
7. 完全二叉树编号性质（顺序存储与堆用）：
    
    - i=1 为根
        
    - parent(i)=⌊i/2⌋
        
    - left(i)=2i（若≤n）
        
    - right(i)=2i+1（若≤n）
        
    - 兄弟：i奇且≠1→左兄弟 i−1；i偶且≠n→右兄弟 i+1。

## 4. 二叉树的存储结构

### 4.1 顺序存储

- 按**完全二叉树编号**把结点放数组位置 i。
    
- 关系直接由下标反映（parent/child公式）。
    
- **优点**：找双亲孩子 O(1)。
    
- **缺点**：对一般二叉树空位多、空间浪费严重（课件还给链状极端例子）。
    

### 4.2 链式存储

1. **二叉链表**：Data + Left + Right。
    
2. **三叉链表**：Data + Parent + Left + Right（便于找双亲）。
    

- 特点：空间只与结点数有关；插删不移动；但空指针多（n+1 个空指针）。

## 6. 二叉树遍历（必考）

### 6.1 两类遍历思想

- **深度优先 DFS**：递归先走到叶子再回溯。
    
- **广度优先 BFS（层序）**：按层从上到下、从左到右。
    

### 6.2 深度优先三种

设树 = V(根) L(左) R(右)，默认“先左后右”：

1. **先序 Preorder：VLR**
    
    - 访问根 → 左子树 → 右子树。
        
2. **中序 Inorder：LVR**
    
    - 左子树 → 根 → 右子树。
        
3. **后序 Postorder：LRV**
    
    - 左子树 → 右子树 → 根。
        

### 6.3 层序遍历

- 用**队列**：根入队；循环出队访问，并把其左右孩子入队。O(n)。
    

### 6.4 遍历应用

- 输出叶子：遍历过程中判断左右孩子都空即叶子。
    
- 求高度：Height = max(HL,HR)+1（递归）。
    
- 表达式树：
    
    - 中序→中缀
        
    - 先序→前缀
        
    - 后序→后缀。

## 7. 二叉树创建（两种核心方法）

1. **直接按结构生成**：逐点 new 结点并连 Left/Right。
    
2. **由遍历序列创建**
    
    - **前序 + 中序** ⇒ 唯一确定二叉树。  
        思路：前序首元素为根；在中序中划分左右子树，再递归。
        
    - **完全前序序列（含空指针标记 ^）** ⇒ 唯一确定二叉树。  
        规则：读到 ^ 建空树；否则建根并递归建左、右。
        
    - 课件给了递归建树代码框架（getchar读入）。
        
3. **层序创建**：用层序输入序列构建（了解+会跟着做）。

## 8. 线索二叉树（Threaded Binary Tree）

### 8.1 为什么要线索化？

- 遍历得到的结点线性序列每次重复算没意义，想把**前驱/后继关系（线索）**保存下来。
    

### 8.2 线索存储方式

1. **顺序存储线索**：把遍历序列再存一份（使用方便但**冗余大**）。
    
2. **链式存储线索**：在二叉树上加 Pred/Next 指针（线索完全但增空间）。
    
3. **利用空指针存部分线索（最常讲）**：
    
    - 左空 → 存前驱线索（ltag=1）
        
    - 右空 → 存后继线索（rtag=1）
        
    - ltag/rtag=0 表示孩子指针。
        
    - 省空间但线索不完全，要结合标志判断。
        

### 8.3 线索的建立与使用

- 建立（线索化）：遍历时维护 pre 与 current，按空指针条件挂线索。
    
- 使用（以中序线索为例）：
    
    - 找后继：若 rtag=1 直接到 rightChild；否则去右子树最左结点。
        
    - 找前驱：若 ltag=1 直接到 leftChild；否则去左子树最右结点。

## 9. 树的应用与特殊二叉树（后半章）

### 9.1 最优二叉树 / 哈夫曼树

- 扩充二叉树：把空指针补外结点；外结点数 = 内结点数 + 1；无度为1结点。
    
- 权、加权路径长度 WPL：  
    [  
    WPL=\sum w_k l_k  
    ]  
    （外结点权 × 路径长度），WPL 最小的树为哈夫曼树。
    
- 结点数：若有 n 个叶子，则哈夫曼树共有 (2n-1) 结点。
    
- **构造算法（贪心）**：  
    初始森林 n 棵单结点树；每次选权最小两棵合并为新树（权=和），重复 n−1 次。  
    不唯一原因：权值相同/左右可互换。
    
- 哈夫曼编码：前缀码；左0右1；高频字符离根近→编码短。

## 10. 树、森林与二叉树的关系（转换）

### 10.1 树 ↔ 二叉树（左孩子右兄弟法）

- **树转二叉树**：  
    兄弟用右指针串起来；双亲只保留与**第一个孩子**的左指针连接。
    
- **二叉树转树**：  
    若某结点为左孩子，则其右链上的结点全是它的兄弟，依次接回双亲。
    

### 10.2 森林 ↔ 二叉树

- **森林转二叉树**：  
    第一棵树根作为二叉树根；  
    T1 的子树森林→左子树；其余树构成的森林→右子树（递归）。
    
- **二叉树转森林**：  
    先按二叉树→树还原，再把根的右链依次断开，得到多棵树。
