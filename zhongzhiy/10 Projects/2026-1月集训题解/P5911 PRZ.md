# P5911 PRZ
## 题意

> [!abstract] 题目关键信息
> $n$个人过桥, 每个人过桥用时$t$和体重$w$不同, 桥的承重最大为$W$, 把人分成不同批次过桥, 只要当前一个批次过桥后, 下一批次的人才能过桥, 求过桥的最短时间
对于 100% 的数据，$100≤W≤400，1≤n≤16，1≤t≤50，10≤w≤100$。
##  题解
定义状态: `dp[i]`为状态`i`需要的最短时间
状态转移: 状态`i`可以由它的子集转移而来, 考虑一个子集`T`作为状态`i`最后通过的一组, 那么`dp[i] = min(dp[i], tmax(T) + dp[i/T])`

#define de(x) cout << (#x) << "=" << (x) << endl;

#else

#endif
#define endl '\n'
#define fi(n) for(int i = 1;i <= n; ++i)
#define fi0(n) for(int i = 0;i < n; ++i)
#define fj(n) for(int j = 1;j <= n; ++j)
#define all(x) (x).begin(), (x).end()
#define hello ios::sync_with_stdio(0); cin.tie(0);cout.tie(0);
#define world return 0;
#define int long long
typedef vector<int> vi;
#define F first
#define S second
typedef pair<int, int> pii;
typedef vector<vector<int>> vvi;
typedef long long ll;


signed main() {
    hello;
    int W, n; cin >> W >> n;
    int S = (1 << n) - 1;
    //每个集合的耗时和重量
    vi ts(S + 1), ws(S + 1);
    for(int j = 0, t, w; j < n; ++j) {
        cin >> t >> w;
        for(int i = 0;i <= S; ++i) {
            if(i& (1 << j)) {
                //耗时是集合中最慢的人的时间
                ts[i] = max(ts[i], t);
                //加上每个重量
                ws[i] += w;
            }
        }
    }

    vi dp(S+1, INT_MAX);
    for(int i = 0;i <= S; ++i) {
        if(ws[i] <= W) dp[i] = ts[i];
        //枚举每个子集
        for(int j = i; j; j = i & (j - 1)) {
            //如果子集合法就更新
            //子集j, 子集的补集为j ^ i
            //不用管子集j这一波人怎么过的桥, 是分开还是一起, 因为之前已经算过了
            if(ws[i ^ j] <= W) dp[i] = min(dp[i], dp[j] + ts[i^j]);
        }
    }
    cout << dp[S] << endl;

    world;
}
