## 2. 一般线性表（Linear List）定义与术语

### 2.1 逻辑定义

- **线性表**：n(n≥0)个**相同特性**数据元素的有限序列  
    ( L=(a_1,a_2,\dots,a_n) )。
    
- **线性关系**：
    
    - 除第一个元素外，每个元素**有且仅有一个直接前驱**；
        
    - 除最后一个元素外，每个元素**有且仅有一个直接后继**。
        
- 形式化表示：  
    Linear_List = (D, R)
    
    - D = { a_i | a_i ∈ D0, i=1..n }
        
    - R = { <a_i, a_{i+1}> | i=1..n-1 }  
        D0 是数据对象（同类元素集合）。
        
- **特征本质**：元素间关系由它们在集合中的**相对位置**决定。
    

### 2.2 常用术语

- 直接前驱、直接后继
    
- 空表
    
- 表长（长度）
    
- 逻辑位置 i（从1开始计）等。

## 3. 线性表ADT定义（操作集合）

对线性表常用操作（必须掌握）：

- MakeEmpty：初始化空表
    
- FindKth(L, i)：取第 i 个元素值
    
- Find(L, X)：按值找元素 X 首次出现的位置
    
- Insert(L, X, i)：在第 i 个位置**之前**插入 X
    
- Delete(L, i)：删除第 i 个元素
    
- Length(L)：求表长
    
- IsEmpty(L)：判空
    
- 查前驱/后继
    
- PrintList(L)：输出表元素
    
- CreateList(endTag)：输入创建表

## 4. 顺序存储实现（数组实现）

### 4.1 存储方式与地址计算

- **连续内存单元**依次存放元素（逻辑相邻=物理相邻）。
    
- 元素大小 l = sizeof(ElementType)，最大容量 MAXSIZE ≥ n。
    
- 地址公式：
    
    - Base = LOC(a1)
        
    - LOC(a_i) = Base + (i−1)·l
        
- **随机存取特性**：知道 Base 就能 O(1) 定位任意元素。
    

### 4.2 结构体表示

- 静态顺序表：数组 + Last
    
- 动态顺序表：指针 Data + MAXSIZE + Last
    
- 习惯：用指针类型 List 表示顺序表，便于传参；
    
    - 某元素：L->Data[i]
        
    - 长度：L->Last + 1。
        

### 4.3 典型操作与复杂度

1. **初始化 MakeEmpty**
    
    - alloc 空间，Last = −1
        
    - 时间 O(1)。
        
2. **按值查找 Find(X)**（顺序查找）
    
    - 从 0 到 Last 扫描
        
    - 平均比较次数 (n+1)/2
        
    - 时间 O(n)。
        
3. **插入 Insert(X, i)**
    
    - 条件：表未满；1 ≤ i ≤ Last+2
        
    - 将 i 及之后元素整体后移一位，再放 X
        
    - 平均移动 n/2
        
    - 时间 O(n)。
        
4. **删除 Delete(i)**
    
    - 条件：1 ≤ i ≤ Last+1
        
    - 将 i+1 及之后元素整体前移一位
        
    - 平均移动 (n−1)/2
        
    - 时间 O(n)。

## 5. 链式存储实现（链表）

### 5.1 存储方式

- 用**任意/非连续**存储单元存放元素；
    
- 每个元素一个**结点**：
    
    - 数据域 Data
        
    - 指针域（存前驱/后继/二者）表示线性关系。
        

### 5.2 特点（对比顺序表）

- 逻辑关系由指针/地址表示
    
- 逻辑相邻 ≠ 物理相邻
    
- **顺序存取**，不能随机访问：访问不同元素时间不同。
    

### 5.3 结构变化

- 单链表：Data + Next
    
- 双链表：Data + Next + Prev
    
- 还有循环单链、循环双链等变形。
    

### 5.4 头结点

- 常在首结点前加**头结点**（不存数据），指向第一个元素，目的是**统一插入/删除边界情况**，简化操作。
    

### 5.5 典型操作与复杂度（带头结点为主）

1. **初始化 MakeEmpty**
    
    - 生成头结点，Next=NULL
        
    - O(1)。
        
2. **Length**
    
    - 指针从头结点向后遍历计数
        
    - O(n)。
        
3. **查找第 K 个元素 FindKth**
    
    - 依次走 K−1 步
        
    - O(n)。
        
4. **按值查找 Find(X)**
    
    - 顺链扫描直到 Data==X
        
    - O(n)。
        
5. **插入 Insert(X, i)**（在第 i 个元素前）
    
    - 找第 i−1 个结点 pre
        
    - 申请 tmp 存 X
        
    - 指针修改：  
        tmp->Next = pre->Next; pre->Next = tmp
        
    - 平均查找 n/2 → O(n)。
        
6. **删除 Delete(i)**
    
    - 找第 i−1 个结点 pre
        
    - tmp=pre->Next
        
    - pre->Next=tmp->Next; free(tmp)
        
    - 平均 O(n)。
        
7. **建表 CreateList(endTag)**
    
    - **顺序建表（尾插）**：r指向尾部，新结点接到尾后，更新 r
        
    - **逆序建表（头插）**：新结点接到头后，成为新首元
        
    - 本质都是不断“申请结点+链接指针”。
        
8. **输出 PrintList**
    
    - 从首元结点遍历打印
        
    - O(n)。
        

### 5.6 链式存储的关键/易错点

- 结点定义、动态申请与释放
    
- 指针链接表示关系
    
- 头结点/头指针/表头指针区分
    
- 操作元素必须掌握其地址
    
- 指针丢失会造成“内存垃圾”
    
- 指针有类型，类型匹配才能正确指向
    
- 动态存储要“**申请—使用—释放**”。

## 6. 线性表ADT应用举例（会用来出题）

### 6.1 通讯录管理

- 数据元素：联系人记录（可含序号、姓名、电话、Email、微信等）
    
- 关系：线性关系（方便查找/管理）
    
- 操作：插入、删除、查询、修改、排序、保存等
    
- 过程：问题分析 → 抽象ADT → 选存储结构实现 → 做交互界面。
    

### 6.2 一元 n 次多项式处理

- 多项式：(P_n(x)=\sum p_k x^{e_k})，指数单调。
    
- 两种线性表抽象方式：
    
    1. **按幂次顺序存系数**（长度 n+1）  
        Lp = (c0, c1, …, cn)
        
    2. **按项存(系数,指数)**（只存非零项）  
        Lp = ((p1,e1), (p2,e2), …)
        
- 要做加减乘/求值/求导等操作时，需要比较顺序存储 vs 链式存储：
    
    - 存储效率（空间占用）
        
    - 操作效率（时间复杂度与实现难度）。

## 7. 一句话对比总结（考点式）

- **顺序表**：连续存储、随机访问快；插删慢（要移动）。
    
- **链表**：非连续存储、插删方便；访问慢（要遍历）。
