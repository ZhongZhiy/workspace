# 🚀 我的 GTD 工作流指南 (基于 Nvim-Orgmode)

本文档简述了本文件夹中各个 `.org` 文件的作用，以及如何在 Neovim 中配合 `nvim-orgmode` 跑通 GTD (Getting Things Done) 工作流。

## 📂 核心文件说明

* **`inbox.org` (收集箱 / 大脑缓存)**
  * **作用**：所有未处理信息的临时收件箱。
  * **用法**：任何一闪而过的念头、待办、文章链接、灵感，**第一时间无脑记录在这里**。在 nvim-orgmode 中，通常使用 Capture 快捷键（例如 `<Leader>oc`）快速录入，不要在这里花时间做分类和排期。
  
* **`gtd.org` (核心行动库)**
  * **作用**：当前正在实际推进的项目、日常习惯和具体的下一步行动（Next Actions）。
  * **用法**：存放已经过大脑加工、明确了具体动作的任务。执行任务时，你的绝大部分精力都集中在这个文件。

* **`someday.org` (将来/也许 孵化器)**
  * **作用**：将来也许会做，但目前不打算投入精力和时间的事（如折腾计划、写作灵感、想看的书）。
  * **用法**：如果不确定一件事目前要不要做，就丢进这里，减轻大脑负担。

* **`refile.org` (中转站)**
  * **作用**：通常用作其他设备（比如手机上的 Orgzly）同步记录信息的默认接收处，或是在整理 Inbox 时的缓冲区。清空时将其内容 Refile（重定向）到 `gtd.org`。

## 🔄 GTD 运转流程 (The Workflow)

保持系统活力的秘诀在于以下四个步骤的循环：

### 1. 收集 (Capture) —— 随时随地
* 脑子里冒出任何任务或想法，立刻按下 Capture 快捷键，记入 `inbox.org`。
* **原则**：不要去记在脑子里，保持大脑清空，专注当下的编码或工作。

### 2. 组织与归档 (Refile) —— 每天或隔天
* 打开 `inbox.org`，从上到下处理每一个条目问自己：**这需要我采取行动吗？**
  * **否**：直接删除，或者移入 `someday.org` 作为备忘。
  * **两分钟内能解决**：立刻顺手做完（比如回个简单微信）。
  * **是，且需要多步完成**：把它定义为一个项目，给它加上 `TODO`，并使用 Refile 快捷键（通常是 `<Leader>or`）将其移动到 `gtd.org` 对应的项目层级下。

### 3. 执行 (Engage) —— 每天
* 打开 nvim-orgmode 的 Agenda 议程视图（通常快捷键是 `<Leader>oa`）。
* 根据当天的精力、标签（如 `@coding`, `@reading`）和时间安排，从 Agenda 中挑选 `TODO` 去完成。
* 专注做事，做完标记为 `DONE`。

### 4. 每周回顾 (Weekly Review) —— 系统不崩溃的关键！
* 每周末（比如周日晚）抽出 15-20 分钟：
  1. **清空**：把 `inbox.org` 彻底清空，全部分发出去。
  2. **维护**：扫视 `gtd.org`，把过期做不完的取消（`CANCELED`）或延期，检查每个项目是否都有明确的“下一步动作”。
  3. **唤醒**：看一眼 `someday.org`，看看有没有什么沉睡的想法这周想启动了，如果有，移入 `gtd.org`。

## ⌨️ 常用快捷键速查

* **快速捕获 (Capture)**: `<Leader>oc`
  * `t`: 待办 (Task) | `w`: 工作 (Work) | `k`: 想法 (Idea) | `n`: 随手记 (Note) | `i`: 带自定义标签任务
  * 浮窗内保存: `<C-c>` 或 `<Leader>w`
  * 浮窗内取消并退出: 普通模式按 `q` 或 `<Esc>`（原生键 `<Leader>ok`）
* **超级议程 (Super Agenda)**:
  * 浮窗超级日程: `<Leader>oa`
  * 全屏超级日程: `<Leader>oF`
  * 议程内快速单键过滤: `ot`(待办) / `on`(下一步) / `og`(进行中) / `ow`(等待) / `od`(完成) / `oa`(重置过滤)
* **Org 缓冲内编辑**:
  * 循环切换状态: `t` 或 `cit` | 切换复选框: `<C-Space>`
  * 重分类 (Refile): `<Leader>or` | 切换归档标签: `<Leader>oA`
  * 排期: `<Leader>ois` | 截止时间: `<Leader>oid`

> 详细配置与更新日志请参阅配置文档：`~/.config/nvim/docs/orgmode.md`
