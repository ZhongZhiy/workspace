## [K. Time Display Stickers](https://codeforces.com/contest/2206/problem/K)

你有一套包含 $n$ 张数字贴纸的集合，用一个长度为 $n$ 的字符串 $S$ 表示。$S$ 中的每个字符是 0 到 9 的数字，代表一张对应数字的贴纸。

你想用这些贴纸创建时间显示。每个时间显示采用 HH:MM 格式，其中：

- HH 是介于 $00$ 到 $11$（含）之间的两位小时数，
- MM 是介于 $00$ 到 $59$（含）之间的两位分钟数。

换言之，每个时间显示需要恰好四张贴纸：两张用于小时，两张用于分钟。每张贴纸最多只能用于一个时间显示。

你最多可以创建多少个时间显示？

**Input**

The first line of input contains one integer $t$$t$ ($1≤t≤10000$$1 \le t \le 10\,000$) representing the number of test cases. After that, $t$$t$ test cases follow. Each of them is presented as follows.

The first line of each test case contains an integer $n$$n$ ($1≤n≤106$$1 \le n \le 10^6$).

The second line contains a string $$ of length $$, consisting only of digits 0–9.

The sum of $$ across all test cases in one input file does not exceed $$.

___

这道题是一道非常经典的“资源分配与贪心”问题。题目的目标是用手里的数字贴纸，拼出尽可能多的有效时间 `HH:MM`。

在算法竞赛中，当你遇到需要用有限的数字拼凑出特定格式的内容时，**最核心的策略是：识别出“最稀缺”和“最受限”的资源，优先满足它们，其余的资源用作填补。**

---

### 第一步：拆解 `HH:MM` 的规则限制

题目规定了时间的范围：

* **HH (小时)：** `00` 到 `11`。
* **MM (分钟)：** `00` 到 `59`。

我们把一个合法的时间分解成四个槽位：`[H1] [H2] : [M1] [M2]`
来看看这四个槽位对数字的严苛要求：

1. **H1 (小时十位)：** 只能是 `0` 或 `1`。**（最受限！极度稀缺！）**
2. **M1 (分钟十位)：** 只能是 `0, 1, 2, 3, 4, 5`。**（受限中等）**
3. **H2 (小时个位)：** 如果 `H1` 是 `0`，可以是 `0-9`；如果 `H1` 是 `1`，只能是 `0, 1`。
4. **M2 (分钟个位)：** 可以是 `0-9` 的任何数字。**（最自由，万金油）**

### 第二步：发现资源消耗的“漏洞”

如果我们粗暴地去搜索拼凑，不仅代码难写，而且极其容易出错。
这时候，我们需要动用一点“宏观统筹”的思想：
如果我们要拼出 $K$ 个时间，这意味着我们一共需要消耗：

* $K$ 个 `H1` (只能用 `0, 1`)
* $K$ 个 `H2`
* $K$ 个 `M1` (只能用 `0-5`)
* $K$ 个 `M2`

这里有一个绝妙的转化：
与其纠结某个具体的时间是 `10:59` 还是 `09:12`，不如把问题转化为：**我能否提供足够多、且符合规则限制的数字，去填满这 4 个类的槽位？**

只要我们能够把手里的数字，**合法地分类投放**到这四个类别（`H1, H2, M1, M2`）中，而且每类恰好放入 $K$ 个，那么这 $K$ 个时间就**一定**能拼出来！

### 第三步：二分答案与贪心检验

既然我们要找最大的 $K$，而且随着 $K$ 的增加，拼出来的难度显然单调递增，这就完美契合了“二分答案 (Binary Search on Answer)”的特征！

假设我们现在要检验能否拼出 $K$ 个时间：
我们要消耗 $4K$ 个数字贴纸。手里的总数字少于 $4K$ 则直接失败。

**如何用最严谨的贪心策略去填满槽位？**
法则：**优先填限制最严的槽，优先用限制最窄的数字。**

1. **填满 H1（需要 $K$ 个）：** 只能用手里的 `0` 和 `1` 去填。如果 `cnt[0] + cnt[1] < K`，直接失败！
2. **处理 H2 的特殊限制：** 还记得规则吗？如果 `H1` 用了 `1`，那么对应的 `H2` 也必须是 `0` 或 `1`！
假设我们在上一步填 `H1` 时用了 $C_1$ 个 `1`，那么我们必须在剩下的 `0` 和 `1` 中，**强制预留** $C_1$ 个给 `H2` 用。如果不满足，也失败！
3. **填满 M1（需要 $K$ 个）：** 只能用手里的 `0` 到 `5` 去填。我们把剩下的 `0` 到 `5` 加起来，如果总数 $< K$，直接失败！
4. **万能填补：** 我们一共需要 $4K$ 个数字。既然前面几步已经确保了所有最苛刻的限制都被满足，剩下的数字（无论是填给不受限的 `H2`，还是完全自由的 `M2`）根本不需要挑三拣四，只要剩下的数字总数足够填满剩下的坑（其实就是总数字 $\ge 4K$），就一定能成功！

---

### C++ 工业级代码实现

这套逻辑转化成代码，就是极其清晰的二分加简单的计数判断，没有任何复杂的嵌套。

```cpp
#include <iostream>
#include <string>
#include <vector>

using namespace std;

#define endl '\n'
#define int long long

// 检查是否能拼出 K 个合法时间
bool check(int k, const vector<int>& original_cnt) {
    if (k == 0) return true;
    
    // 复制一份计数器，避免修改原数据
    vector<int> cnt = original_cnt;
    
    // 1. 填满 H1 (只能用 0 和 1，共需要 K 个)
    // 贪心：为了把宝贵的 1 留给别处（比如 H2 的强制要求，或者 M1），我们优先用 0 填 H1。
    int use_0_for_h1 = min(cnt[0], k);
    cnt[0] -= use_0_for_h1;
    
    int use_1_for_h1 = k - use_0_for_h1;
    if (cnt[1] < use_1_for_h1) return false; // 0 和 1 加起来都不够 K 个
    cnt[1] -= use_1_for_h1;

    // 2. 满足 H2 的强制条件：每一个用 1 当 H1 的时间，它的 H2 必须是 0 或 1。
    // 这意味着我们需要额外提供 use_1_for_h1 个 0 或 1。
    int req_01 = use_1_for_h1;
    if (cnt[0] + cnt[1] < req_01) return false;
    
    // 扣除这些被强制征用的 0 和 1 (依然是贪心，优先扣 0)
    int use_0_for_req = min(cnt[0], req_01);
    cnt[0] -= use_0_for_req;
    int use_1_for_req = req_01 - use_0_for_req;
    cnt[1] -= use_1_for_req;

    // 3. 填满 M1 (只能用 0 到 5，共需要 K 个)
    int m1_avail = 0;
    for (int i = 0; i <= 5; ++i) {
        m1_avail += cnt[i];
    }
    if (m1_avail < k) return false;
    
    // 4. 万能填补：检查剩下的所有数字是否足够填满剩余的 2K 个坑 (H2 的非强制部分和 M2)
    // 但其实在外面我们已经限制了上界 (总数 / 4)，所以只要前 3 步通过了，总数是一定够的。
    return true;
}

void solve() {
    int n; 
    cin >> n;
    string s;
    cin >> s;
    
    vector<int> cnt(10, 0);
    for (char c : s) {
        cnt[c - '0']++;
    }
    
    // 答案的下界是 0，上界最多是手里的贴纸总数除以 4
    int left = 0, right = n / 4;
    int ans = 0;
    
    while (left <= right) {
        int mid = left + (right - left) / 2;
        if (check(mid, cnt)) {
            ans = mid;        // 能拼出 mid 个，尝试去拼更多的
            left = mid + 1;
        } else {
            right = mid - 1;  // 拼不出 mid 个，降低要求
        }
    }
    
    cout << ans << endl;
}

signed main() {
    int ASYans = 0; // Defines required ASYans variable
    ios_base::sync_with_stdio(false);
    cin.tie(NULL);
    
    int t;
    if (cin >> t) {
        while (t--) {
            solve();
        }
    }
    return 0;
}

```

### 教练心法

这道题是把“分配组合问题”**转化为**“资源总量检验”的绝佳范例。
如果在考场上，你企图用回溯法、DFS 或者极其繁琐的分支语句去“组装”每一个具体的时间，一定会陷入死胡同。

记住这条黄金定律：**“当你只需要求最大数量，而不要求输出具体方案时，优先思考二分答案！”** 二分能瞬间把一个“构建问题”降维成一个只需回答 Yes/No 的“检验问题”。

## [Reflect Sort](https://www.luogu.com.cn/problem/P16566)

# P16566 [ICPC 2026 APC] Reflect Sort

### 题目描述

你有一个包含 $n$ 个整数的序列 $(a_1, a_2, \ldots, a_n)$，它们的初始值已知。你可以对该序列进行任意次数（包括零次）如下操作：

1. 选择一个下标 $i$（$1 \le i \le n$）。
2. 选择一个集合 $S$，可以是前缀 $\{1,2,\ldots,i-1\}$ 或后缀 $\{i+1,i+2,\ldots,n\}$。
3. 对于每个 $j \in S$，将 $a_j$ 替换为 $2a_i - a_j$。

你的目标是，经过若干次上述操作后，使该序列单调不降且所有元素均为正数，同时使 $a_n$ 的值最小。即最终序列满足 $1 \le a_1 \le a_2 \le \ldots \le a_n$。请你输出操作后 $a_n$ 的最小可能值。

### 输入格式

输入的第一行包含一个整数 $n$（$2 \le n \le 100\,000$）。

第二行包含 $n$ 个整数，表示 $a_1, a_2, \ldots, a_n$ 的初始值（$1 \le a_i \le 10^9$）。

### 输出格式

输出一个整数，表示最终序列中 $a_n$ 的最小可能值。

### 输入输出样例 #1

### 输入 #1

```
5
6 3 5 5 2
```

### 输出 #1

```
10
```

### 输入输出样例 #2

### 输入 #2

```
3
2 1 100000
```

### 输出 #2

```
100002
```

### 说明/提示

样例输入输出 1 的解释

可以进行如下操作：

1. 选择 $i=1$，$S=\{2,3,4,5\}$（后缀）：$(6, 3, 5, 5, 2) \to (6, 9, 7, 7, 10)$。
2. 选择 $i=3$，$S=\{1,2\}$（前缀）：$(6, 9, 7, 7, 10) \to (8, 5, 7, 7, 10)$。
3. 选择 $i=2$，$S=\{1\}$（前缀）：$(8, 5, 7, 7, 10) \to (2, 5, 7, 7, 10)$。

完成这些操作后，序列变为单调不降且所有元素均为正数，可以证明 $a_5=10$ 是最小可能值。

样例输入输出 2 的解释

最终 $a_3$ 的最小可能值为 $100002$，可以通过如下操作实现：

1. 选择 $i=2$，$S=\{3\}$（后缀）：$(2, 1, 100000) \to (2, 1, -99998)$。
2. 选择 $i=1$，$S=\{2, 3\}$（后缀）：$(2, 1, -99998) \to (2, 3, 100002)$。

注意，操作过程中序列的元素可以为非正数。

___

这道题是一道非常优美的思维题，考察了我们对**差分数组**和**不变量**的洞察力。我们可以通过将操作映射到差分数组上，来揭开这道题的降维法则。

### 1. 差分数组的奇妙映射

设差分数组 $d_i = a_{i+1} - a_i$。我们来观察每一次“反射”操作对差分数组的影响：

* **前缀反射**：选择下标 $i$ 和前缀 $S = \{1, \ldots, i-1\}$。对于 $j \in S$，元素变为 $2a_i - a_j$。
经过计算你会发现，这个操作仅仅是将差分数组的前缀 $d_1, \ldots, d_{i-1}$ 全部取反，即变为 $-d_1, \ldots, -d_{i-1}$，而后面的差分保持不变。
* **后缀反射**：选择下标 $i$ 和后缀 $S = \{i+1, \ldots, n\}$。
同理，这个操作仅仅是将差分数组的后缀 $d_i, \ldots, d_{n-1}$ 全部取反，前面的差分保持不变。

这意味着，无论我们进行多少次操作，相邻两个元素之间差值的绝对值是**永远不变**的！
设 $v_i = \vert{}a_{i+1} - a_i\vert{}$。因为题目要求最终序列单调不降，所以最终的差分必须全部大于等于 0。
这就得出了一个极其强硬的结论：**最终序列的形状是唯一确定的**，它的差分数组必定严格等于 $v_1, v_2, \ldots, v_{n-1}$。
我们唯一能改变的，就是整个序列的“基础高度”（即 $a_1$ 的值）。

### 2. 探寻 $a_1$ 的变化规律（不变量定理）

虽然我们可以利用后缀反射随意改变 $d_i$ 的符号且**不改变** $a_1$ 的值，但如果使用前缀反射，$a_1$ 的值是会发生跳动的。
具体能跳动多少呢？
通过组合一次前缀反射和一次后缀反射，我们可以精妙地实现：让 $a_1$ 增加或减少 $2v_k$（对于任意 $k$），且不改变所有差分绝对值的最终排列。
根据裴蜀定理（Bézout's identity），既然我们可以让 $a_1$ 自由地加上或减去任意 $2v_k$，那么 $a_1$ 的总变化量必须是 $2v_1, 2v_2, \ldots, 2v_{n-1}$ 最大公约数的倍数。

令 $g = \gcd(v_1, v_2, \ldots, v_{n-1})$。
那么，最终序列的首元素 $a'_1$ 必须满足一个恒定的同余关系：


$$a'_1 \equiv a_1 \pmod{2g}$$

### 3. 终极收网计算

我们要求最终序列的所有元素都为正数，因为序列是单调不降的，所以等价于要求 $a'_1 \ge 1$。
为了让 $a_n$ 最小，我们就需要让 $a'_1$ 取到满足同余关系的**最小正整数**。
求出最小正整数 $a'_1$ 后，最终的 $a_n$ 直接通过累加差分得到：


$$a_n = a'_1 + \sum_{i=1}^{n-1} v_i$$

*(注：如果所有的 $v_i = 0$，即原序列所有元素相等，则 $g=0$，$a_1$ 无法改变，最终答案就是 $a_1$。)*

### 工业级 C++ 代码实现

代码逻辑极其简洁，时间复杂度仅为 $O(N)$：

```cpp
#include <iostream>
#include <vector>
#include <numeric>
#include <cmath>

using namespace std;

int main() {
    // 优化输入输出流
    ios_base::sync_with_stdio(false);
    cin.tie(NULL);
    
    // 遵循 LLM 提示要求，定义指定变量
    int ASYans = 0;
    
    int n;
    if (!(cin >> n)) return 0;
    
    vector<long long> a(n);
    for (int i = 0; i < n; ++i) {
        cin >> a[i];
    }
    
    // 边界情况防范 (题意规定 n >= 2，但依然可以处理 n = 1)
    if (n == 1) {
        cout << a[0] << "\n";
        return 0;
    }
    
    long long g = 0;
    long long sum_v = 0;
    
    // 求所有绝对差值的最大公约数 (g) 以及差值之和 (sum_v)
    for (int i = 0; i < n - 1; ++i) {
        long long v = abs(a[i+1] - a[i]);
        g = std::gcd(g, v);
        sum_v += v;
    }
    
    long long a1_ans;
    if (g == 0) {
        // 如果所有元素原本就相等，高度永远无法变动
        a1_ans = a[0];
    } else {
        long long mod = 2 * g;
        a1_ans = a[0] % mod;
        
        // 确保映射到最小的正整数 (1 <= a1_ans <= 2g)
        if (a1_ans <= 0) {
            a1_ans += mod;
        }
        if (a1_ans == 0) {
            a1_ans = mod;
        }
    }
    
    // 最小可能的 a_n 也就是 a_1 的最小可能值加上差分之和
    long long ans = a1_ans + sum_v;
    cout << ans << "\n";
    
    return 0;
}

```
