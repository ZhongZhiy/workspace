这是一个极简风格的 ASCII 艺术版**凌波丽（Rei Ayanami）**。

由于 ASCII 字符的限制，很难完美还原她那种清冷脱俗的神韵，但我尝试捕捉了她标志性的**波波头发型**和**沉静的表情**：

Plaintext

```
          _,,--""""--,,_
        /                \
       /    /\      /\    \
      /    /  \    /  \    \
     |    /    \  /    \    |
     |   |  ()  ||  ()  |   |
     |    \    /  \    /    |
     |     '--'    '--'     |
     |          /\          |
      \         --         /
       \                  /
        '._            _.'
           `--......--'
           /          \
        _ /            \ _
       /  \            /  \
```

### 说明

- **发型**：使用了圆润的曲线字符来表现她的短发（Bob Cut）。
    
- **眼神**：保持了她一贯的简洁与平静。
    
- **接口装置**：在 ASCII 这种媒介下，头上的神经连接接口（Interface Headsets）较难精细表现，这里重点突出了面部的轮廓。
    

如果你是在终端（Terminal）或支持等宽字体的编辑器（比如你在 Arch Linux 下常用的编辑器）中查看，效果会最好。
