## 0. 本讲范围

特殊线性表包括：**栈、队列、字符串、数组、广义表**。它们都是线性表的“操作受限/元素受限/关系更多层”的特化。

---

## 1. 栈（Stack）

### 1.1 定义与特性

- **定义**：一端固定，只允许在另一端进行插入/删除的线性表（栈顶操作）。
    
- 术语：栈顶 top、栈底 bottom、入栈 push、出栈 pop、栈空/栈满。
    
- **操作特性**：**FILO / LIFO**（先进后出 / 后进先出）。
    
- 栈特殊在“**操作受限制**”，元素/关系仍是线性的。
    

### 1.2 ADT Stack

- CreateStack(MaxSize)
    
- IsFull / IsEmpty
    
- Push(X) / Pop()
    
- GetTop()
    
- StackSize() 等。
    

### 1.3 顺序栈实现

- **结构**：数组 Data + 栈顶指针 Top + MaxSize。Top=-1 表示空。
    
- **Push**：先判满，再 `Data[++Top]=X`。O(1)
    
- **Pop**：先判空，再返回 `Data[Top--]`。O(1)
    
- 溢出：
    
    - 上溢 Overflow：满了还入栈
        
    - 下溢 Underflow：空了还出栈。
        

### 1.4 共享栈（两个/多个栈）

- **两个栈共享一块数组**：Top1 从左增，Top2 从右减；
    
    - 满：`Top2 - Top1 == 1`
        
    - Push/Pop 通过 Tag 区分哪个栈。
        
- 多栈共享：可“浮动再分配”共享空间（思想层面了解）。
    

### 1.5 链栈实现

- **结构**：单链表结点 Data+Next；栈顶是表头位置（便于 O(1) 入/出）。
    
- 特点：空间易扩展，几乎不产生溢出（除非系统没内存）。
    

### 1.6 栈的典型应用

1. **出栈序列计数**
    
    - 给定入栈 1..n，所有合法出栈序列个数为 **Catalan 数**。n=4 时为 14 种，不是 24 种全排列。
        
2. **表达式求值**
    
    - 表达式：操作数 + 运算符；形式：中缀/前缀/后缀。
        
    - **后缀求值**：  
        读到操作数→入栈；读到运算符→弹出两数算完再入栈；最终栈顶是结果。O(n)。
        
    - **中缀求值** 两种方法：  
        a) 中缀→后缀（算符优先法）→后缀求值。  
        b) 直接中缀求值：**两个栈** OPTR(运算符) + OPND(操作数)，比较优先级决定入栈/计算/脱括号。
        
    - 运算符优先级表、优先级比较函数 CompOp 是关键。
        
3. **递归/函数调用模拟**
    
    - 调用需保存现场（返回地址、参数、局部变量）且遵循“后调用先返回”，所以用栈管理。
        
    - 递归可用显式栈转非递归并做优化。

## 2. 队列（Queue）

### 2.1 定义与特性

- **定义**：只允许**一端插入（队尾 rear）**，另一端删除（队首 front）的线性表。
    
- **FIFO / LILO**：先进先出。
    
- 术语：队首、队尾、入队 AddQ、出队 DeleteQ、队空/队满。
    

### 2.2 ADT Queue

- CreateQueue(MaxSize)
    
- IsFullQ / IsEmptyQ
    
- AddQ(X) / DeleteQ()
    
- FrontQ()
    
- QueueSize() 等。
    

### 2.3 顺序队列与循环队列

- 顺序队列：数组 Data + front/rear 指针。
    
    - 麻烦点：**空/满判断不唯一**、出队后出现**假溢出**（前面有空位但 rear 到末尾）。
        
- **解决：循环队列（环状队列）**
    
    - 视数组为环，用取模 `%MaxSize` 回绕。
        
    - 判空：`front == rear`
        
    - 判满（两种方案）：
        
        1. 加计数/布尔标记；
            
        2. **牺牲一个单元**：满时 `front == (rear+1)%MaxSize`。常用此法。
            
    - O(1) 操作：
        
        - AddQ：`rear=(rear+1)%MaxSize; Data[rear]=X`
            
        - DeleteQ：`front=(front+1)%MaxSize; return Data[front]`
            
        - 长度：`(rear - front + MaxSize) % MaxSize`。
            

### 2.4 链队列

- **结构**：单链表 + 两指针 Front/Rear。
    
- 入队在尾、出队在头，均 O(1)。
    
- 特点：简单、无假溢出，但指针域带来额外空间。
    

### 2.5 典型应用

- **打印机缓冲区**：主机写入任务入队，打印机按 FIFO 出队执行。
    
- **CPU 分时/服务大厅排队模拟**：多个窗口队列 + 事件表（按时间有序线性表）。

## 3. 字符串（String）

### 3.1 定义与特性

- **定义**：数据元素限定为字符的线性表。
    
- 特殊点：操作对象往往是**子串**而非单元素。
    
- 术语：空串、空格串、主串、子串、位置、长度、相等比较等。
    

### 3.2 ADT String

- Setnull, StrAssign, StrCompare, StrLength, StrConcat
    
- Substr, strstr/Index（模式匹配）
    
- StrReplace, StrInsert, StrDelete 等。
    

### 3.3 顺序存储

- 本质是字符数组，末尾用 `'\0'` 结束；可用结构存 curlen/MaxSize。
    
- C 语言库 string.h 提供 strcpy/strcat/strcmp/strlen/strstr 等。
    

### 3.4 模式匹配

1. **BF（Brute Force）朴素匹配**
    
    - 逐起点比较，不等则回溯换起点。
        
    - 最坏 O(mn)。
        
2. **KMP 匹配**
    
    - 核心：利用模式串的**部分匹配信息**，失配时主串不回溯，按 next 跳转。
        
    - next[j]：模式串第 j 位失配时，下一个比较位置（“失败函数”）。
        
    - 计算 next：按定义或递推，典型算法 get_next，O(m)。
        
    - 匹配算法 index_KMP：O(m+n)。
        
    - 有 nextval 优化版本（减少无效比较）。
        

- 例题比较：BF 比较次数 > KMP（文中示例 23 vs 17）。

## 4. 数组（Array）与矩阵

### 4.1 数组定义

- **数组是特殊线性表**：元素受**多个线性关系**约束（多维）。维/下标概念。
    
- n 维数组形式化：D 为多下标元素集合，R 含 R1..Rn 多组相邻关系。
    
- 因“牵一发而动全身”，数组常用于**静态数据**，一般不做插删。
    

### 4.2 数组顺序存储与地址映射

- 连续空间存放多维元素，需约定优先次序：
    
    - **行主序**（先行后列）
        
    - **列主序**（先列后行）。
        
- 元素数：  
    $(n=\prod_{i=1}^{k}(d_i-c_i+1))$，空间 Size=n·l。
    
- 地址公式（掌握二维/三维）：
    
    - 1D：LOC(a[i]) = Base + (i-c1)·l
        
    - 2D 行主序：  
        LOC(a[i,j]) = Base + (d2-c2+1)(i-c1)l + (j-c2)l
        
    - 2D 列主序：  
        LOC(a[i,j]) = Base + (d1-c1+1)(j-c2)l + (i-c1)l
        
    - 3D 行主序：  
        Base + (d2-c2+1)(d3-c3+1)(i-c1)l
        
        - (d3-c3+1)(j-c2)l + (k-c3)l。
            
- 特点：**随机存取 O(1)**。
    

### 4.3 矩阵与特殊矩阵压缩

- 普通矩阵：二维数组存储，操作（转置/加减乘/输出）直接做。
    
- **特殊矩阵**：对称/三角/带状/稀疏矩阵
    
    - 共同点：零多 or 重复多 → 直接二维数组浪费空间。
        

1. **对称矩阵、上/下三角矩阵**
    
    - 只存一个三角区：空间 $(1+2+\dots+n = n(n+1)/2)$。
        
    - 需掌握下标 (i,j) ↔ 一维 k 的映射与地址计算。
        
2. **带状/三对角矩阵**
    
    - 带宽 d：每行最多 (2d+1) 个非零。
        
    - 空间：(n(2d+1) - 2d)。
        
    - 行主序映射：  
        $LOC(aij)=Base+(i-1)(2d+1)+(j-i)$，其中 i-d ≤ j ≤ i+d。
        
3. **稀疏矩阵**
    
    - 非零元素 s 远小于 m·n；稀疏因子 e=s/(m·n)，e≤0.05 常视为稀疏。
        
    - **三元组线性表表示**：每个非零元素 (row,col,value)。可按行或列排序。
        
    - 压缩存储：
        
        - **三元组顺序存储**：Triple 数组 + Rows/Cols/Terms。
            
        - **十字链表**：多重链表示二维关系；行、列各有循环链表头结点；操作更复杂但结构表达强。输入/建立/输出是基础必会。

## 5. 广义表（Generalized List）

### 5.1 定义与特点

- **定义**：线性表的推广，元素要么是**原子项**（不可再分），要么是**子表（广义表）**。
    
- 记法：用括号与逗号；大写表示子表，小写表示原子。
    
- 表头/表尾：
    
    - 表头 a1 可能是原子或子表
        
    - 表尾 (a2..an) **一定是子表**。
        
- 三大性质：
    
    1. **多层次结构**（表中有表）
        
    2. **共享性**（可被多个表引用）
        
    3. **递归性**（如 E=(a,E)）。
        

### 5.2 ADT Lists

- InitGList, GListLength, GListDepth, GListEmpty
    
- GetHead/GetTail
    
- InsertFirst/DeleteFirst
    
- Traverse_GL(visit) 等。
    

### 5.3 存储：多重链表（重点理解）

- 由于元素结构不一，**难用顺序存储**，用链式更合适。
    
- 通用三域思想：
    
    - Tag 标志域区分原子/子表
        
    - Data/Sublist 联合域（原子存值，子表存指针）
        
    - Next 后继指针。
        
- 常见多重链实现方式：
    
    1. **每个元素一个结点**（Tag+union+Next）
        
    2. **尾链表存储**（hp/tp 指向表头/表尾）
        
    3. 另一种 hp/tp/next 组合形式  
        → 具体算法略，但本质是多链指针操作。

## 6. 章末速记对比（高频考点）

- **栈：LIFO，单端操作，适合回溯/递归/表达式。**
    
- **队列：FIFO，双端分工，适合排队/缓冲/调度。**
    
- **字符串：元素是字符，核心是子串与模式匹配（BF vs KMP）。**
    
- **数组：多维+多关系，顺序存储+行/列主序地址映射。**
    
- **广义表：元素可再为表，多层次/共享/递归，多重链存储。**
