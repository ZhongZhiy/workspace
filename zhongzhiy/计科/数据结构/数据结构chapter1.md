## 1.2 数据结构基础（定义原话尽量保留）

### 1.2.1 基本概念

- **数据（Data）**：**“能输入计算机且能被计算机处理的各种符号的集合。”**
    
- **数据元素（Data Element）**：**“数据的基本单位，在计算机程序中通常作为一个整体进行考虑和处理。”**
    
- **数据项（Data Item）**：**“数据元素的组成部分，是最小的、不可分割的数据单位。”**
    
- **数据对象（Data Object）**：**“具有相同性质的数据元素的集合，是数据的一个子集。”**
    
- **结构（Structure）**：**“数据元素之间存在的关系。”**
    
- **数据结构（Data Structure）**：**“相互之间存在一种或多种特定关系的数据元素的集合。”**
    
    - 形式化：**Data_Structure = (D, R)**  
        D：数据元素集合；R：D 上的关系集合。
        

### 1.2.2 逻辑结构（原话型结论）

- **“逻辑结构是从逻辑关系上描述数据，和存储无关。”**
    
- 四类逻辑结构：
    
    1. **集合结构**：元素同属一个集合，除“同属”外无其他关系。
        
    2. **线性结构**：**“数据元素之间存在一对一关系。”**
        
    3. **树形结构**：**“数据元素之间存在一对多关系。”**
        
    4. **图状结构（网状结构）**：**“数据元素之间存在多对多关系。”**
        

### 1.2.3 存储结构（物理结构）

- **“存储结构是逻辑结构在计算机中的表示（又称物理结构、映像）。”**
    
- **两种最基本的存储结构**：
    
    1. **顺序存储结构**：**“把逻辑上相邻的元素存储在物理位置相邻的存储单元中。”**
        
    2. **链式存储结构**：**“用一组任意的存储单元存储线性表的数据元素，元素之间的逻辑关系用指针表示。”**
        
- **“逻辑结构与存储结构是相互独立的。”**
    
- 同一逻辑结构可对应多种存储实现，选择取决于时间/空间需求。
    

### 1.2.4 数据类型与抽象数据类型

- **数据类型（Data Type）**：**“一组性质相同的值的集合以及定义在这个值集合上的一组操作的总称。”**
    
- **抽象数据类型（ADT, Abstract Data Type）**：  
    **“一个数学模型以及定义在该模型上的一组操作。”**
    
- **“ADT 的实现包括：数据结构的实现和在其上的基本操作的实现。”**
    
- **“通常所说的数据类型是已经实现了的抽象数据类型。”**

## 1.3 算法基础（定义原话保留）

### 1.3.1 算法定义

- **算法（Algorithm）**：  
    **“对特定问题求解步骤的一种描述，是指令的有限序列。”**
    
- 算法五个特性（原文式）：
    
    1. **有穷性**
        
    2. **确定性**
        
    3. **可行性**
        
    4. **输入**
        
    5. **输出**
        

### 1.3.2 算法描述方法

- 自然语言、图形、伪代码、程序语言。
    

### 1.3.3 算法评价标准

- **正确性、可读性、健壮性、有效性（时间/空间）。**
    

### 1.3.4 算法复杂度

- **“算法分析的目的是看算法的时间复杂度和空间复杂度随问题规模 n 的增长趋势。”**
    
- **时间复杂度**：T(n)=O(f(n)) 表示算法时间随 n 的数量级。
    
- **空间复杂度**：S(n) 表示辅助空间随 n 的数量级。
    
- 常见增长阶（原表顺序）：  
    [  
    O(1),\ O(\log n),\ O(n),\ O(n\log n),\ O(n^2),\ O(n^3),\ O(2^n),\ O(n!),\ O(n^n)  
    ]  
    
- **最好/最坏/平均时间复杂度**：Tbest、Tworst、Tavg。
