## $x \oplus x$ 的结果是？
0

## $x \oplus 0$ 的结果是？
x

## 若要通过异或运算得到 $x$ 的按位取反（~x），应执行什么操作？
$x \oplus (-1)$ （即 $x$ 与全 1 二进制数异或）

## 异或运算的自反性：若 $x \oplus y = z$，则 $z \oplus x = {{c1::y}}$。

## 设 $b_i$ 为前缀异或和，求区间 $[i, j]$ 内所有元素的异或和公式是？
$b_j \oplus b_{i-1}$

## 在已知前缀异或和数组 $b$ 的情况下，求原数组第 $i$ 个元素 $a_i$ 的公式是？
$b_i \oplus b_{i-1}$

## 为什么 $b_j \oplus b_{i-1}$ 等于区间 $[i, j]$ 的异或和？
因为 $b_j$ 包含了 $1 \dots j$ 的异或，而 $\oplus b_{i-1}$ 利用自反性消去了前 $1 \dots i-1$ 项。

## 连续异或同一个数两次的结果是什么？（例如 $a \oplus b \oplus b$）
$a$ （由于 $b \oplus b = 0$ 且 $a \oplus 0 = a$）
