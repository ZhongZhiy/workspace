# 算法

## 什么是二分图判定（Bipartite Graph Check）？

<!-- notecardId: 1767880956368 -->
将图中的节点分成两组，使得每条边的两个端点属于不同的组（即相邻节点颜色不同）。

## 一个图是二分图的充分必要条件是：该图中不含 {{c1::奇环 (Odd Cycle)}}。

<!-- notecardId: 1767880956395 -->



## 使用染色法判定二分图时，若当前节点颜色为 $c$（取值 1 或 2），其邻居应染上的颜色可以用哪个简便表达式表示？
$3 - c$

## 二分图染色过程中，检测到非二分图的标志是：发现某个邻居已经染过色，且 {{c1::颜色与当前节点相同}}。

<!-- notecardId: 1767880956407 -->

## 在主循环中遍历所有节点 `for (int i = 1; i <= n; i++)` 启动搜索的目的是什么？

<!-- notecardId: 1767880956411 -->
为了确保处理图中所有 {{c1::不连通的分量 (Disconnected Components)}}。

## 使用 DFS 或 BFS 进行二分图判定的时间复杂度和空间复杂度分别是？

<!-- notecardId: 1767880956414 -->
时间复杂度：$O(n + m)$；空间复杂度：$O(n + m)$。

## 在 DFS 实现二分图判定时，`color[u]` 数组通常初始化为 {{c1::0}}，代表该节点 {{c2::尚未访问/染色}}。

## 如果在染色过程中发现冲突（即存在奇环），递归函数应如何处理？

<!-- notecardId: 1767880956421 -->
立即返回 `false`，并让上层递归同样返回 `false` 以终止搜索。

## 二分图判定算法的核心逻辑填空：

<!-- notecardId: 1767880956425 -->
```cpp
for (int v : adj[u]) {
    if (color[v] == 0) {
        if (!dfs(v, {{c1::3 - c}})) return false;
    } else if (color[v] == {{c2::c}}) {
        return false;
    }
}
```

## 为什么在 `getNext` 函数的循环过程中直接记录 `j` 无法得到整串的所有 Border？

<!-- notecardId: 1767880956429 -->
因为循环中的 `j` 记录的是 $S$ 的各个“前缀”的最长 Border 长度，而非“整串”的 Border。

## 查找整串 $S$ 所有 Border 的核心理论依据：如果一个字符串有长度为 $k$ 的 Border，那么该 Border 的 {{c1::Border}} 也是原串的一个更短 Border。

<!-- notecardId: 1767880956432 -->

## 递归寻找整串所有 Border 的核心代码逻辑：

<!-- notecardId: 1767880956436 -->
```cpp
int curr = pi[n - 1];
while (curr > 0) {
    results.push_back(curr);
    curr = {{c1::pi[curr - 1]}}; 
}

```

## 为什么通过 `curr = pi[curr - 1]` 递归跳转是正确的？

<!-- notecardId: 1767880956441 -->

由于前缀  与后缀  完全相等，前缀的任何 Border 必然也是整个字符串  的后缀，从而符合 Border 定义。
