
# 计网

## 协议模型和层次
对等层通过协议(下层提供的服务)进行通信。
每层实现一组特定的功能，向上层提供服务, 一层层, 左后实现计算机网络

协议通过下层提供的服务进行实现, 给上层提供服务。
除了最底层和最上层


原语: 上层使用下层的方式

服务访问点: SAP(Service Access Point) 服务访问点

### 服务类型
1. 无连接的服务 
2. 面向连接的服务

## 数据单元

SDU(Service Data Unit) 服务数据单元
PDUs(Protocol Data Unit) 协议数据单元

上一层的SDU + header 被封装成下一层的PDU

**链路层** 解决相邻两点的P2P传输, **网络层** 在链路层基础上传输端到端E2E的数据

**传输层**可以提供进程与进程之间的通信, 还可以提供可靠的传输服务, 例如TCP协议

发送段(大封装) -> 交换机(两层解封装, 再封装)->  路由器(三层解封装, 再封装)-> 接收端(四层解封装)

### 各层次的协议数据单元
1. 应用层: 报文(message)
2. 传输层: 报文段(segment)
3. 网络层: 数据报(datagram)/分组(packet)
4. 链路层: 帧(frame)
5. 物理层: 比特流(bit stream)
