
# work

## tar 打包文件夹 `/photo` 为 `photo.tar` 并且显示打包过程

```shell
tar -cvf photo.tar /photo
```

## tar 打包文件夹并且压缩 `/photo` 为 `photo.tar.gz`

```shell
tar -czf photo.tar.gz /photo
```

## tar 解压提取文件 `photo.tar.gz` 到指定`path`
```shell
tar -xzf photo.tar.gz /path/
```

## tar 打包 `/sdcard/DCIM`中的全部文件为 `/sdcard/DCIM.tar`
```shell
//-C 是change director 就是切换目录, 否则 tar 会把多层目录一起打包进去, 如果想要纯一个文件夹, 就需要切目录
tar -C /sdcard -vcf /sdcard/DCIM.tar DCIM
```
