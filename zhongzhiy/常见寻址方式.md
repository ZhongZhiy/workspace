x86 的寻址方式（addressing modes）其实是“**你怎么指定操作数在哪里**”。从你现在的 32 位 AT&T 语法视角来看，可以分成几大类。每类我都给你最直观的例子 + 对应含义。

---

## 0. 先有个总览

x86 操作数可以在三种地方：

1. **立即数**（写死的常量）
    
2. **寄存器**
    
3. **内存**（通过各种“地址表达式”算出来）
    

“寻址方式”主要就是第 3 类：**怎么算内存地址**。

---

## 1. 立即数寻址（Immediate）

写死一个数，前面有 `$`：

```asm
movl $5, %eax
```

意思：eax = 5  
（C：`eax = 5;`）

---

## 2. 寄存器寻址（Register）

操作数就在寄存器里：

```asm
mov %eax, %ebx
```

意思：ebx = eax  
（C：`ebx = eax;`）

---

## 3. 直接内存寻址（Absolute / Direct memory）

地址是一个固定常量（或符号），不靠寄存器：

```asm
movl 0x804a000, %eax
```

意思：eax = 内存[0x804a000]

如果有符号表你会看到：

```asm
movl global_var, %eax
```

---

## 4. 间接寻址（Register-indirect）

寄存器里放地址，用括号表示“去内存取”：

```asm
movl (%eax), %ebx
```

意思：ebx = 内存[eax]  
（C：`ebx = *eax;`）

---

## 5. 基址 + 位移（Base + displacement）

最常见：**寄存器当基址再加偏移**：

```asm
movl -0x4(%ebp), %eax
movl 8(%ebp), %eax
movl 12(%esp), %edx
```

意思：

- eax = 内存[ebp-4] （局部变量）
    
- eax = 内存[ebp+8] （第1个参数）
    
- edx = 内存[esp+12] （某个栈位置）
    

对应 C：

```c
eax = *(int*)(ebp - 4);
eax = *(int*)(ebp + 8);
```

---

## 6. 变址寻址（Indexed）

只有 index * scale（没有 base），常用于表/数组：

```asm
movl (,%ecx,4), %eax
```

意思：eax = 内存[ecx*4]

> base 省略了，就写空位：`(, index, scale)`

---

## 7. 基址 + 变址 + 比例 + 位移（Full / SIB）

x86 最强的寻址形式：

```
disp(base, index, scale)
```

例子：

```asm
movl 8(%eax,%ecx,4), %edx
```

意思：  
edx = 内存[eax + ecx*4 + 8]

这就是 C 里的：

```c
edx = *(int*)((char*)eax + ecx*4 + 8);
```

**典型语义：数组/结构体混合访问。**

---

## 8. 相对寻址（PC-relative / RIP-relative，64位常见）

你现在贴的是 32 位，所以不常见；  
但 64 位你会经常看到：

```asm
mov 0x2fc9(%rip), %rax
lea main(%rip), %rdi
```

意思：地址 = rip + 偏移  
这是为了 **位置无关代码（PIC/PIE）**，共享库/ASLR 都靠它。

---

## 9. 隐式寻址（Implicit）

有些指令不写操作数，因为位置是**约定死的**：

- `ret`：隐式用栈顶返回地址
    
- `push %eax`：隐式写栈顶
    
- 乘除法：隐式用 ax/eax/edx
    

例子（32位乘法）：

```asm
imul %ebx
```

隐式含义：

- eax * ebx
    
- 结果低32位在 eax，高32位在 edx
    

---

## 10. 小抄：AT&T 写法速记

|AT&T形式|内存地址含义|
|---|---|
|`addr`|内存[addr]|
|`(%eax)`|内存[eax]|
|`8(%eax)`|内存[eax+8]|
|`(%eax,%ecx)`|内存[eax+ecx]|
|`(%eax,%ecx,4)`|内存[eax+ecx*4]|
|`8(%eax,%ecx,4)`|内存[eax+ecx*4+8]|
|`(,%ecx,4)`|内存[ecx*4]|

---

## 11. 你该怎么把它们和 C 直觉对上

- `base` 常常是：
    
    - 数组首地址
        
    - `this` 指针
        
    - 栈帧基址 ebp
        
- `index*scale` 常常是：
    
    - 数组下标 i
        
    - scale = 元素大小（int=4, short=2, char=1）
        
- `disp` 常常是：
    
    - 结构体字段偏移
        
    - arr 起点再偏一点
        
    - 局部变量/参数固定偏移
