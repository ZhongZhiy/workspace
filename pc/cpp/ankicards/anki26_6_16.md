## [线段树]
#线段树 #权值线段树

线段树维护可重集, 求第 $k$ 小的数, 和小于 $k$ 的数的个数
___

把线段树的区间当成桶, 线段树维护桶中数字的大小

1. 小于 $k$ 的数个数就有区间 `[1, k-1]` 中个数
```cpp
//求 [l, r] 区间的数的个数
int query_rnk(int l, int r, int p = 1, int cl = 1, int cr = sz){
    if(r < l) return 0;
    if(l <= cl && r >= cr){
        return tr[p].v;
    }
    int mid = (cl + cr) >> 1;
    int ans = 0;
    if(l <= mid) ans += query_rnk(l, r, p<<1, cl, mid);
    if(r > mid) ans += query_rnk(l, r, p<<1|1,  mid+1, cr);
    return ans;
}
```

2. 第 $k$ 小的数, 在节点 `p`, 如果左子树的大于 $k$, 那么这个数一定在左子树上, 否字在右子树上, 只不过查右子树的时候个数就需要减去左子树的大小 `k - tr[p<<1]`
```cpp
int query_num(int l, int p = 1, int cl = 1, int cr = sz){
    if(cl == cr){
        return cl;
    }
    int mid = (cl + cr) >> 1;
    if(tr[p<<1].v >= l) return query_num(l, p<<1, cl, mid);
    return query_num(l-tr[p<<1].v, p<<1|1, mid+1, cr);
}
```

实际上就做到了一般 **平衡树的操作**

## [G. Couleur](https://codeforces.com/gym/104566/problem/G)

DreamGrid 有一个包含 $n$ 个整数的数组。他可以对数组执行以下操作：选择一个未被选择过的元素并将其标记为不可用。DreamGrid 希望恰好执行 $n$ 次操作，直到所有元素都被标记。

DreamGrid 将子数组的成本定义为该子数组中的逆序对数。在每次操作前，DreamGrid 希望知道不包含任何不可用元素的子数组的最大成本。

请注意，子数组 $a_l, a_{l+1}, ..., a_{r-1}, a_r$ 是指原数组中 连续 的一段元素，其中 1 ≤ l ≤ r ≤ n。子数组 $a_l, a_{l+1}, ..., a_{r-1}, a_r$ 中的逆序对是指一对索引 (i, j) 和 (l ≤ i < j ≤ r)，满足不等式 $a_i > a_j$。

存在多个测试用例。第一行输入包含一个整数 $T$，表示测试用例的数量。对于每个测试用例：

第一行包含一个整数 $n (1 ≤ n ≤ 10^5)$ ——表示数组的长度。

第二行包含数组 $a_1, a_2, ..., a_n (1 ≤ a_i ≤ n)$ 的 n 个数值。

第三行包含一个排列 $p_1, p_2, ..., p_n$，表示按顺序执行操作时所选元素的索引。

请注意该排列是加密的，您可以通过以下方法获取真实排列：设 $z_i$ 为第 $i$ 次操作前的答案，则第 $i$ 次操作的实际索引为 $p_i \oplus z_i$，其中 $\oplus$ 表示按位异或运算符。

保证所有 $n$ 的总和不超过 $10^6$。

___
题目要求强制在线,

我的思路是使用可持久化线段树维护区间逆序对, 每次删除一个元素就是分裂一个区间, 那就用 **小并大** 的方法维护逆序对, 这样就可以在 $O(\log^2 n)$ 的时间复杂度内完成每次操作。

jiangly 的思路是使用分裂权值线段树维护逆序对, 每次删除一个元素就是分裂一个区间, 维护每个区间内的逆序对数量, 分裂函数 `split` 很妙

```cpp
#include <bits/stdc++.h>

using i64 = long long;

constexpr int N = 3E6;

struct Node {
    int l = 0;  //区间左端点
    int r = 0;  //区间右端点
    int cnt = 0; //区间内的元素个数
    i64 sum = 0; //区间内的逆序对数量
    int max = -1E9; //区间内的最大值
    int min = 1E9; //区间内的最小值
    int tag = 0; //懒标记, 用于区间修改
};

int tot = 0;  //当前节点总数
std::vector<Node> t(N); //线段树节点数组

void pull(int p) {  //更新节点信息
    t[p].cnt = t[t[p].l].cnt + t[t[p].r].cnt;
    t[p].sum = t[t[p].l].sum + t[t[p].r].sum;
    t[p].max = std::max(t[t[p].l].max, t[t[p].r].max);
    t[p].min = std::min(t[t[p].l].min, t[t[p].r].min);
}

void add(int p, int v) {  
    if (!p) {
        return;
    }
    t[p].sum += 1LL * t[p].cnt * v;  //逆序对数量增加
    t[p].tag += v; //懒标记增加
}

void push(int p) {  
    if (t[p].tag) {
        add(t[p].l, t[p].tag);
        add(t[p].r, t[p].tag);
    }
    t[p].tag = 0;
}

void add(int &p, int l, int r, int x, int y, int i) {
    if (!p) {
        p = ++tot;
        t[p] = {};
    }
    if (r - l == 1) {
        t[p].cnt += 1;
        t[p].sum += y;
        t[p].min = t[p].max = i;
        return;
    }
    int m = (l + r) / 2;
    push(p);
    if (x < m) {
        add(t[p].l, l, m, x, y, i);
    } else {
        add(t[p].r, m, r, x, y, i);
    }
    pull(p);
}

int query(int p, int l, int r, int x, int y) {
    if (!p || l >= y || r <= x) {
        return 0;
    }
    if (l >= x && r <= y) {
        return t[p].cnt;
    }
    int m = (l + r) / 2;
    push(p);
    return query(t[p].l, l, m, x, y) + query(t[p].r, m, r, x, y);
}

std::pair<int, int> split(int p, int v) {
    if (t[p].min >= v) {
        return {0, p};
    }
    if (t[p].max < v) {
        return {p, 0};
    }
    push(p);
    int q = ++tot;
    t[q] = {};
    auto [a, b] = split(t[p].l, v);  //分裂左子树
    auto [c, d] = split(t[p].r, v);  //分裂右子树
    t[p].l = a;
    t[p].r = c;
    t[q].l = b;
    t[q].r = d;
    add(b, -t[c].cnt);  //更新逆序对数量, 因为 c 中的元素都比 b 中的元素大, 所以 b 中的逆序对数量减少了 c 中的元素个数
    pull(p);
    pull(q);
    return {p, q};
}

void solve() {
    int n;
    std::cin >> n;

    tot = 0;

    std::vector<int> a(n);
    for (int i = 0; i < n; i++) {
        std::cin >> a[i];
        a[i]--;
    }
    std::vector<int> o(n);
    std::iota(o.begin(), o.end(), 0);
    std::sort(o.begin(), o.end(),
        [&](int i, int j) {
            return a[i] < a[j] || (a[i] == a[j] && i < j);
        });
    for (int i = 0; i < n; i++) {
        a[o[i]] = i;
    }

    int rt = 0;
    for (int i = 0; i < n; i++) {
        int v = query(rt, 0, n, a[i] + 1, n);
        add(rt, 0, n, a[i], v, i);
    }

    std::map<int, int> seg;
    seg[0] = rt;
    seg[n] = -1;
    std::multiset<i64> s{t[rt].sum};

    i64 ans;
    for (int i = 0; i < n; i++) {
        ans = *s.rbegin();
        std::cout << ans << " \n"[i == n - 1];

        i64 p;
        std::cin >> p;
        p ^= ans;
        p--;

        if (p < 0 || p >= n) {
            continue;
        }

        auto it = std::prev(seg.upper_bound(p));
        int l = it->first, r = l + t[it->second].cnt;
        int nd = it->second;
        seg.erase(it);
        // std::cerr << "(" << l << ", " << r << ")\n";

        s.extract(t[nd].sum);
        auto [L, MR] = split(nd, p);
        auto [M, R] = split(MR, p + 1);
        // std::cerr << p << " " << t[L].sum << " " << t[R].sum << "\n";
        if (L) {
            s.insert(t[L].sum);
            seg[l] = L;
        }
        if (R) {
            s.insert(t[R].sum);
            seg[p + 1] = R;
        }
    }
}

int main() {
    std::ios::sync_with_stdio(false);
    std::cin.tie(nullptr);

    int t;
    std::cin >> t;

    while (t--) {
        solve();
    }

    return 0;
}

```


## [Erratic Lights](https://www.luogu.com.cn/problem/P15211)

给定一个长度为 $n$ 的字符串代表不同颜色的灯, 其中 $b$ 代表蓝色, $r$ 代表红色, $g$ 代表绿色, 每次触摸其中一个等, 会等概率的变成其中一种颜色, 求把所有灯变成同一种颜色的 **最小期望次数**, $(1 \le n \le 100)$, 答案要求不超过 $10^{-6}$ 的绝对误差。

**样例**
输入
```
2
rb
```
输出
```
3
```

输入
```
5
rgbrg
```

输出
```
7.5
```


___

每种灯是 **绝对对称的**, 和次序, 颜色无关, 定义 $f(x, y, z)$ 为当前有 $x$ 个红灯, $y$ 个绿灯, $z$ 个蓝灯的最小期望次数, 其中 $x \ge y \ge \z$, 这样保证不用考虑颜色, 只考虑数量, 每次有 $3$ 种决策, 选择触摸红灯, 绿灯, 蓝灯, 那么到达状态 $f(x, y, z)$ 就是选择触摸这三个灯中的最小值

选择触摸 $x$, 那么有 $3$ 种情况, 触摸到红灯, 绿灯, 蓝灯, 分别到达状态 $f(x-1, y, z)$, $f(x, y-1, z)$, $f(x, y, z-1)$, 期望次数就是
$$
f(x, y, z) = 1 + \frac{1}{3}f(x, y, z) + \frac{1}{3}f(x-1, y+1, z) + \frac{1}{3}f(x-1, y, z+1)
$$

移项后
$$
f(x, y, z) = \frac{3}{2} + \frac{1}{2}f(x-1, y+1, z) + \frac{1}{2}f(x-1, y, z+1)
$$

同理对 $y, z$ 也有类似的递推关系。

定义最终状态为 $f(n, 0, 0) = 0$, 其他状态为 $f(x, y, z) = \infty$, 然后枚举所有的状态进行松弛, 直到所有值都和上一次的值相同, 就是最小期望次数。

```cpp
constexpr int N = 1e5;
struct Node{
    int x, y, z;
    Node(){}
    Node(int x, int y, int z):x(x), y(y), z(z){}
    bool operator < (const Node& a)const{
        if(x != a.x)return x < a.x;
        if(y != a.y) return y < a.y;
        return z < a.z;
    }
};

void solve(){
    int n; cin >> n;
    string s; cin >> s;
    
    vector<int> cnt(3);
    for(auto c : s) {
        cnt[0] += (c == 'r');
        cnt[1] += (c == 'g');
        cnt[2] += (c == 'b');
    }
    sort(all(cnt), greater<int>());

    map<Node, int> id;
    vector<Node> nodes;

    for(int i = n; i >= 0;--i){
        for(int j = min(i,n-i); j >= 0;--j){
            int k = n - i - j;
            if(k <= j){
                nodes.push_back({i, j, k});
                id[nodes.back()] = nodes.size()-1;
            }
        }
    }

    int M = nodes.size();

    // 修复 2：获取状态 ID 前必须强行排序，防止触发 map 隐式插入陷阱
    auto get_id = [&](int a, int b, int c) {
        int arr[3] = {a, b, c};
        sort(arr, arr + 3, greater<int>());
        return id[Node(arr[0], arr[1], arr[2])];
    };

    vector<vector<pii>> trans(3, vector<pii>(M));
    for(int i = 0;i < M; ++i){
        auto [x, y, z] = nodes[i];
        if(x > 0) trans[0][i] = {get_id(x-1, y+1, z), get_id(x-1, y, z+1)};
        if(y > 0) trans[1][i] = {get_id(x+1, y-1, z), get_id(x, y-1, z+1)};
        if(z > 0) trans[2][i] = {get_id(x+1, y, z-1), get_id(x, y+1, z-1)};
    }

    vector<ld> dp(M + 1, 1e9);
    bool ok = 1;
    
    int tar_id = id[Node(n, 0, 0)];
    // 修复 1：记录起点 ID
    int start_id = id[Node(cnt[0], cnt[1], cnt[2])]; 
    dp[tar_id] = 0;

    while(ok){
        ok = 0;
        for(int i = 0;i < M; ++i){
            if(i == tar_id) continue;

            ld exp = 1e9;
            auto [x, y, z] = nodes[i];

            // 修复 3：动态自环消除 (K: 有多少种概率回到自身)
            auto relax = [&](int act) {
                int k = 1; // 1/3概率颜色没变，必然回到自己，k 初始至少为 1
                ld sum = 0;
                int nxt[2] = {trans[act][i].F, trans[act][i].S};
                
                for(int j = 0; j < 2; ++j) {
                    if (nxt[j] == i) k++;
                    else sum += dp[nxt[j]];
                }
                
                if (k == 3) return (ld)1e9; // 3种情况全回自己，毫无意义
                return 3.0 / (3 - k) + sum / (3 - k);
            };

            if(x > 0) exp = min(exp, relax(0));
            if(y > 0) exp = min(exp, relax(1));
            if(z > 0) exp = min(exp, relax(2));

            if(dp[i] - exp > 1e-9){
                dp[i] = exp;
                ok = 1;
            }
        }
    }
    // 修正 1：输出 start_id
    cout << fixed << setprecision(10) << dp[start_id] << endl;
}

signed main() {
    hello;
    int t = 1;
    while(t--) solve();
    return 0;
}
```



## Card 1：博弈论核心结论（定性条件）
#博弈 #贪心
**Front:**
在两人轮流取物的零和博弈中（每次取数最大化自己得分），如果我要打破绝对贪心顺序，去拿一个价值较小的物品 $x$ 且保证不亏（属于最优策略），必须满足什么前置条件？
___

**Back:**
当前所有价值 **严格大于 $x$ 的物品**，其剩余数量必须均为 **偶数**。

> **理解/备注:** 偶数个最大值构成了互相抵消的“对子”。不去碰它们，对手也不敢碰；一旦对手拿一个，你立刻拿另一个进行“一换一”，差值收益绝对不会受损。


## Card 2：合法槽位推导（定量公式）

**Front:**
在状态倒推中，已知有 $f$ 个同等价值的大物品，它们把时间线切成了 $f+1$ 个槽。
已知绝对法则：**放置较小物品的槽位，必须保证其右侧剩余的该大物品数量为偶数**。
请问这 $f+1$ 个槽中，**合法的槽位数量 $m$** 是多少？

___
**Back:**
$m = \lfloor f/2 \rfloor + 1$

> **理解/备注:** 合法槽与非法槽必然是绝对交替出现的。不管 $f$ 是 3 还是 4，可用槽位分别是 2 和 3。


### Card 3：插空计数的方案合并（状态转移）
#组合数学

**Front:**
博弈序列计数题采用**从小到大**插入法。
已知已经排好了 $L$ 个较小元素，现在要将这 $L$ 个元素塞进当前物品（频次为 $f$）产生的 $m$ 个合法槽位中。当前步骤的**方案合并公式**是什么？
___

**Back:**
方案数 $\times \binom{L+m-1}{m-1} \times f!$

> **理解/备注:**
> 1. $\binom{L+m-1}{m-1}$：经典隔板法。把 $L$ 个已经绑定好的相对顺序序列，分配进 $m$ 个允许为空的盒子（槽）中。
> 2. $f!$：因为相同价值的物品带有不同的下标，是**可区分**的，需要乘上它们自身的排列。

## [Optimal Strategy](https://qoj.ac/contest/1997/problem/10775)

给定 $n$ 个物品, 每个物品有一个价值 $v_i$ , 两人轮流取物品, 每次取一个物品, 每位玩家都会最大化自己的得分, 问在两人都采取最优策略的情况下, 一共有多少取物品的顺序是合法的, 也就是每次取物品的顺序都是最大化自己的得分的, 答案模 $998244353$. $(1 \le n \le 10^6)$, $(1 \le v_i \le n)$

**样例1**

input
```
3
1 2 2
```
output
```
4
```

**样例2**

input
```
6
1 2 3 3 2 1 
```

output
```
120
```

**样例3**
```
12
1 1 4 5 1 4 1 9 1 9 8 10
```
___

这道题取值双方是一定的: 偶数个的数就平分, 奇数个的就贪心

模拟过程:
1. 先手取 $a$, 确保大于 $a$ 的数都是 **偶数**个, 如果有奇数个的数 $b$, 那么后手就可以取这个 $b$, 导致先手总是落后一个 $b$, 就不是最优策略了

**每次取的数, 比这个数大的都是偶数个, 就是取数的策略**

怎么量化这个策略, **从小到大构造**:

假设已经排好了的数为 $S$, 其中 $|S| = l$ , 那么, 当前排的数为 $n$, 有 $k$ 个, 可以让 $0, 2, 4, ...k/2*2$ 个之前有 $|S|$ 中的数, 这样就是把 $l$ 个数放入 $k/2 + 1$ 个槽中的组合数, 其中 $k$ 个数字是不同的, 再乘一个 $k!$
$$
ways = ways \times \binom{k/2+1+l-1}{l-1} \times k!
$$

```cpp
constexpr int M = 998244353;
void solve(){
    int n; cin >> n;
    vector<int> cnt(n + 1);
    fi(n){
        int x; cin >> x;
        cnt[x]++;
    }

    //预处理阶乘, 阶乘逆元, 组合数
    int H = 2*n;
    vector<int> fac(H + 1);
    fac[0] = 1;
    for(int i = 1;i <= H; ++i) fac[i] = fac[i-1] * i % M;
    
    vector<int> inf(H + 1);
    auto qpow = [&](int exp, int base) ->int{
        int res = 1;
        while(exp){
            if(exp&1) res = (res * base)% M;
            base = base * base%M;
            exp >>= 1;
        }
        return res%M;
    };
    
    auto inv = [&](int x)->int{return qpow(M-2, x);};
    
    inf[H] = inv(fac[H]);
    
    for(int i = H-1;i >= 0; --i) inf[i] = (i+1)*inf[i+1]%M;
    
    auto C = [&](int x, int y)->int{
        if(x == y || y == 0) return 1;
        if(y > x) return 0;
        // de2(fac[n], inf[m])de2(n, inf[n-m])
        return fac[x]*inf[y]%M*inf[x-y]%M;
    };

    //统计答案
    int ans = 1, total = 0;
    for(int i = 1;i <= n; ++i){
        if(cnt[i]){
            int m = cnt[i]/2 + 1;
            // de2(m, total)
            // de2(C(m+total-1, m-1), fac[m])
            ans  = ans * C(m+total - 1, m-1) % M * fac[cnt[i]] % M;
            total += cnt[i];
        }
    }
    cout << ans << endl;
}
```
