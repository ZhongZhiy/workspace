前后缀拆分技巧（Prefix & Suffix Trick）不仅用于乘法，它的**终极本质**可以总结为一句话：

> **只要一个运算 $\oplus$ 满足“结合律”（即 $(a \oplus b) \oplus c = a \oplus (b \oplus c)$），哪怕它完全没有“逆运算（无法做减法/除法）”，都可以通过前后缀拆分在 $O(1)$ 时间内优雅地扣除任意一项！**

在代数学中，满足结合律的结构叫**半群（Semigroup）**。下面为你盘点算法竞赛中利用这个思想解决的 **4 大经典场景**。

---

## 1. $\gcd$ 运算（最大公约数）

### 经典场景：删除一个数后的最大 $\gcd$

* **问题描述**：给定一个数组 $A = [a_1, a_2, \ldots, a_n]$，你可以**删除其中恰好一个数**，求剩下的 $n-1$ 个数的最大公约数 $\gcd$ 的最大可能值。
* **为什么不能做逆运算**：
已知全局 $\gcd(a_1, \dots, a_n) = 2$，如果你删掉了 $a_i = 6$，你根本没办法从 $2$ 里面“除掉” $6$ 的贡献。$\gcd$ 是完全不可逆的。

### 破局解法：

1. 预处理前缀 $\gcd$ 数组：

$$pref[i] = \gcd(a_1, a_2, \ldots, a_i)$$


2. 预处理后缀 $\gcd$ 数组：

$$suff[i] = \gcd(a_i, a_{i+1}, \ldots, a_n)$$


3. **扣除 $a_i$ 后的 $\gcd$**：

$$\text{ans}_i = \gcd(pref[i-1], suff[i+1])$$



```cpp
// 只需要 2 次循环预处理，就可以在 O(1) 内回答删除任意 a[i] 后的 gcd
int ans = 0;
for (int i = 1; i <= n; ++i) {
    int left_gcd = (i == 1) ? 0 : pref[i - 1];
    int right_gcd = (i == n) ? 0 : suff[i + 1];
    ans = max(ans, std::gcd(left_gcd, right_gcd));
}

```

## 2. 矩阵乘法（Matrix Multiplication）

### 经典场景：线段树 / 树上动态 DP 扣除中间节点

* **问题描述**：有一连串矩阵 $M_1 \times M_2 \times M_3 \times \dots \times M_n$，要求求出**不包含 $M_i$ 的矩阵连乘积**。
* **为什么不能做逆运算**：
1. 矩阵乘法**不满足交换律**（$A \times B \neq B \times A$），求逆矩阵不能乱插位置；
2. 矩阵可能不可逆（行列式 $\det(M) = 0$ 时根本不存在逆矩阵）。



### 破局解法：

* $pref[i] = M_1 \times M_2 \times \dots \times M_i$
* $suff[i] = M_i \times M_{i+1} \times \dots \times M_n$
* **扣除 $M_i$ 后的矩阵积**：

$$pref[i-1] \times suff[i+1]$$

## 3. 按位运算（Bitwise AND / OR）

### 经典场景：消除单点影响的位运算

* **问题描述**：给定数组 $A$，求删去 $a_i$ 后，剩下所有数的**按位与（AND）**或**按位或（OR）**。
* **为什么不能做逆运算**：
位运算会破坏信息。例如 $5 \mid 3 = 7$（二进制 `101 | 011 = 111`），你知道结果是 `111`，但如果你要把 `011`“撤销掉”，你根本不知道原来对应位上的 `1` 是来自 $5$ 还是来自 $3$。

### 破局解法：

* 扣除 $a_i$ 后的按位或结果：

$$\text{OR\_value} = pref\_or[i-1] \mid suff\_or[i+1]$$



---

## 4. 区间极值（$\max / \min$）

### 经典场景：删除某项后的次大值 / 最值变化

* **问题描述**：求删除 $a_i$ 后剩下的数组的最大值 $\max$。
* **为什么用前后缀**：
虽然这题可以通过“维护最大值和次大值”来做，但**前后缀拆分的代码优雅度极高**，完全不需要写复杂的分类讨论 `if (a[i] == max_val)`。
* **破局解法**：

$$\text{max\_except\_i} = \max(pref\_max[i-1], suff\_max[i+1])$$



---

## 📊 总结归纳表

| 运算符 $\oplus$ | 是否有逆运算 | 前后缀结合方式 | 典型题型 |
| --- | --- | --- | --- |
| **加法 / 减法** | ✅ 有（减法） | 实际上直接用全和减去 $a_i$ 即可 | 前缀和、差分 |
| **乘法 $\bmod M$** | ⚠️ 仅当互质时有 | $pref[i-1] \times suff[i+1] \pmod M$ | AtCoder V (Subtree) |
| **最大公约数 $\gcd$** | ❌ 无 | $\gcd(pref[i-1], suff[i+1])$ | 树上删点求 $\gcd$ / 删除单项最大 $\gcd$ |
| **矩阵乘法** | ❌ 普遍无 | $pref[i-1] \times suff[i+1]$ | 树上矩阵换根 DP |
| **位运算 $\text{AND}/\text{OR}$** | ❌ 无 | $pref[i-1] \text{ op } suff[i+1]$ | 消除干扰位 |
| **极值 $\max / \min$** | ❌ 无 | $\max(pref[i-1], suff[i+1])$ | 换根 DP 维护树高/长路径 |
