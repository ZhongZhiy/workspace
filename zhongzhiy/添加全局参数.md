### 全局异常处理器: `server -> handler -> ` 
添加 `@ExceptionHandler` 注解
当 Controller（控制器）层的方法在执行过程中抛出异常时，Spring 会自动寻找被 `@ExceptionHandler` 标记的方法，并将异常对象传递给该方法来处理，最后由该方法决定向客户端返回什么样的数据。

### **MyBatis**框架, 把 java 和 mysql 连接起来
#### `@Mapper` 注解



```java
@Mapper
public interface EmployeeMapper { ... }
```

- **作用**：告诉 Spring 和 MyBatis 框架：“这是一个数据库操作接口”。MyBatis 看到它后，会自动在后台生成这个接口的实现类，你不需要自己写实现类代码。

里面的方法: 例如

```java
/**  
 * 根据用户名查询员工  
 * @param username  
 * @return  
 */  
@Select("select * from employee where username = #{username}")  
Employee getByUsername(String username);
```
