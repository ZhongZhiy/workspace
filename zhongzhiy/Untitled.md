L你的这个痛点非常经典。在算法竞赛（Competitive Programming）中，频繁在浏览器、编辑器和在线表格之间来回切换，不仅消耗精力，还很容易打断思考的连贯性。

在 Emacs 中，解决这个问题的核心思路是：**将“复制样例、本地测试、提交、打卡记录”这些机械化的外部操作，全部内聚到 Emacs 内部闭环完成**。

通过组合两套效率工具，你可以将原有的繁琐步骤缩减到极致。

## 优化一：消灭复制样例与手动测试 —— 引入 `oj.el`

`online-judge-tools` 是算法竞赛界大名鼎鼎的命令行工具，而 Emacs 拥有它的优秀前端插件 `oj`。

### 🚀 带来的改变：

- **以前**：去网页找样例 -> 复制 -> 回编辑器建文件 -> 粘贴 -> 编译 -> 运行输入比对。
    
- **现在**：在 Emacs 中输入网址 -> **自动生成代码文件并下载所有样例** -> 写完代码一键比对所有测试点，甚至直接在 Emacs 里提交。
    

### 配置与使用方法：

1. **系统底层准备**（在终端安装 Python 工具支持）：
    
    Bash
    
    ```
    pip3 install online-judge-tools online-judge-template-generator selenium
    ```
    
2. **Emacs 配置**（下载并引入 `oj` 插件）：
    
    代码段
    
    ```
    (unless (package-installed-p 'oj)
      (package-install 'oj))
    ```
    
3. **丝滑新流程**：
    
    - **拉取题目**：按下 `M-x oj-prepare`，直接粘贴你想写的题目 URL（支持 Codeforces, AtCoder 等主流平台）。它会自动在本地为你建立好专门的目录，拉取所有标准输入输出样例，并生成好代码模板。
        
    - **一键测试**：代码写完后，不需要切换窗口，直接 `M-x oj-test`（或绑定快捷键）。Emacs 会自动调用编译器编译，并把所有下载好的样例全部跑一遍，在旁边清晰地显示哪些 AC、哪些 WA。
        
    - **一键提交**：测试全过之后，直接 `M-x oj-submit`，代码就交上去了，连网页都不用开。
        

## 优化二：消灭在线表格记录 —— 引入 `Org-mode` 时间钟

你完全不需要手动去网页表格敲“开始时间”和“结束时间”，Emacs 标志性的 `Org-mode` 自带的 **`Org-clock`（时间钟）** 功能就是为了这种精准时间统计而生的。

### 🚀 带来的改变：

- **以前**：看一眼表 -> 记下开始时间 -> 写完题 -> 再看一眼表 -> 算时间差 -> 填入网页表格。
    
- **现在**：创建任务 -> **一键秒表打卡** -> 写题 -> **一键落表停表**，所有时间与耗时自动精确生成。
    

### 操作演示：

在你的工作目录下建立一个 `cp_diary.org` 文件，专门用来管理你的刷题日志：

代码段

```
* TODO Codeforces 1900A - Halloumi Boxes
  :PROPERTIES:
  :Source:   Codeforces
  :Tags:     DP, Greedy
  :END:
```

- **开始做题时**：将光标放在这道题的标题上，按下快捷键 **`C-c C-x C-i`** (`org-clock-in`)。Emacs 会自动启动一个隐形秒表，并记录下这一刻的精准时间。
    
- **题目 AC 后**：回到这个文件，按下快捷键 **`C-c C-x C-o`** (`org-clock-out`)。秒表停止，Emacs 会自动在题目下方生成一条绝对精确的耗时记录：
    
    代码段
    
    ```
    :LOGBOOK:
    CLOCK: [2026-07-19 Sun 17:00]--[2026-07-19 Sun 17:35] =>  0:35
    :END:
    ```
    
- **自动生成周报/月报**：如果你想要汇总，只需在文件末尾插入一个 `#+BEGIN: clocktable` 标签，Emacs 会自动把所有题目的来源、日期、总耗时聚合渲染成一张极漂亮的本地表格，完全可以平替并超越在线表格。
    

## 优化三：减少换窗翻译 —— 引入 `gts` (go-translate)

如果读题时遇到生疏的英文算法术语，频繁切到网页翻译也很打断思路。可以安装 `gts` 插件，将选中的文本直接在 Emacs 的侧边栏或底部回显翻译结果，看完即走。

## 🎯 终极简化后的丝滑工作流

在使用平铺式窗口管理器（如左右分屏分好浏览器与 Emacs）的前提下，你的新流程是：

1. **看题**：在浏览器侧读题、思考。
    
2. **打卡**：在 Emacs 的 Org 文件里敲下题目，`C-c C-x C-i` 开启秒表。
    
3. **拉取**：`M-x oj-prepare` 粘贴链接，代码模板和样例秒速就绪。
    
4. **编码与测试**：写完 C++ 代码，一个快捷键触发 `oj-test` 自动测完所有样例。
    
5. **提交与收工**：`oj-submit` 提交代码，回到 Org 文件 `C-c C-x C-o` 停表记录。
    

除了最初读题那一眼，剩下的复制、测试、记录统计，全部在 Emacs 键盘流中闭环搞定。
