既然你已经找到了这些 `.cookie` 文件，要把它们集成到你的 `fortune-mod` 中其实非常简单。你只需要把这些文本文件“编译”成 `fortune` 能够识别的二进制索引文件即可。

以下是详细的操作步骤：

### 1. 检查文件格式

首先，确保这些 `.cookie` 文件的格式是正确的。`fortune` 要求每段语录之间必须用一个**单独占一行的百分号 `%`** 隔开。

你可以用 `head` 命令看一下：

Bash

```
head -n 20 你的文件名.cookie
```

如果每段话后面都有一个 `%`，那就没问题。

### 2. 生成索引文件 (`.dat`)

`fortune` 程序为了快速随机读取，需要一个对应的 `.dat` 文件。你需要使用 `strfile` 命令来生成它。

假设你有一个文件叫 `tang300.cookie`，在终端运行：

Bash

```
strfile tang300.cookie
```

执行完后，你会发现文件夹里多了一个 `tang300.cookie.dat` 文件。

### 3. 如何使用这些文件？

#### 方法 A：直接通过路径调用（最快测试）

你不需要移动文件，直接指定路径就能运行：

Bash

```
fortune ./tang300.cookie
```

#### 方法 B：放入系统目录（正式使用）

如果你想让它像原生命令一样工作（比如直接输入 `fortune tang300`），建议进行以下操作：

1. **重命名（可选）：** 习惯上我们会去掉 `.cookie` 后缀，让命令更简洁。
    
    Bash
    
    ```
    mv tang300.cookie tang300
    mv tang300.cookie.dat tang300.dat
    ```
    
2. **移动到系统路径：**
    
    Bash
    
    ```
    sudo cp tang300 tang300.dat /usr/share/fortune/
    ```
    
3. 使用：
    
    现在你可以直接输入：
    
    Bash
    
    ```
    fortune tang300 | cowsay | lolcat
    ```
    

---

### 4. 批量处理所有 .cookie 文件

如果你下载的仓库里有很多 `.cookie` 文件，一个个手动转太麻烦了。你可以用下面这个循环命令一次性搞定：

Bash

```
# 进入存放 .cookie 文件的目录
cd /path/to/your/cookie/files

# 批量生成 .dat 文件
for f in *.cookie; do strfile "$f"; done

# (可选) 批量移动到系统目录
sudo cp *.cookie *.dat /usr/share/fortune/
```

### 💡 特别提示：

- **关于中文乱码：** 如果你发现输出的中文是乱码，请确保 `.cookie` 文件是 **UTF-8** 编码。Arch Linux 默认使用 UTF-8，通常不会有问题。
    
- **多库随机：** 如果你把很多库都拷进了 `/usr/share/fortune/`，你可以让 `fortune` 在所有库里随机抽取：
    
    Bash
    
    ```
    fortune  # 默认在所有库随机抽
    ```
    
    或者查看每个库的占比：
    
    Bash
    
    ```
    fortune -f
    ```
