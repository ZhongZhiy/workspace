```cpp
struct Point{
    int x, y;
    //重载加法, 返回 Point
    Point operator + (const& Point other)const{
        return {x + other.x , y + other.y};
    }
    
    //重载=
    bool operator = (const& Point other) const{
        return x = other.x && y = other.y;
    }
    
    //重载<< 返回 ostream&
    friend ostream& operator << (ostream& os, const Point& p){
        os << "("  << p.x << ", " << p.y << ")";
        return os;
    }
}
```

## [Exceptional Segments](https://codeforces.com/contest/2225/problem/D)
  给定两个整数 $n$ 和 $x$。

考虑序列 $[1, 2, 3, \dots, n]$。你需要求出其中包含 $x$ 且异或和为 $0$ 的子段数量。换句话说，你需要统计满足 $1 \le l \le x \le r \le n$ 且 $l \oplus (l+1) \oplus \dots \oplus r = 0$ 的数对 $(l, r)$ 的个数，其中 $\oplus$ 表示按位异或。

例如，如果 $n = 7$ 且 $x = 6$，那么下面这些区间是合法的：

-   $(4, 7)$，因为 $x$ 在该区间内，且 $4 \oplus 5 \oplus 6 \oplus 7 = 0$；
-   $(1, 7)$，因为 $x$ 在该区间内，且 $1 \oplus 2 \oplus 3 \oplus 4 \oplus 5 \oplus 6 \oplus 7 = 0$。

由于答案可能非常大，请输出对 $998\\,244\\,353$ 取模后的结果。

**输入**

每个测试包含多个测试用例。第一行包含测试用例数量 $t$ ($1 \le t \le 2 \cdot 10^5$)。接下来是测试用例的描述。

每个测试用例的唯一一行包含两个整数 $n$ 和 $x$ ($1 \le x \le n \le 10^{18}$)。

---
由于数字很大, 所以不能直接前缀和, 
注意到这个规律, 前缀异或和`pref[i]`：
$$
pref_i = i , if i % 4 = 0
$$

$$
pref_i = 1, if i % 4 = 1
$$

$$ 
pref_i = i + 1, if i % 4 = i + 1
$$

$$ 
pref_i = 0, if i % 4 = 3
$$

所以只要统计 `x` 左边和右边的`perf[i] = 1 or 0` 的个数就可以了

值得注意的是怎么计算个数
如果是一个余`r` 的数列, $ a + r, 2*a + r, 3 * a + r, 4 * a + r ... m * a + r $
那么计算前 $n$ 个数里模 4 余 3 的数的个数就是计算这个等差数列有多少个数, 计算 $a$ 的系数, 直接减去余数, 除以 $ a $ 就可以了, 即 $ (n - 3) / 4$

```cpp
#include<bits/stdc++.h>

using namespace std;

#define int long long

const int MOD = 998'244'353;

int get0(int x){
    return 1ll + (x >= 3 ? (x - 3) / 4 + 1 : 0);
}

int get1(int x){
    return (x >= 1 ? (x - 1) / 4 + 1 : 0);
}

void solve(){
	int n, x;
	cin >> n >> x;

    int l0 = get0(x - 1) % MOD;
    int r0 = (get0(n) - l0) % MOD;
	int ans = l0 * r0;

    int l1 = get1(x - 1) % MOD;
    int r1 = (get1(n) - l1) % MOD;
	ans += l1 * r1;
    ans %= MOD;

    cout << ans << '\n';
}
```

## 求[最大子数组的和](https://www.luogu.com.cn/problem/P1115)?
**方法一**: 动态规划
`cur_mx[i]`是以`a[i]`结尾的最大子数组和, 那么对于第`i`个数,
如果`cur_mx[i-1] > 0` 那么 `cur_mx[i] = cur_mx[i-1] + a[i]`
否则`cur_mx[i] = a[i]`
再维护一个全局最大值`mx = max(mx, cur_mx[i])`

**方法二** : 
`pref[i]`是以第`i`个数结尾的最大值, `suf[i]`是以 第`i`个数起始的最大值
那么最大区间和就是`mx = pref[i] + suf[i] - a[i]`

## [NO-Subsequence substring](https://atcoder.jp/contests/abc452/tasks/abc452_d)

**问题描述**

给定由小写英文字母组成的字符串 $S$ 和 $T$。

在 $S$ 的所有非空子串 $s$ 中，统计那些**不**包含 $T$ 作为一个（不一定连续的）子序列的子串数量。

这里，若 $S$ 的两个子串来自不同的位置，则视为不同，即使它们作为字符串相同。

什么是子串？字符串 $X$ 的一个子串是通过从 $X$ 的开头删除零个或多个字符、并从 $X$ 的结尾删除零个或多个字符后得到的字符串。什么是子序列？字符串 $X$ 的一个子序列是通过从 $X$ 中删除零个或多个元素，并保持剩余元素原有顺序后得到的字符串。


**约束条件**

-   $S$ 是一个由小写英文字母组成的字符串。
-   $1\le |S|\le2\times10 ^ 5$，其中 $|S|$ 表示 $S$ 的长度。
-   $T$ 是一个由小写英文字母组成的字符串。
-   $1\le |T|\le50$，其中 $|T|$ 表示 $T$ 的长度。

---

对于 $S$ 中的每一个可能的起始位置 $L$，我们要找到最小的结束位置 $R$，使得子串 $S[L \dots R]$ 能够包含 $T$ 作为子序列。

一旦我们找到了这个最小的 $R$，那么所有以 $L$ 开头、以 $k \ge R$ 结尾的子串（即 $S[L \dots R], S[L \dots R+1], \dots, S[L \dots |S|-1]$）都必然包含 $T$ 作为子序列。

**包含 $T$ 的子串总数 = $\sum_{L=0}^{|S|-1} (|S| - R_L)$**
*(其中 $R_L$ 是使得 $S[L \dots R_L]$ 包含 $T$ 的最小右端点；若不存在则贡献为 0)*


**算法步骤**

1. 第一步：预处理字符位置（序列自动机思想）
为了快速跳转到下一个字符，我们需要预处理一个数组 `next_pos[i][char]`，表示在 $S$ 中，从下标 $i$ 开始（包含 $i$），字符 `char` 第一次出现的位置。

* **实现**：从右往左遍历 $S$，记录每个字母最后出现的位置。
* **复杂度**：$O(26 \times |S|)$。

2. 第二步：遍历起始点 $L$
对于每一个 $L \in [0, |S|-1]$：
1.  从 $L$ 开始，在 $S$ 中贪心地寻找 $T$ 的第一个字符、第二个字符……直到找完 $T$ 的所有字符。
2.  借助 `next_pos` 数组，我们可以快速完成这个过程。
3.  如果找到了最后一个字符，记其位置为 $R$，则该 $L$ 贡献的包含 $T$ 的子串数量为 $|S| - R$。

```cpp
void solve(){
    string s, t; cin >> s >> t;
    int lens = s.size(), lent = t.size();
    vector<vector<int>> nex_pos(26, vector<int>(lens + 1, lens));

    for(int c = 0;c < 26; ++c){
        for(int i = lens - 1; i >= 0; --i){
            nex_pos[c][i] = nex_pos[c][i+1];
            if(s[i] = c + 'a') nex_pos[c][i] = i;
        }
    }

    int ans = lens * (lens + 1) / 2;

    for(int i = 0;i < lens; ++i){
        int cur = nex_pos[t[0]-'a'][i];
        bool nof = (cur = lens);

        for(int j = 0;j < lent - 1; ++j){
            if(cur >= lens){
                nof = 1;
                break;
            }
            //注意nex_pos[t[j+1]-'a'][cur] 是再cur这个位置上找, 也就是包括了cur, 而找, 需要从下一个地方找, 也就是cur + 1
            cur = nex_pos[t[j+1]-'a'][cur+1]; 
            if(cur >= lens){
                nof = 1;
                break;
            }
        }
        if(!nof){
            ans -= (lens - cur);
        }
    }
    cout << ans << endl;
}
```

## [You WILL Like Sigma Problem](https://atcoder.jp/contests/abc452/tasks/abc452_e)
**问题陈述**


给定一个长度为 $N$ 的正整数序列 $A = (A &#95; 1, \cdots, A &#95; N)$ 和一个长度为 $M$ 的正整数序列 $B = (B &#95; 1, \cdots, B &#95; M)$。

求 $\displaystyle \sum &#95; {i=1}^{N} \sum &#95; {j=1}^{M} A &#95; i \cdot B &#95; j \cdot (i \bmod j)$ 的值，对 $998244353$ 取模。

**约束条件**

-   $1 \leq N,M \leq 5 \times 10^5$
-   $1 \leq A_i, B_j \leq 5 \times 10^5$
-   所有输入值均为整数。

---
又是处理 $i \bmod j$, 需要转换为 $i \bmod j = i - i/j * j$
设 $ k = i \bmod j$, 
这道题的核心在于对取模运算 $(i \bmod j)$ 进行拆解，并利用**调和级数**的复杂度特性进行优化。

**核心思路**

首先，利用取模运算的定义：$i \bmod j = i - j \cdot \lfloor \frac{i}{j} \rfloor$。
我们将原式展开：

$$\sum_{i=1}^{N} \sum_{j=1}^{M} A_i \cdot B_j \cdot (i - j \lfloor \frac{i}{j} \rfloor)$$

通过分配律，将求和拆分为两部分：

1.  **第一部分（常数项）：**
    $$\left( \sum_{i=1}^{N} A_i \cdot i \right) \cdot \left( \sum_{j=1}^{M} B_j \right)$$
    这一部分非常简单，分别算出两个序列的和相乘即可。

2.  **第二部分（涉及向下取整）：**
    $$\sum_{i=1}^{N} \sum_{j=1}^{M} A_i \cdot (B_j \cdot j) \cdot \lfloor \frac{i}{j} \rfloor$$
    我们交换求和顺序，先对 $j$ 进行枚举：
    $$\sum_{j=1}^{M} (B_j \cdot j) \sum_{i=1}^{N} A_i \cdot \lfloor \frac{i}{j} \rfloor$$


**优化技巧：分段加速**

对于固定的 $j$，$\lfloor \frac{i}{j} \rfloor$ 的值在一段连续的 $i$ 区间内是相同的：
* 当 $i \in [j, 2j-1]$ 时，$\lfloor \frac{i}{j} \rfloor = 1$
* 当 $i \in [2j, 3j-1]$ 时，$\lfloor \frac{i}{j} \rfloor = 2$
* 一般地，当 $i \in [kj, (k+1)j-1]$ 时，$\lfloor \frac{i}{j} \rfloor = k$

因此，我们可以预计算 $A$ 的**前缀和** $SumA$，那么对于每一个 $j$，内部对 $i$ 的求和可以写成：
$$\sum_{k=1}^{\lfloor N/j \rfloor} k \cdot (SumA[\min(N, (k+1)j-1)] - SumA[kj-1])$$

**复杂度分析**
总复杂度由 $j$ 的循环和内部 $k$ 的循环决定，其次数为：
$$\sum_{j=1}^{M} \frac{N}{j} = N \sum_{j=1}^{M} \frac{1}{j} \approx O(N \log M)$$
当 $N, M = 2 \times 10^5$ 时，计算量约为 $2.4 \times 10^6$，在 2 秒的时间限制内非常充裕。

```cpp
void solve(){
    constexpr int M = 998244353;
    int n, m; cin >> n >> m;
    vi a(n + 1), b(m + 1);
    fi(n) cin >> a[i];
    fi(m) cin >> b[i];
    //i * a[i],  sum a[i], sum b[i]
    vi ia(n + 1), sa(n + 1), sb(m + 1);
    fi(n) ia[i] = (ia[i-1] + i*a[i])% M;
    fi(n) sa[i] = (sa[i-1] + a[i]) % M;
    fi(m) sb[i] = (sb[i-1] + b[i]) % M;

    int sum1 = (ia[n] * sb[m]) % M;
    int sum2 = 0;
    //通过固定j和k来处理
    for(int j = 1;j <= m; ++j){
        for(int k = 1;k <= n / j; ++k){
            int l = j * k, r = min(j * (k + 1)-1, n);
            sum2 += b[j] * j %M * k % M * (sa[r] - sa[l-1] + M) % M; sum2 %= M;
        }
    }
    cout << (sum1 - sum2 + M )% M;
}
```
