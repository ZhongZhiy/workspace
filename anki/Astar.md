## A* 算法中估价函数 $f(x) = g(x) + h(x)$ 的各项含义是什么？
$g(x)$ 是从起点到当前状态的实际代价；$h(x)$ 是从当前状态到目标的估计代价。

## 在求解 $k$ 短路问题时，A* 算法的 $h(x)$ 通常设为 {{c1::从节点 $x$ 到终点 $t$ 的最短路径长度}}。



## 为了预处理出所有结点的 $h(x)$ 值，应该采取什么操作？
在反向图上以终点 $t$ 为起点运行一遍单源最短路算法（如 Dijkstra）。

## A* 求解 $k$ 短路时，优先队列中存储的状态通常包含哪两个核心信息？
当前到达的结点 $x$ 和已经走过的实际距离 $g(x)$。

## 优先队列在取出状态时，是按照哪个值的从小到大顺序排序的？
$f(x) = g(x) + h(x)$ （即实际代价加上估计剩余代价的总和）。

## 判定 $k$ 短路成功的标准：当目标结点 $t$ 第 {{c1::k}} 次被从优先队列中 {{c2::弹出 (pop)}} 时，对应的 $g(t)$ 即为所求。

## A* 求解 $k$ 短路的一个重要优化：当一个结点已经被取出超过 {{c1::k}} 次时，不再扩展其子状态。

## 为什么当取出次数大于 $k$ 时可以停止扩展？
因为前 $k$ 次取出已经涵盖了所有可能构成前 $k$ 短路径的情况，后续取出的状态必然不会对前 $k$ 短路产生贡献。

## A* 算法在 $k$ 短路问题中的最坏时间复杂度（如 $n$ 元环形态）是多少？
$O(nk \log n)$

## 代码逻辑填空：在反向图预处理 $H[x]$（最短路）时，使用的优先队列排序准则是？

struct node2 {

## 代码逻辑填空：在 A* 搜索过程中，优先队列的排序准则是？

```cpp
struct node {
    int x, v; // v 是 g(x)
    bool operator<(node a) const { 
        return {{c1::v + H[x] > a.v + H[a.x]}}; // 按 f(x) 值从小到大排序
    }
};

```

## 如果在优先队列为空时仍未访问到终点 t 共 k 次，说明了什么？
起点 s 到终点 t 之间的路径总数不足 k 条。
