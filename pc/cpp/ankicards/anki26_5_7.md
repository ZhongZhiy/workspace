
# work

## [pacman] 更新本地数据库, 拉取最新高列表
`pacman -Sy` Sync yes refresh

## [pacman] 搜索远程仓库的软件
`pacman -Ss` Sync + search

## [pacman] 只下载不安装
`pacman -Sw <pkg>` Sync + download(w)

## [pacman] 递归删除, 把不再被依赖的包都删除
`pacman -Rs <pkg>` Remove + secursive

## [pacman] 彻底删除, 连带依赖和配置文件
`pacman -Rns <pkg> ` Remove + nosave + secursive

## [pacman] 查询本地软件把文件都装到哪里了
`pacman -Ql <pkg>` query + list

## [pacman] 查询本地软件的详细情况, 安装时间, 大小, 等详细情况
`pacman -Qi <pkg>`

## [pacman] 删除所有孤立包
`pacman -Rns $(pacman -Qdtq)`
