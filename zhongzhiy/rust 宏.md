既然你想深入掌握 Rust 的**宏（Macro）语法**，那我们就把所有面纱揭开，彻底搞懂它。

Rust 的宏可以分成两大类：

1. **声明宏（Declarative Macros）**：也就是我们一直在用的 `macro_rules!`。它像“模式匹配（`match`）”一样工作，属于**代码片段的替换**。
    
2. **过程宏（Procedural Macros）**：类似于编译器插件，直接接收并操作 AST（抽象语法树）。（算法竞赛用不到，今天我们专注于**声明宏**）。
    

### 1. 声明宏的完整语法骨架

Rust

```
macro_rules! 宏名字 {
    ( 匹配模式 1 ) => { 展开后的代码块 1 };
    ( 匹配模式 2 ) => { 展开后的代码块 2 };
}
```

- **外层符号自由**：调用或定义时，大括号 `{}`、圆括号 `()`、方括号 `[]` 是可以**互换**的。比如 `vec![1, 2]` 和 `vec!(1, 2)`、`vec!{1, 2}` 没区别，只是约定俗成数组用 `[]`，逻辑代码块用 `{}`。
    

### 2. 核心：元变量与指示符（片段匹配）

宏的输入不是普通的变量，而是代码片段。我们用 **`$名字:指示符`** 来捕捉这些片段。

以下是算法竞赛和日常开发最常用的**指示符（Designators）大百科**：

| **指示符**     | **代表什么成分**                           | **竞赛经典用途举例** |
| ----------- | ------------------------------------ | ------------ |
| **`expr`**  | 表达式（能算出一个值的，如 `a + 5`, `10`, `f(x)`） | 计算、传值、核心逻辑替换 |
| **`ty`**    | 数据类型（如 `i32`, `Vec<usize>`, `&str`）  | 泛型别名、快捷定义类型  |
| **`ident`** | 标识符（变量名、函数名、结构体名）                    | 动态生成新变量、函数   |
| **`stmt`**  | 单条语句（通常以分号结尾，如 `let x = 5;`）         | 批量执行初始化代码    |
| **`block`** | 代码块（用 `{}` 包裹的多行代码）                  | 注入整段复杂逻辑     |
| **`path`**  | 完整路径（如 `std::collections::HashMap`）  | 引用深层标准库      |

#### 举个例子：组合使用的威力

Rust

```
macro_rules! create_var {
    // 匹配一个标识符（变量名）和一个数据类型
    ($name:ident, $t:ty) => {
        let mut $name: $t = Default::default();
    };
}

fn main() {
    create_var!(my_array, Vec<i32>); 
    // 编译时被替换为：let mut my_array: Vec<i32> = Default::default();
}
```

### 3. 灵魂语法：重复匹配（宏的循环）

这是宏最强大的地方，能让你处理**任意数量**的参数（像 `println!` 那样传入无数个变量）。

语法格式：**`$( 匹配规则 ) 分隔符 计数符`**

- **分隔符**：常见的是逗号 `,` 或分号 `;`。
    
- **计数符**：
    
    - `*`：代表出现 **0 次或多次**。
        
    - `+`：代表出现 **1 次或多次**。
        

#### 拆解：多变量赋值宏

你想写一个宏，一行代码同时给多个变量赋值：`assign!(a = 1, b = 2, c = 3);`

Rust

```
macro_rules! assign {
    // 匹配模式拆解：
    // $( ... ),* --> 整体由逗号隔开，重复多次
    // $id:ident = $val:expr --> 内部长成 "变量名 = 表达式" 的样子
    ( $($id:ident = $val:expr),* ) => {
        $(
            $id = $val; // 展开代码：针对每一个匹配到的组合，生成这行代码
        )*
    };
}

fn main() {
    let (mut a, mut b, mut c) = (0, 0, 0);
    assign!(a = 10, b = 20, c = 30); // 一步到位
}
```

### 4. 什么是“高级卫生宏（Hygiene）”？

在 C++ 中，如果你写 `#define P(x) int t = x;`，而在 `main` 里面刚好也有一个变量叫 `int t`，这两个 `t` 就会撞车（命名空间污染），引发极其隐蔽的 Bug。

**Rust 的宏是完全“卫生”的。** * 在宏内部定义的本地变量，在外部是**完全不可见**的。

- 在宏外部的变量，除非你显式地通过 `$id:ident` 把它当作参数传进宏里，否则宏内部也**无权访问**。
    

这保证了宏的安全，也意味着你无法在宏里暗度陈仓地去修改外面不相关的变量。

### 5. 宏的调试黑科技：`cargo expand`

由于宏是编译前替换的，有时候报错很难看懂。你想知道宏展开后到底长什么样，可以在电脑终端安装一个神器：

Bash

```
cargo install cargo-expand
```

然后在项目根目录下运行 `cargo expand`，它会把你整个 Rust 文件里所有的宏**全部展开成最原始的白话文代码**显示出来，是 debug 宏的终极武器！

### 总结

掌握 Rust 声明宏只需要盯紧三件事：

1. **长相匹配**：括号里定义好形状。
    
2. **成分通配**：用 `:expr`、`:ident` 规定代码成分。
    
3. **复制粘贴**：用 `$(...)*` 搞定重复。
