

## [小红的最佳区间](https://ac.nowcoder.com/acm/contest/134529/D)
小红有 n 个闭区间，第 i 个区间为 $\[l_i,r_i\]$。  
她现在想另外选择一个闭区间 $\[L,L+k\]$，其中 L 可以是任意整数。如果两个区间的交集非空，那么称它们相交。

特别地，如果两个区间只有端点重合，我们也认为它们的交集非空。例如 $\[1,3\] 和 \[3,5\]$ 相交。

注意，小红选的区间不要求等于给定的 n 个区间中的某一个，它只需要长度恰好为 k 即可。

请你求出，最多有多少个给定区间能够与她选择的区间 $\[L,L+k\]$ 相交。

$(1 \le n \le 2 \times 10^5, 0 \le k \le 10^9, 0 \le l_i \le r_i \le 10^9)$

---
思路: 
这个求区间与区间的交集, 可以转换为点值与区间的交集个数:
如果 $\[L, L+k\], \[L_i, R_i \]$, 有交集, 那么:
$L \le R_i \and L+k \ge L_i \Rightarrow L_i - k \le L \le R_i$
这样就转换成了: 如果一些区间 $\[L_i - k, R_i\]$, 找一个点 $L$, 在 $L$ 值处区间重叠最多

现在找重叠区间, 因为 $L_i$ 的值太大了, 所以不可能用差分和前缀和, 应该使用 **扫描线**, 处理 **关键点**:
维护一个当前重叠值`cur`, 便利 $\{L_i - k, R_i}$, 点集, 遇到$L_i - k$ 就 $+1$ , 遇到 $R_i$ 就 $-1$
统计统计最大值

```cpp
void solve(){
    int n, k; cin >> n >> k;
    vector<pii> v(n * 2);
    fi0(n){
        int l, r; cin >> l >> r;
        v[i*2] = {l-k, 1}; //转换, 打标记 start 为 1, end 为0
        v[i*2+1] = {r, -1};
    }
    sort(all(v), [](const pii& a, const pii& b) {  //排序, 值相同, start 优先
        if(a.first != b.first) return a.F < b.F;
        return a.S > b.S;
    });

    int mx = 0, cur = 0, i = 0;

    while(i < 2 * n){
        int pos = v[i].F;  //当前位置, 处理在这个位置的所以关键点
        while(i < 2 * n && v[i].F = pos && v[i].S == 1) cur++, i++;  //如果当前位置有start, 就++
        mx = max(cur, mx);  
        while(i < 2 * n && v[i].F = pos && v[i].S == -1) cur--, i++;  //要离开当前位置了, 更新当前位置的end
    }
    cout << mx << endl;
}
```

  ## [01](https://acm.hdu.edu.cn/contest/problem?cid=1203&pid=1011)
定一个 01 串 s，字符串长度为 n，给定 k，每次操作可以指定 i，然后将 $i,(i+k) \bmod n$ 两个位置的值反转，询问是否能通过若干次操作使得这个串是一个回文串。 备注：kk 不能为 00。$(2 \le \sum n \le 2e6, 1 \le k \less n)$
---
在一个数组长为 $n$ 向右移动 $k$ 步长, 会形成一个环 $( i \equiv j \bmod gcd(n, k))$
令 $d = gcd(n, k)$
那么考虑 $i$ 在环 $p$中, 那么其对应回文 $n - i - 1 \bmod d \Rightarrow n - 1 - (i \bmod d) = n - 1 - (j \bmod d)$, 因为 $(i \equiv j \bmod d)$, 令 $n - 1 - i$ 在环 $p'$ 中, 说明环 $p$ 的所以回文对应字符都在 $p'$ 

在环 $p$ 中, 1的奇偶性是一定的, 那么如果 环$p$ 和环 $p'$ 中1 的个数一致, 那么就可以转换为回文, 
如果 环$p'$ 就是 环$p$, 那么就考虑, 如果环 $p$ 的个数是偶数, 那么1的个数是奇数, 那么, 怎么变化都不能形成回文

```cpp
void solve() {
    int n, k;
    if (!(cin >> n >> k)) return;
    string s;
    cin >> s;

    int d = gcd(n, k);

    // 1. 统计每个环（共 d 个环）中 '1' 的个数奇偶性
    // 环的编号由 i % d 决定
    vector<int> p(d, 0);
    for (int i = 0; i < n; ++i) {
        if (s[i] = '1') {
            p[i % d] ^= 1; // 使用异或处理奇偶性
        }
    }

    // 2. 检查回文约束
    bool ok = true;
    for (int j = 0; j < d; ++j) {
        // 环 j 在回文对称后的镜像环编号
        int r = (n - 1 - j) % d;
        if (r < 0) r += d; // 确保正数余数

        if (j < r) {
            // 如果是两个不同的环互为镜像，它们的奇偶性必须一致
            if (p[j] != p[r]) {
                ok = false;
                break;
            }
        } else if (j = r) {
            // 如果环是自镜像的
            // 当 n 为偶数时，自镜像环内的元素必然成对，总和必为偶数
            if (n % 2 = 0 && p[j] != 0) {
                ok = false;
                break;
            }
            // 当 n 为奇数时，中间点可以调节奇偶性，无限制
        }
    }

    if (ok) cout << "YES" << endl;
    else cout << "NO" << endl;
}
```

## [星际走私客的跃迁网络](https://cpc.csgrandeur.cn/csgoj/problemset/problem?pid=1511)
去除掉“量子跃迁”、“星系”、“走私客”这些文学外衣，这道题的**纯算法定义**如下：

1. 基础模型

* **给定一个加权有向图**：包含 $N$ 个节点，节点编号 $1 \sim N$。
* **节点点权**：每个节点 $i$ 都有一个互不相同的点权 $A_i$。
* **边权矩阵**：给定一个邻接矩阵 $W_{i,j}$，表示节点 $i$ 到节点 $j$ 的直接边权。若不可达则为 $\infty$。

 2. 定义“单次合法路径（跳跃）”

定义从节点 $u$ 到节点 $v$ 的一次“单次合法路径”为：

* 在原图中从 $u$ 到 $v$ 的一条路径。
* **核心约束**：该路径上除了起点 $u$ 和终点 $v$ 之外，所有的中间节点 $x$，其点权必须满足：$A_x < \min(A_u, A_v)$。
* **代价计算**：该“跳跃”的代价定义为满足上述约束的所有路径中，边权之和的**最小值**。

3. 核心任务

* **总目标**：给定起点 $S$、终点 $T$ 和常数 $K$。
* **路径构造**：你需要构造一条由**恰好 $K$ 段**“单次合法路径”首尾相连而成的总路径。
* **最小化**：求解这 $K$ 段路径的代价总和的最小值。

---

 4. 抽象后的算法流程

这道题本质上是分两步走的最短路问题：

* **第一阶段：构建新图（预处理）**
利用 **Floyd-Warshall** 算法的思想。将节点按 $A_i$ 从小到大排序。当处理到第 $k$ 个节点时，它能作为中间点去更新那些 $A$ 值比它大的节点对之间的最短距离。由此计算出任意两点 $(u, v)$ 之间符合约束的“单次跳跃”最小代价 $D_{u,v}$。
* **第二阶段：计算恰好 $K$ 步最短路（求解）**
基于第一阶段得到的新图（矩阵 $D$），计算其在 **$(\min, +)$ 代数系统**下的 **$K$ 次幂**。
* 即矩阵乘法定义改为：$C_{i,j} = \min_{1 \le k \le N} (A_{i,k} + B_{k,j})$。
* 利用**矩阵快速幂**在 $O(N^3 \log K)$ 时间内求出矩阵 $D^K$。
5. 最终输出

针对 $Q$ 次询问 $(S, T)$，直接输出矩阵 $D^K$ 中第 $S$ 行第 $T$ 列的数值。若数值为 $\infty$，则输出 $-1$。

```cpp
constexpr int N = 155, INF = 0x3f3f3f3f3f3ff3f;
int mn[N][N], cur[N][N], w[N][N];

struct Mat{
    int sz;
    vector<vi> x;
    Mat(){}
    Mat(int sz):sz(sz), x(vector<vi>(sz+1, vi(sz+1))){}
    Mat operator * (const Mat &a) {
        Mat res(a.sz);
        fi(a.sz)fj(a.sz) res.x[i][j] = INF;

        for(int k = 1;k <= a.sz; ++k){
            for(int i = 1;i <= a.sz; ++i){
                if(x[i][k] = INF) continue;
                for(int j = 1;j <= a.sz; ++j){
                    if(a.x[k][j] = INF) continue;
                    res.x[i][j] = min(res.x[i][j], x[i][k] + a.x[k][j]);
                }
            }
        }

        return res;
    }
};

int n, k;
void solve(){
    cin >> n >> k;
    vector<pii> a(n + 1);
    fi(n){
        cin >> a[i].S;
        a[i].F = i;
    }

    sort(a.begin()+1, a.end(), [](const pii &a, const pii &b)->bool {
        return a.S < b.S;
    });

    vi rank(n + 1);
    fi(n) rank[a[i].F] = i;

    fi(n)fj(n){
        cin >> w[i][j];
        if(w[i][j] = -1) w[i][j] = INF;
        cur[i][j] = w[i][j];
        mn[i][j] = INF;
    }

   for(int h = 1;h <= n; ++h){
       int mid = a[h].F;

       for(int i = 1;i <= n; ++i){
           for(int j = 1;j <= n; ++j){
               if(i != j && min(rank[i], rank[j]) = h)
                   mn[i][j] = cur[i][j];
           }
       }
       for(int i = 1;i <= n; ++i){
           if(cur[i][mid] = INF) continue;
           for(int j = 1;j <= n; ++j){
               if(cur[mid][j] = INF) continue;
               cur[i][j] = min(cur[i][j], cur[i][mid]+cur[mid][j]);
           }
       }
   }

   Mat res(n);
   fi(n)fj(n) res.x[i][j] = (i != j ? INF : 0);
   Mat base(n);
   fi(n)fj(n) base.x[i][j] = mn[i][j];

   while(k){
       if(k & 1) res = res * base;
       base = base * base;
       k >>= 1;
   }

   int q; cin >> q;
   fi(q){
       int s, t; cin >> s >> t;
       int ans = res.x[s][t];
       if(ans >= INF) cout << -1 << endl;
       else cout << ans << endl;
   }
}
```

## 倍增处理 lca问题的代码, 预处理和查询

```cpp

//预处理lca, 算每个节点的deep, 和倍增祖先, 记录深度
void initlca(int x){
    for(int i = 0;i < 20-1; ++i) fa[x][i+1] = fa[fa[x][i]][i]; 
    for(auto &c : e[x]){
        if(c = fa[x][0]) continue;
        dep[c] = dep[x]+1;
        fa[c][0] = x;
        initlca(c);
    }
}

int lca(int x, int y){
    if(dep[x] < dep[y]) swap(x, y);  //让x更深
    //让x和y到达同层
    for(int d = dep[x] - dep[y], i = 0;d; d >>= 1, i++){
        if(d&1) x = fa[x][i];
    }
    if(x = y) return x; 
    //不断上跳
    for(int i = 19; i >= 0; --i){
        if(fa[x][i] != fa[y][i]) x = fa[x][i], y = fa[y][i];
    }
    return fa[x][0];
}
```

## [测试玻璃](https://cpc.csgrandeur.cn/csgoj/problemset/problem?pid=1512)
你需要在一栋有 n 层楼的高楼进行测试。因为玻璃未能实现量产，只有 m 块玻璃供你测试，但能保证所有的玻璃的硬度都是相同的。

你需要通过往下扔玻璃的方式来测试。换句话说，你可以进行以下查询：

>    选择一个整数 f ，如果玻璃从 f 层扔下碎了，交互器将回答 1, 否则将回答 0。

已进行的测试不会影响玻璃的硬度，但碎了的玻璃无法继续使用。

玻璃的硬度为 h 当且仅当满足以下条件:

    玻璃从 h 层及以下扔下不会碎。

    玻璃从 h+1 层及以上扔下碎了。

此外，玻璃在第 n+1 层及以上扔下必碎，也就是说，玻璃的硬度 h 满足 $0≤h≤n$ 。

由于时间有限，你需要在有限次数内测出玻璃的硬度。

---

理解这道题的思路，我们需要经历一次“思维反转”。这道题之所以难，是因为如果我们顺着想（“怎么测最少”），会陷入死胡同。

下面我用大白话，把这个精妙的思路拆解为 4 个思考层级：

 层级一：直觉与痛点（为什么不能无脑二分？）

假设有 100 层楼：

1. **如果玻璃无限多**：我们肯定无脑选中间层（第 50 层）扔。碎了去下半区，没碎去上半区。这就是经典的**二分查找**，最多 7 次搞定。
2. **如果只有 1 块玻璃**：你敢选第 50 层吗？不敢。万一碎了，剩下 49 层你没玻璃了，彻底没法测。你只能**老老实实从第 1 层开始一层层往上试**，最坏要测 100 次。

**痛点来了**：玻璃的数量，决定了你“敢不敢迈大步子”。玻璃越多，步子可以迈得越大（越接近二分）；玻璃越少，步子只能迈得很小（越接近线性扫描）。


层级二：核心思想 —— 逆向思维（把“求次数”变成“求能测多少层”）

正面算“最少需要几次”非常复杂。数学家们想出了一个绝妙的逆向定义：
我不问你需要几次，我问你：**如果只给你 $k$ 次扔的机会，和 $m$ 块玻璃，你最多能“罩得住”多少层楼？**

我们把这个“能罩得住的最大楼层数”定义为能力值：`f(k, m)`。

现在想象你站在一栋未知高度的大楼前，手里有 $k$ 次机会和 $m$ 块玻璃。你要挑一层楼 $x$ 扔下去，结果无非两种：

1. **💥 碎了**：
* 代价：你损失了 1 块玻璃，消耗了 1 次机会。
* 剩余资产：你还剩 $k-1$ 次机会，$m-1$ 块玻璃。
* 结论：你剩下的资产，**最多只能帮你测出下方的 `f(k-1, m-1)` 层楼**。所以，为了保证不翻车，你在选 $x$ 的时候，它的下方绝对不能超过 `f(k-1, m-1)` 层！


2. **✅ 没碎**：
* 代价：玻璃没少，只消耗了 1 次机会。
* 剩余资产：你还剩 $k-1$ 次机会，$m$ 块玻璃。
* 结论：你剩下的资产，可以继续去测上方的 `f(k-1, m)` 层楼。



**终极等式诞生**：
你一共能测的最大楼层数 = **碎了能测的下半区楼层** + **当前这 1 层** + **没碎能测的上半区楼层**
即：`f(k, m) = f(k-1, m-1) + 1 + f(k-1, m)`


层级三：如何确定扔哪一层？（交互策略）

有了上面的理论，我们在实际交互测试时该怎么做？

假设当前我们要测的区间是 `[L, R]`，我们有 $k$ 次机会，$m$ 块玻璃。
**你下一步该去哪一层扔？** 答案是：**必须把剩下的机会利用到极致！**

既然你碎了之后，手里剩下的牌（$k-1$ 次， $m-1$ 块）最多只能测 `f(k-1, m-1)` 层，那我们就**卡着这个极限**去选楼层。
你要测试的楼层 $x$ 就是：
**$x = L + f(k-1, m-1)$**

* **如果碎了**：答案一定在 `[L, x-1]`，这个区间正好有 `f(k-1, m-1)` 层，你手里的牌刚好能把它测完！
* **如果没碎**：答案一定在 `[x+1, R]`，你失去了一次机会但玻璃没少，正好用剩下的牌测上半区。

这就是为什么代码里有一句核心逻辑：`long long x = min(R, L + get_f(k - 1, m - 1));`
（取 min 是因为有时候你算出来的跨度已经超出了实际上界的 R，那就直接测 R 就行了）。


层级四：优化细节（玻璃真的需要很多吗？）

题目里说 $n$ 高达 $10^{18}$，$m$ 有 $2 \cdot 10^5$。
但你想想，如果每次都让你二分（也就是玻璃无限的情况），测 $10^{18}$ 层楼需要多少次？
$2^{60} > 10^{18}$。这意味着，你最多只需要扔 60 次！
既然最多扔 60 次，那你手里拿 61 块玻璃和拿 1 万块玻璃，有区别吗？**毫无区别，因为你根本扔不到玻璃用完。**
所以在代码最开始，有一个极大的简化：`m = min(m, 60LL);`。超过 60 块玻璃的，统统当 60 块处理，直接防止了数据的庞大计算。

思路总结图景

1. **预计算**：先算出来给你 $m$ 块玻璃，测 $n$ 层楼，你兜底最少需要几次机会（设为 $k$）。
2. **卡极限**：每次测试，都选择一个“一旦玻璃碎了，剩下的机会和玻璃刚好能覆盖下半区”的楼层 $x$ 去扔。
3. **收缩区间**：根据交互器返回的碎没碎，调整区间上下限 `L` 和 `R`，同时机会 $k-1$。如果是碎了，玻璃 $m-1$。
4. **得出答案**：当 $L$ 和 $R$ 重合时，答案就水落石出了。

## [Trade](https://acm.hdu.edu.cn/contest/problem?cid=1203&pid=1004)
给定 n+1n+1 天的股票价格序列 $A_1,A_2,…,A_{n+1}$其中 $1≤Ai≤10^9$。小 A 初始时刻没有持有任何股票，且拥有足够多现金。

在第 $i（1≤i≤n）$天，小 A 必须且只能进行一次操作，操作有且仅有以下两种：

    Buy：支付 $A_i$ 元，买入 1 股股票；
    Sell：卖出 1 股股票，获得 $Ai$ 元。

需要满足以下约束：

- 任何时刻，小 A 持有的股票数量都不能为负数；
- 如果当天选择卖出，那么在卖出前手中必须至少持有 1 股股票。
- **浮盈加仓**：小 A 是狂热的短线战士，假设现在是第 $i（3≤i≤n）$天，如果最近连续的两笔交易$（i−2, i−1）$都是购买且价格不降 $A_{i−1}≥A_{i−2}$，小 A 会在第 i 天果断选择购买。

第 n 天结束后，第 $n+1$ 天小 A 会以当天价格无条件卖出所有手上的股票（如果有），计算 小 A 能够获得的最大净收益是多少。
Input

第一行包含一个整数 T，表示数据组数。

接下来每组数据包含两行：

- 第一行一个整数 n，表示前 n 天可以进行交易；
- 第二行包含 $n+1$ 个整数 $A_1,A_2,…,A_{n+1}$，其中 $A_i$ 表示第 i 天的交易价格。

数据范围满足：$T=5，1≤n≤500$，且所有测试点中 $∑n≤2000$。

---
DP
设状态`f[i][j][s1][s2]`为
1. 当前是第 i 天
2. 当前持有股票 j 股
3. 第 $i-1$ 天操作为 s1
4. 第 $i-2$ 天操作为 s2
表示第 i 天结束后, 持有 j 股, 且 前两天的操作分别为 s1, s2, 的最大收益

转移, 如果满足 `s1 = 1 && s2 = 1 && a[i-2] <= a[i-1]` 那么 第 i 天一定要买的, 否则: 
1. 买入
2. 卖出

```cpp
#include <iostream>
#include <vector>
#include <algorithm>

using namespace std;

typedef long long ll;

const ll INF = 1e18;

void solve() {
    int n;
    cin >> n;
    vector<ll> a(n + 2);
    for (int i = 1; i <= n + 1; ++i) {
        cin >> a[i];
    }

    // dp[i][j][last1][last2]
    // i: 第i天 (1~n)
    // j: 持有股票数 (0~n)
    // last1: 第i天操作 (1:Buy, 0:Sell)
    // last2: 第i-1天操作 (1:Buy, 0:Sell)
    // 空间优化：由于n=500，500*500*2*2 * 8字节 约 8MB，可以直接开。
    // 为了方便理解，这里使用四维数组。
    static ll dp[505][505][2][2];

    // 初始化DP表
    for (int i = 0; i <= n; ++i) {
        for (int j = 0; j <= n; ++j) {
            for (int l1 = 0; l1 < 2; ++l1) {
                for (int l2 = 0; l2 < 2; ++l2) {
                    dp[i][j][l1][l2] = -INF;
                }
            }
        }
    }

    // 第1天：由于初始没有股票，必须Buy
    dp[1][1][1][0] = -a[1];

    for (int i = 2; i <= n; ++i) {
        for (int j = 0; j <= i; ++j) {
            for (int l1 = 0; l1 < 2; ++l1) {
                for (int l2 = 0; l2 < 2; ++l2) {
                    if (dp[i - 1][j][l1][l2] <= -INF) continue;

                    ll curr_profit = dp[i - 1][j][l1][l2];

                    // 检查第i天是否触发“浮盈加仓”强制购买
                    // 条件：i >= 3，且i-1和i-2都是购买，且 A[i-1] >= A[i-2]
                    bool force_buy = false;
                    if (i >= 3 && l1 = 1 && l2 = 1 && a[i - 1] >= a[i - 2]) {
                        force_buy = true;
                    }

                    // 决策 1: Buy
                    dp[i][j + 1][1][l1] = max(dp[i][j + 1][1][l1], curr_profit - a[i]);

                    // 决策 2: Sell (如果不满足强制购买条件，且手中有票)
                    if (!force_buy && j > 0) {
                        dp[i][j - 1][0][l1] = max(dp[i][j - 1][0][l1], curr_profit + a[i]);
                    }
                }
            }
        }
    }

    // 第n+1天：无条件卖出所有
    ll max_profit = -INF;
    for (int j = 0; j <= n; ++j) {
        for (int l1 = 0; l1 < 2; ++l1) {
            for (int l2 = 0; l2 < 2; ++l2) {
                if (dp[n][j][l1][l2] > -INF) {
                    max_profit = max(max_profit, dp[n][j][l1][l2] + (ll)j * a[n + 1]);
                }
            }
        }
    }

    cout << max_profit << endl;
}

int main() {
    ios::sync_with_stdio(false);
    cin.tie(0);

    int t;
    cin >> t;
    while (t--) {
        solve();
    }
    return 0;
}
```


## [Horse Racing](https://acm.hdu.edu.cn/contest/problem?cid=1203&pid=1008)
A 和 B 受到田忌赛马的启发，想进行一次赛马比赛。

一共有 $n(1≤n≤3×10^5)$个等级的马，第 i 个等级中，A 有 $a_i$ 匹，B 有 $b_i$ 匹。保证两人的马总数相同, 

每匹马只能参赛一次。比赛规则如下：

- 高等级马对低等级马，必胜。
- 同等级马对同等级马，双方各有 50%50% 概率获胜。
- A 和 B 都不知道对方剩余马匹构成，因此都采用完全随机策略：
- 每一轮从自己剩余马中等概率随机选出一匹出战；
- 直到全部马匹比完。

请你计算 A 最终期望赢下的场数，并对 998244353 取模输出。

Input

第一行一个整数 T，表示测试数据组数。题目要求多组数据，固定为 $T=5$。

对于每组数据：

- 第一行一个整数 n，表示马的等级数。

- 第二行 n 个整数 $a_1,a_2,…,a_n$, 满足 $0≤ai≤10^6$

- 第三行 $n$ 个整数 $b_1,b_2,…,b_n$, 满足 $0≤bi≤10^6$。

---
 一、 题目分析与解题思路

1. 核心思路：期望的线性性 (Linearity of Expectation)

这道题要求的是 A 最终赢下的**总场数**的期望。
设 $S$ 为 A（或 B）的总马匹数。假设 A 的马分别为 $X_1, X_2, \dots, X_S$，B 的马分别为 $Y_1, Y_2, \dots, Y_S$。
设随机变量 $I_k$ 为 A 的第 $k$ 匹马是否获胜（赢了记为 1，没赢记为 0）。那么总赢场数 $W = \sum_{k=1}^S I_k$。
根据期望的线性性：


$$E[W] = E\left[\sum_{k=1}^S I_k\right] = \sum_{k=1}^S E[I_k] = \sum_{k=1}^S P(X_k \text{ 获胜})$$

2. 概率转化

由于 A 和 B 都是**完全随机**出战，这意味着：**A 的每一匹马都有相等的概率（$1/S$）遇到 B 的任何一匹马。**
因此，对于 A 的某一匹马 $X_k$，它获胜的概率为：


$$P(X_k \text{ 获胜}) = \sum_{j=1}^S P(X_k \text{ 遇到 } Y_j) \cdot P(X_k \text{ 战胜 } Y_j) = \frac{1}{S} \sum_{j=1}^S P(X_k \text{ 战胜 } Y_j)$$

3. 利用等级归类计算

我们不需要逐匹马计算，可以按等级 $i$ 进行归类。
设等级为 $i$ 的马，A 有 $a_i$ 匹，B 有 $b_i$ 匹。
对于 A 的一匹等级为 $i$ 的马，它遇到 B 的所有马中：

* 能稳赢等级小于 $i$ 的马，数量为 $\sum_{m=1}^{i-1} b_m$。
* 有 $50\%$ 概率赢同等级 $i$ 的马，数量为 $b_i$。
* 稳输等级大于 $i$ 的马。

所以，等级为 $i$ 的一匹 A 马，其获胜概率的贡献和为：


$$\text{Score}_i = a_i \times \left( (\sum_{m=1}^{i-1} b_m) \times 1 + b_i \times \frac{1}{2} \right)$$

最终总期望 $E = \frac{1}{S} \sum_{i=1}^n \text{Score}_i$。
