## [幻灵战队 2](https://acm.hdu.edu.cn/contest/problem?cid=1230&pid=1010)

给出一个长度为 𝑛 的胜负序列（其中 0 表示失败，1 表示胜利）
。
初始时科技点为 0，连续失败的第 𝑥 场对战将会获得 20 + 5𝑥 的
科技点。
你可以将至多 𝑘 场失败改成胜利，使得重新计算后的科技点总和
最小。求出可能获得的科技点总和的最小值。
$1 \le 𝑛 \le 10^5 ，0 \le 𝑘 \le 𝑛$。

---

如果有1个长为 m 的连续失败序列, 那么记 $f(m, c)$ 表示长为 m 的序列翻转 c 个点后的科技值, 那么直觉上, 插入点的收益随着 c 的增加而减少, 对于每一块都如此, 那么用 **优先队列** 维护当前最大 **添加一个点后的收益**, 每次取出最大的, 取出  k 个就是可以获得的最大收益

```cpp
//计算长为x的块的科技点
int f(int x){
    return 20*x + 5 * x * (x + 1) / 2;
}

//计算 长为 s, 翻转 c 个点后的科技值
int cal_d(int s, int c){
    int res_0 = s - c;
    int cnt_block = c + 1;
    int basic = res_0 / cnt_block;
    int rem = res_0 % cnt_block;
    return cnt_block * f(basic) + rem * (f(basic+1)-f(basic));
}

//优先队列, 维护最大收益, 同时记录块大小s和已经插入的点个数c
struct Node{
    int s, c, dec;
    Node(){}
    Node(int s, int c, int dec):s(s), c(c), dec(dec){}
    bool operator < (const Node& a)const{
        return dec < a.dec;
    }
};

void solve(){
    int n, k; cin >>n >> k;
    string s; cin >> s;

    int ans = 0;
    vector<int> p;
    for(int i = 0;i < n; ){  //计算连续失败的0块
        if(s[i] = '0'){
            int j = i;
            while(j < n && s[j] = '0')j++;
            p.push_back(j-i);
            ans += cal_d(j-i, 0);
            i = j;
        }else i++;
    }

    priority_queue<Node> pq;

    //插入所有块插入一个点相比不插入的收益
    for(auto &c : p){
        pq.push({c, 0, cal_d(c, 0) - cal_d(c, 1)});
    }

    while(k-- && !pq.empty()){
        auto [c, s, d] = pq.top(); pq.pop();
        ans -= d;
        s++;
        if(s != c) pq.push({c, s, cal_d(c, s) - cal_d(c, s+1)});
    }
    cout << ans << endl;
}
```



## [数论】C Looooops](https://icpc.upc.edu.cn/problem.php?cid=4577&pid=7)

一个循环体 `for(value = A; value != B; value += C)` 所有数都在 模 $2^k$ 下运算, 求会进行多少次循环. $(1 \le k \le 32, 0 \le A, B, C \less 2^k)$

---
这就是求 $$A + x \tiems C \equiv B \pmod{2^k}$$ 的解, 

转换一下就等价于 $$Cx + 2^k y = b - a \pmod{2^k}$$ 同余方程的解,

根据裴蜀定理, 方程有解当且仅当 $b - a$ 是 $C$ 和 $2^k$ 的最大公约数的倍数.

在有解的情况下, 使用 **拓展欧几里得算法**, 可以得到 $x, y$ 的特解

此外: 

### 一、为什么 `exgcd` 算出的 $x$ 会是负数？

扩展欧几里得算法 `exgcd(c, m, x, y)` 求解的是方程：


$$c \cdot x + m \cdot y = \gcd(c, m)$$

在算法的递归推导中，为了满足这个等式，算出的 $x$ 和 $y$ **必然一正一负**。

#### 极简举例：

假设 $c = 3, m = 16$，它们的 $\gcd(3, 16) = 1$。
方程为：


$$3x + 16y = 1$$

`exgcd` 运行后，算出的解是：


$$x = -5, \quad y = 1$$

验算一下：$3 \times (-5) + 16 \times 1 = -15 + 16 = 1$，完全正确！
**但是这里的 $x = -5$ 是负数！**

如果你的 `time = 4`，直接计算 `x * time` 就会得到 $-5 \times 4 = -20$。
**物理意义暴击**：你总不能跟编译器说“这个 `for` 循环倒退着执行了 -20 次”吧？

___

### 二、为什么 $x \times \text{time}$ 只是一个特解？周期的数学推导

我们原方程要解的是：


$$c \cdot x + m \cdot y = E$$

两边同时除以 $g = \gcd(c, m)$，得到简化的方程：


$$c' \cdot x + m' \cdot y = E' \quad \left(\text{其中 } c' = \frac{c}{g}, \; m' = \frac{m}{g}, \; E' = \frac{E}{g}\right)$$

此时 $c'$ 与 $m'$ **互质**（$\gcd(c', m') = 1$）。

假设我们通过 `exgcd` 找到了一个可行解 $x_0$。
那么，如果我们将 $x$ **增加 $m'$**，同时把 $y$ **减少 $c'$**，方程依然成立！

#### 数学验证：

$$c'(x_0 + m') + m'(y_0 - c') = c'x_0 + c'm' + m'y_0 - m'c' = c'x_0 + m'y_0 = E'$$

这就意味着：**同余方程的解在数轴上是无限多个的！**
所有的解构成了等差数列：


$$\dots, \; x_0 - 2m', \; x_0 - m', \; \mathbf{x_0}, \; x_0 + m', \; x_0 + 2m', \; \dots$$

* 这个等差数列的公差（最小周期）就是：

$$\text{mod\_x} = m' = \frac{m}{\gcd(c, m)}$$


* `exgcd` 算出的只是这个数列里**随便某一个特定的解（特解）**。

___

### 三、为什么要找“最小非负解”？

在 C 语言的 `for` 循环中：

```c
for (variable = A; variable != B; variable += C)

```

1. **循环次数不能是负数**：必须满足 $x \ge 0$。
2. **首次到达即终止**：`variable` 从 $A$ 开始增加，**第一次**遇到等于 $B$ 时循环就结束了。所以我们需要寻找的是**所有大于等于 0 的解中，最小的那一个**。

因此，我们要把那个可能极小、甚至是负数的特解 $x_1 = x \times \text{time}$，平移到半开区间 $[0, \; \text{mod\_x})$ 中。

___

### 四、C++ 代码中的“最小非负化”防坑技巧

在 C++ 中，由于负数取模（如 `-20 % 16`）的结果依然是负数（`-4`），所以不能直接使用 `x % mod_x`。

标准的**最小非负化公式**为：


$$\text{ans} = (x_1 \bmod \text{mod\_x} + \text{mod\_x}) \bmod \text{mod\_x}$$

#### 手推演练：

还是上面的例子，假设算出的特解 $x_1 = -20$，周期 $\text{mod\_x} = 16$：

1. `-20 % 16` $\to$ `-4`
2. `-4 + 16` $\to$ `12`（成功拉回正数区间！）
3. `12 % 16` $\to$ `12`

```cpp
void exgcd(int a, int b, int&x, int& y ){
    if(!b){x = 1, y = 0; return;}
    exgcd(b, a%b, x, y); int x0 = x, y0 = y;
    x = y0, y= x0-a/b*y0; return;
}

int gcd(int a, int b){
    if(!a) return b;
    return gcd(b%a, a);
}

void solve(){
    int a, b, c, k;
    while(cin >> a >> b >> c >> k&&(a||b||c||k)){
        int m = 1LL<<k;
        int gd = gcd(c, m);
        if((b-a+m)%m%gd != 0){
            cout << "FOREVER\n";
            continue;
        }

        int time = (b-a+m)%m/gd;
        int x, y;
        exgcd(c, m, x, y);
        int mod_x = m / gd;
        int ans = ((x*time) % mod_x + mod_x)%mod_x;
        cout << ans << endl;
    }
}
```

## [E - Payment ](https://atcoder.jp/contests/abc155/tasks/abc155_e)

### 题目描述

在 AtCoder 王国中，仅使用纸币作为货币。共有 $10^{100}+1$ 种纸币，面额分别为 $1, 10, 10^2, 10^3, \dots, 10^{(10^{100})}$。你来到一家商场购物，正在购买一台价值为 $N$ 的章鱼烧机器。_（章鱼烧是一种日本小吃的名称。）_

为了支付，你将选择至少为 $N$ 的金额交给店员。然后，店员会找零给你，即你支付的金额减去 $N$。

当你和店员都选择最小化纸币总数的组合方式时，你和店员使用的纸币总数的最小可能值是多少？

假设你拥有足够数量的纸币，店员也同样拥有足够数量的纸币。

### Constraints

-   $N$ is an integer between $1$ and $10^{1,000,000}$ (inclusive).

---

从最低位开始考虑, 最低位为 $d$, 那么, 有两个选择:
1. 直接用 d 张货币
2. 用 10-d 张货币, 同时下一位 + 1

从后往前, 处理过的就不会有影响来, 满足 "无后效性", 因此可以使用动态规划来解决.

设 `dp0`为直接使用 d 张货币的最小使用数量, `dp1` 为使用 10-d 张货币的最小使用数量. 每次从前一个状态的最小转移

```cpp
void solve(){
    string s; cin >> s;
    int len = s.size();
    int dp0 = 0, dp1 = INT_MAX;  //最开始没有上一个状态 
    for(int i = len - 1; i >= 0 ; --i){
        int n = s[i] - '0';
        int ndp0 = min(dp0+n, dp1 + (n + 1));  //从上一个状态转移
        int ndp1 = min(dp0+(10-n), dp1 + (9-n));
        dp0 = ndp0;
        dp1 = ndp1;
    }
    cout << min(dp0, dp1 + 1) << endl;
}
```

## [问题 G：Pole Arrangement](https://icpc.upc.edu.cn/problem.php?cid=4577&pid=6)

有高度为 $1, 2, 3, ..., n$ 的柱子, 计算满足下面两个条件的排列方式的个数:

1. 从左往右看, 只能看到 $l$ 个柱子
2. 从右往左看只能看到 $r$ 个柱子

柱子要被看到就一定要比它之前的都高, $(1 \le l, r \le n \le 20)$

---
数据范围很小, $20!$ 大约 $2.3 \times 10^{18}$


> **本质机制**：
> 第一类斯特林数 $\left[ \begin{matrix} n \\ k \end{matrix} \right]$ 表示将 $n$ 个不同元素划分为 $k$ 个非空循环（轮换）的方案数。
> **巧妙转化**：在排列中，“从左往右能看到的柱子数”恰好等于该排列中**前缀最大值的个数**。而长度为 $n$ 的排列中拥有 $k$ 个前缀最大值的排列数量，**严格等于第一类斯特林数 $\left[ \begin{matrix} n \\ k \end{matrix} \right]$**！

___

### 3. 底层概念与公式扫盲

#### 第一类斯特林数递推公式

$$\left[ \begin{matrix} n \\ k \end{matrix} \right] = \left[ \begin{matrix} n-1 \\ k-1 \end{matrix} \right] + (n-1) \cdot \left[ \begin{matrix} n-1 \\ k \end{matrix} \right]$$

* **边界条件**：$\left[ \begin{matrix} 0 \\ 0 \end{matrix} \right] = 1$，其余 $\left[ \begin{matrix} n \\ 0 \end{matrix} \right] = 0, \left[ \begin{matrix} 0 \\ k \end{matrix} \right] = 0$。
* **物理意义**：考虑第 $n$ 个（最高的）元素：
1. 它自成一个新的前缀最大值组：即从前 $n-1$ 个元素选 $k-1$ 组，方案数为 $\left[ \begin{matrix} n-1 \\ k-1 \end{matrix} \right]$；
2. 它被放在某个已有元素的后面（被挡住）：有 $n-1$ 个位置可放，方案数为 $(n-1) \cdot \left[ \begin{matrix} n-1 \\ k \end{matrix} \right]$。


___

### 阶段 2：思维演进与本题解构

```cpp
#include <iostream>
#include <vector>
using namespace std;

const int MAXN = 25;

// S1[n][k] 表示第一类斯特林数
long long S1[MAXN][MAXN];
// C[n][k] 表示组合数
long long C[MAXN][MAXN];

// 预处理斯特林数与组合数
void init() {
    // 1. 预处理组合数
    for (int i = 0; i < MAXN; ++i) {
        C[i][0] = 1;
        for (int j = 1; j <= i; ++j) {
            C[i][j] = C[i - 1][j - 1] + C[i - 1][j];
        }
    }

    // 2. 预处理第一类斯特林数
    S1[0][0] = 1;
    for (int i = 1; i < MAXN; ++i) {
        for (int j = 1; j <= i; ++j) {
            S1[i][j] = S1[i - 1][j - 1] + (i - 1) * S1[i - 1][j];
        }
    }
}

void solve() {
    int n, l, r;
    cin >> n >> l >> r;

    // 非法情况判断
    if (l + r - 2 < 0 || l + r - 2 > n - 1) {
        cout << 0 << "\n";
        return;
    }

    // 套用核心公式：C(l + r - 2, l - 1) * S1(n - 1, l + r - 2)
    long long ans = C[l + r - 2][l - 1] * S1[n - 1][l + r - 2];
    cout << ans << "\n";
}
```

## [foata变换]

求 n 的 **排列** 的 **前缀最大值** 的个数为 m 的排列数量

---

看似完全不相干的两个概念：

1. **几何/视觉概念**：排列中“能看到的柱子数”（即**前缀最大值的个数**）。
2. **抽象代数概念**：将 $n$ 个元素划分为 $k$ 个圆圈/轮换的方案数（即**第一类斯特林数** $\left[ \begin{matrix} n \\ k \end{matrix} \right]$）。

它们之所以**数量严格相等**，是因为存在一个极其巧妙的“一对一完美映射”（数学上称为 **Foata 标准变换 / Foata's Transition Lemma**）。

___


### 第二步：神奇的桥梁（Foata 标准变换）

如何将任何一个“拆成 $k$ 个圆圈的组合”**无损且唯一地**转化为一个“拥有 $k$ 个前缀最大值的普通排列”？

我们可以规定一套**标准的书写规则**：

### 规则 1：规范圆圈内部的写法

对于任意一个圆圈（轮换），**把这个圆圈里最大的那个数，强制提到圆圈的最开头**。

* 例如圆圈 `(1 2 4)`，最大数是 4，我们把它改写为 `(4 1 2)`。
* *注意：在圆圈（轮换）里，(1 2 4) 和 (4 1 2) 的元素轮换顺序完全相同，本质是同一个圆圈。*

### 规则 2：规范圆圈之间的排序

把这 $k$ 个圆圈，**按照它们开头的那个最大数，从小到大进行排序**。

* 例如有两个圆圈 `(3 1)` 和 `(4 2)`，因为 $3 < 4$，所以 `(3 1)` 必须排在 `(4 2)` 的左边，写成 `(3 1)(4 2)`。

### 规则 3：直接抹掉所有括号！

把排好序的圆圈直接抹掉括号，变成一个普通数列。

* `(3 1)(4 2)` 抹掉括号后 $\to$ 排列 `[3, 1, 4, 2]`。

___

## 第三步：为什么前缀最大值恰好是 $k$ 个？

让我们观察按照上述规则拍平后的数列 `[3, 1, 4, 2]`：

1. **第 1 个圆圈的开头**是 `3`：
* 因为它是数列的第 1 个数，所以 `3` 必定是**第 1 个前缀最大值**。
* 这个圆圈后面的所有数字（如 `1`），根据规则 1，都必定比 `3` 小，所以它们**绝对不可能**成为前缀最大值！


2. **第 2 个圆圈的开头**是 `4`：
* 根据规则 2，圆圈是按开头大小升序排列的，所以 $4 > 3$。
* `4` 不仅大于前一个圆圈的开头 `3`，也大于第一个圆圈里的所有数！因此 `4` 必定是**第 2 个前缀最大值**。
* 同理，`4` 后面的数（如 `2`）都比 `4` 小，不可能成为前缀最大值。



> **核心结论**：
> 每一个原圆圈的“开头最大数”，在抹掉括号后，**恰好且仅仅是**新排列里的一个前缀最大值！
> **$k$ 个圆圈 $\Longleftrightarrow$ $k$ 个前缀最大值。**

___

因为每一个“将 $n$ 个元素划分为 $k$ 个圆圈的方案”，都通过 Foata 变换**唯一对应**一个“拥有 $k$ 个前缀最大值的 $n$ 阶排列”；反之亦然。

所以：


$$\text{拥有 } k \text{ 个前缀最大值的排列数量} \equiv \text{划分成 } k \text{ 个圆圈的方案数} \equiv \left[ \begin{matrix} n \\ k \end{matrix} \right]$$

这就是组合数学中这个转换极度巧妙的底层逻辑。

## [D. Lucky Permutation](https://codeforces.com/problemset/problem/1768/D)

给定一个长度为 $$$n$$$ 的排列$$$^\dagger$$$ $$$p$$$。

在一次操作中，你可以选择两个下标 $$$1 \le i \lt j \le n$$$ 并交换 $$$p &#95; i$$$ 和 $$$p &#95; j$$$。

求使得该排列中**恰好存在一个**逆序$$$^\ddagger$$$所需的最小操作次数。

$$$^\dagger$$$ 排列是指由 $$$1$$$ 到 $$$n$$$ 的 $$$n$$$ 个不同整数以任意顺序组成的数组。例如 $$$[2,3,1,5,4]$$$ 是一个排列，但 $$$[1,2,2]$$$ 不是排列（数字 $$$2$$$ 在数组中出现两次），$$$[1,3,4]$$$ 也不是排列（$$$n=3$$$ 但数组中出现了 $$$4$$$）。

$$$^\ddagger$$$ 排列 $$$p$$$ 的逆序数是指满足 $$$1 \le i \lt j \le n$$$ 且 $$$p &#95; i \gt p &#95; j$$$ 的下标对 $$$(i, j)$$$ 的数量。

**输入**

第一行包含一个整数 $$$t$$$（$$$1 \le t \le 10^4$$$），表示测试用例的数量。接下来是测试用例的描述。

每个测试用例的第一行包含一个整数 $$$n$$$（$$$2 \le n \le 2 \cdot 10^5$$$）。

每个测试用例的第二行包含 $$$n$$$ 个整数 $$$p &#95; 1,p &#95; 2,\ldots, p &#95; n$$$（$$$1 \le p &#95; i \le n$$$）。保证 $$$p$$$ 是一个排列。

保证所有测试用例的 $$$n$$$ 的总和不超过 $$$2 \cdot 10^5$$$。

---
这道题主要是有个结论: 
> 把一个排列还原成有序的最小操作次数是 $n - c$, 其中 $n$ 是排列总个数, $c$ 是排列划分成的环的个数
> 在一个环内交换就会把一个环划分成两个小环
> 在两个环间交换, 就会合并两个环

那么要求有一个逆序数, 就是有一个相邻点在同一个环中, 那么就只需要 $n - c - 1$ 次操作

否则就要 $n - c + 1$ 次操作

```cpp
void solve(){
    int n; cin >> n;
    vi a(n + 1);
    fi(n) cin >> a[i];
    vector<bool > vis(n + 1);
    vector<vi> cys;

    for(int i = 1;i <= n; ++i){
        if(!vis[i]){
            vis[i] = 1;
            int j = a[i];
            vi cy;
            cy.push_back(i);
            while(!vis[j]){
                vis[j] = 1;
                cy.push_back(j);
                j = a[j];
            }
            cys.push_back(std::move(cy));
        }
    }

    int c = cys.size();
    bool ko = 0;
    for(auto &v : cys){
        if(ko) break;
        if(v.size() = 1) continue;
        else {
            sort(all(v));
            for(int i = 1;i < v.size(); ++i){
                if(v[i] = v[i-1]+1) {
                    ko = 1;
                    break;
                }
            }
        }
    }
```

### 题目描述

一个由小写英文字母组成的字符串被称为**好字符串**，当且仅当它满足以下条件：

-   通过最多修改一个字符，可以使其变为回文串。

例如，`a`、`iwai` 和 `abcdcza` 都是好字符串，但 `abcd` 和 `atcoder` 不是好字符串。特别注意，回文串本身也是好字符串。

给定一个由小写英文字母组成的字符串 $S$。

请计算 $S$ 中是非空子串（连续子序列）且为好字符串的数量。

即使两个子串在字符串内容上相同，只要它们在 $S$ 中的位置不同，就分别计数。

什么是子串？

$S$ 的**子串**是指通过从 $S$ 的开头删除零个或多个字符，以及从 $S$ 的末尾删除零个或多个字符得到的字符串。  
例如，`ab` 是 `abc` 的子串，但 `ac` 不是 `abc` 的子串。


### Constraints

-   $S$ is a string of length between $1$ and $10^4$, inclusive, consisting of lowercase English letters.

---
简单来说就是找所有能在最多修改一个字符的情况下的回文子串个数

$n \le 10^4$, 可以接受 $(O(n^2))$的做法, 用 **中心拓展法** , 枚举所有的中心 $(2*n - 1)$, 包括以字符为中心和以间隙为中心的字符

从中心向两边拓展, 记录不同的数量, 如果数量多于 1, 就可以结束这个中心了

> 中心技巧, $i \in [0, 2*n - 1]$, 让 $l = i/2, r = i - l$, 这样奇数 $i$ 就相当于是两个数的缝隙, 偶数就是以一个字符为中心

```cpp
void solve(){
    string s; cin >> s;
    int len = s.size();
    int tar = len*2 - 1, ans = 0;
    for(int i = 0;i <= tar; ++i){
        int l = i/2, r = i - l;
        int diff = 0;
        while(l >= 0 && r < len){
            if(s[l] != s[r])diff++;
            if(diff > 1) break;
            l--; r++;
            ans ++;
        }
    }
    cout << ans << endl;
}
```


## [D. Deleting Divisors](https://codeforces.com/problemset/problem/1537/D)

Alice和Bob正在玩一个游戏。

他们从一个正整数$$$n$$$开始，轮流对其进行操作。每回合玩家可以从$$$n$$$中减去一个不等于$$$1$$$或$$$n$$$的约数。无法进行操作的一方判负。Alice总是先手。

**Input**

The first line contains a single integer $t$$t$ ($1≤t≤104$$1 \leq t \leq 10^4$) — the number of test cases. Then $t$$t$ test cases follow.

Each test case contains a single integer $n$$n$ ($1≤n≤109$$1 \leq n \leq 10^9$) — the initial number.

---
博弈题型, 分奇偶讨论, 

针对本题，我们考虑以下 $$$3$$$ 种情况：

1) n 为奇数  
2) n 为偶数，且 $$$n$$$ 不是 2 的幂  
3) n 是 2 的幂  

若 $$$n$$$ 为奇数，唯一操作是减去一个奇因数（因为所有因数都是奇数）。这样操作后，我们将得到一个非 2 的幂的偶数（情况 2）。设 $$$D$$$ 是 $$$n$$$ 的因数，则 $$$n-D$$$ 必然也能被 $$$D$$$ 整除。由于 $$$D$$$ 是奇数，$$$n-D$$$ 不可能是 2 的幂。

若 $$$n$$$ 为偶数且不是 2 的幂，说明 $$$n$$$ 存在奇因数。减去该奇因数后，得到的 $$$n-D$$$ 为奇数（情况 1）。现在证明每次操作都减去奇因数可致胜：质数态是必败态，因为唯一操作是减去该数本身，使 $$$n=0$$$ 而落败。由于所有质数要么是奇数要么是 2 的幂，因此让对手面临奇数态是必胜策略——对手要么遇到质数（必败），要么操作后返还一个非 2 的幂的偶数。你可以持续此过程，因为永远不会落入必败态，且游戏步数有限，对手终将落败。

由此证得：奇数态必败，非 2 的幂的偶数态必胜。

若 $$$n$$$ 是 2 的幂呢？每步操作有两种选择：将 $$$n$$$ 减半，或使其变为非 2 的幂的偶数（已证此为对手的必胜态）。唯一最优解是将 $$$n$$$ 减半，使其保持 2 的幂。双方持续此操作直到某方得到 $$$2$$$（质数态，必败）。若 $$$log &#95; 2(n)$$$ 为偶数，Alice 胜；否则 Bob 胜。

也就是, 先手奇数就 **永远只能拿到奇数**, 先手偶数也就只能拿到偶数

## [E - Knapsack 2](https://atcoder.jp/contests/dp/tasks/dp_e)

### 题目描述

有 $N$ 个物品，编号为 $1, 2, \ldots, N$。对于每个 $i$（$1 \leq i \leq N$），物品 $i$ 的重量为 $w &#95; i$，价值为 $v &#95; i$。

太郎决定从这 $N$ 个物品中选取一些放入背包带回家。背包的容量为 $W$，这意味着所选物品的总重量不能超过 $W$。

请求出太郎能带回家的物品价值总和的最大可能值。

### Constraints

-   All values in input are integers.
-   $1 \leq N \leq 100$
-   $1 \leq W \leq 10^9$
-   $1 \leq w_i \leq W$
-   $1 \leq v_i \leq 10^3$

---





#### 1. 数据范围与复杂度倒推

在算法竞赛中，反常的数据范围往往就是破局的阵眼。

* **输入特征**：物品数量 **N <= 100**，单个物品价值 **v_i <= 10^3**，但背包容量 **W** 高达 **10^9**。
* **复杂度倒推**：
* 传统的 0-1 背包状态是“在前几个物品中选，体积不超过多少时的最大价值”，时间复杂度为 $\mathcal{O}(N \times W)$。如果把 **100** 和 **10^9** 相乘，计算量高达 **10^{11}**，不仅会引发严重超时（1秒限制一般在 **10^8** 左右），而且开出大小为 **10^9** 的数组会瞬间把内存撑爆。
* 但是，注意看价值！所有物品的总价值极限为 $N \times \max(v_i) = 100 \times 1000 = \textbf{100000}$（也就是 **10^5**）。$\mathcal{O}(N \times V_{max})$ 的计算量只有 **10^7**，完美契合时空限制。



#### 2. 前置知识

**核心知识点：状态定义反转（Domain-Codomain Swapping in DP）**

* **痛点与瓶颈**：传统 DP 以“资源限制”（重量）作为状态数组的下标，以“目标收益”（价值）作为数组存储的值。当“资源限制”极大而“目标收益”极小时，这种映射关系就成了导致维度爆炸的瓶颈。
* **本质机制**：数学中，如果一个函数 $y = f(x)$ 是单调的，我们可以求它的反函数 $x = f^{-1}(y)$。在背包问题中，为了获得越高的价值，必然需要越大的重量。既然以重量为下标行不通，我们就“把定义域和值域互换”！
* 将状态重定义为：在达到**特定价值**时，所需要的**最小重量**。
* 算完后，只需从最大价值往回遍历，找到第一个“最小重量 $\le \textbf{W}$”的价值，那就是答案。


* **底层概念扫盲**：
* **0-1 背包的空间优化**：在一维数组上，必须**逆序遍历**状态变量，以确保每个物品在一个状态转移过程中只被使用一次（保持 0-1 属性）。



___

### 阶段 2：思维演进与本题解构

#### 1. 朴素推导到最优解

* **传统方程（不可用）**：$dp[w]$ 表示重量不超过 $w$ 时的最大价值。
$$dp[w] = \max(dp[w], dp[w - w_i] + v_i)$$


* **反转方程（最优解）**：设 $dp[v]$ 表示**正好凑出价值 $v$** 时所需要的最少重量。
面对第 $i$ 个物品（重量为 $w_i$，价值为 $v_i$），如果我们要凑出总价值 $v$，那么有两种选择：
1. 不选它：重量保持为原本凑出 $v$ 的最小重量 $dp[v]$。
2. 选它：说明剩下的价值 $v - v_i$ 是用之前的物品凑出的，总重量变为 $dp[v - v_i] + w_i$。
我们要让重量越轻越好（这样才能装得下），因此取最小值：

$$dp[v] = \min(dp[v], dp[v - v_i] + w_i)$$



#### 3. 正确性逻辑

因为 $dp$ 数组维护的是严格的下限（最小重量），只要最后扫描时满足 $dp[v] \le W$，就说明在背包容量允许的物理现实下，必然存在一种组合能刚好达到价值 $v$。这避开了冗余的“大重量-小价值”状态，实现了降维打击。






```cpp
#include <iostream>
#include <vector>
#include <algorithm>

using namespace std;

// 使用 long long 防止极限情况下的溢出
const long long INF = 1e18; 

int main() {
    // IO 优化
    ios_base::sync_with_stdio(false);
    cin.tie(NULL);

    int N;
    long long W;
    if (!(cin >> N >> W)) return 0;

    vector<long long> w(N);
    vector<int> v(N);
    int max_v_sum = 0;

    for (int i = 0; i < N; ++i) {
        cin >> w[i] >> v[i];
        max_v_sum += v[i];
    }

    // dp[j] 表示达到准确价值 j 所需的最小重量
    // 初始化为无穷大，表示不可达
    vector<long long> dp(max_v_sum + 1, INF);
    dp[0] = 0; // 价值为 0 不需要任何重量

    for (int i = 0; i < N; ++i) {
        // 避坑点 1：0-1 背包的一维优化，必须逆序遍历！
        // 如果正序，当前的物品会被当成完全背包（被无限次重复使用）。
        for (int j = max_v_sum; j >= v[i]; --j) {
            if (dp[j - v[i]] != INF) { // 只有前置状态合法时才转移，防止 INF + w[i] 溢出
                dp[j] = min(dp[j], dp[j - v[i]] + w[i]);
            }
        }
    }

    // 避坑点 2：从最大可能价值往回找，找到的第一个重量 <= W 的价值即为答案
    long long ans = 0;
    for (int j = max_v_sum; j >= 0; --j) {
        if (dp[j] <= W) {
            ans = j;
            break;
        }
    }

    cout << ans << "\n";

    return 0;
}

```

**【避坑指南】**

1. **无穷大的溢出陷阱 (Integer Overflow)**：由于 $w_i$ 最大可达 **10^9**，如果有 100 个物品，理论上的最大重量总和是 **10^{11}**。如果你用 32 位 `int`，或者把 `INF` 设为普通的 `1e9`，都会瞬间引发逻辑错误甚至整型溢出。必须开 `long long` 且 `INF` 设为 `1e18`。
2. **无穷大转移陷阱**：在做加法 `dp[j - v[i]] + w[i]` 时，如果前面是 `INF`，加上一个数可能会导致变量溢出变成负数。必须加 `if (dp[j - v[i]] != INF)` 的判断，这是写求最小值的 DP 时非常良好的习惯。




##  [背包DP]

为什么传统的 0-1 背包算法无法解决“超大背包容量（如 $W = 10^9$）”的问题？我们该用什么核心机制破除此瓶颈？

---
1. 传统 DP 将重量作为状态数组下标，会直接导致 $\mathcal{O}(NW)$ 超时且 MLE（数组开爆）。
2. 破除机制：**状态与值互换（State Inversion）**。将方程反转为 $dp[v] = w$，以总价值（极小）作下标，记录达到该价值所需的“最小重量”。




## [背包DP]

考场上看到背包/DP题目，给出“重量 $W \le 10^9$，但价值 $V \le 1000$ 且 $N \le 100$”，应瞬间反应出什么决策树与核心方程？

---
* **决策树**：阻断传统求最大价值的回路 $\rightarrow$ 转求固定价值的“最小重量” $\rightarrow$ 建立 $\mathcal{O}(N \times \sum V)$ 的一维 DP。
* **核心转换公式**：
$$dp[v] = \min(dp[v], dp[v - v_i] + w_i)$$


* **避坑点**：`dp` 数组必须用 `long long`，`INF` 设为 `1e18` 防溢出；最后求答案需从大到小遍历 $dp$ 找第一个 $\le W$ 的解。
