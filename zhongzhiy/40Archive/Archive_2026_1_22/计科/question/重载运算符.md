## 🧩 一、基本语法：结构体中重载运算符

假设我们有一个二维向量结构体 `Point`，我们想要支持加法、比较等操作。

### ✅ 示例：重载 `+` 运算符

```cpp
#include <iostream>
using namespace std;

struct Point {
    int x, y;

    // 重载加法运算符
    Point operator+(const Point& other) const {
        return {x + other.x, y + other.y};
    }

    // 重载比较运算符 ==
    bool operator==(const Point& other) const {
        return x == other.x && y == other.y;
    }

    // 重载输出运算符 <<（需要写成友元函数或全局函数）
    friend ostream& operator<<(ostream& os, const Point& p) {
        os << "(" << p.x << ", " << p.y << ")";
        return os;
    }
};
```

## 🔧 二、详细讲解

### ✅ 成员函数 vs 友元函数 vs 全局函数

- **成员函数形式**：
    
    - 用于重载二元运算符（如 `+`、`-`、`*` 等）
        
    - 语法是 `Type operator符号(const Type& other) const`
        
    - 左边的对象是 `this`，右边是参数
        
- **友元函数形式**（通常用于 `<<`、`>>` 这样的非成员操作）
    
    - 必须加上 `friend` 关键字
        
    - 语法和普通函数一样，但可以访问私有成员

## ✅ 三、常用重载运算符

|运算符|说明|示例|
|---|---|---|
|`+`|加法|`A + B`|
|`-`|减法|`A - B`|
|`*`|乘法|`A * 3`|
|`/`|除法|`A / 2`|
|`==`|相等比较|`A == B`|
|`<`|小于（用于排序）|`sort(v.begin(), v.end())`|
|`<<`|输出（cout）|`cout << A;`|
|`>>`|输入（cin）|`cin >> A;`|

## 🧪 示例代码：重载 `<` 用于 `std::set`

```cpp
#include <iostream>
#include <set>
using namespace std;

struct Point {
    int x, y;

    bool operator<(const Point& other) const {
        return (x == other.x) ? y < other.y : x < other.x;
    }
};

int main() {
    set<Point> s;
    s.insert({1, 2});
    s.insert({0, 2});
    s.insert({1, 1});

    for (const auto& p : s) {
        cout << p.x << " " << p.y << endl;
    }
}
```

## 🐱 总结

|类型|写法|注意事项|
|---|---|---|
|成员函数|`Point operator+(const Point& other) const`|`this` 为左操作数|
|友元函数|`friend ostream& operator<<(ostream&, const Point&)`|不能作为成员函数|
|排序使用 `<`|`bool operator<(const Point& other) const`|用于 `set`、`map`|
