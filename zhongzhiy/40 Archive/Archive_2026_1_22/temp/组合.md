这道题是组合数学中非常经典的**“隔板法”（Stars and Bars）**问题。

### 1. 问题建模

你要求解的是将 $m$ 个相同的苹果放入 $n$ 个不同的篮子（孩子）里，且允许篮子为空。这等价于求方程：

$$x_1 + x_2 + \dots + x_n = m$$

的**非负整数解**的个数。

### 2. 隔板法思路

想象你有 $m$ 个苹果（星星），你需要用 $n-1$ 块隔板将它们分成 $n$ 份。

- **允许为空的情况：** 如果直接在苹果之间插板，要求每份至少一个。但本题允许孩子分到 0 个苹果。
    
- **转化技巧：** 为了处理“允许为空”，我们可以假设先向总数里“借” $n$ 个苹果，分给每个孩子各一个，这样每个孩子至少有一个苹果，然后再应用插板法。或者更直白的理解是：
    
    - 总共有 $m$ 个苹果和 $n-1$ 个隔板，一共 $m + n - 1$ 个位置。
        
    - 从这 $m + n - 1$ 个位置中选出 $n - 1$ 个位置放隔板，剩下的放苹果。
        

### 3. 数学公式

根据上述逻辑，总的方法数等于从 $m+n-1$ 个位置中选出 $n-1$ 个位置的组合数：

$$C(m+n-1, n-1) = \binom{m+n-1}{n-1}$$

根据组合数的对称性，这也等于 $\binom{m+n-1}{m}$。

其展开式为：

$$\frac{(m+n-1)!}{m! \times (n-1)!}$$

**实现逻辑：**

1. 读取 $n$ 和 $m$。
    
2. 计算分子：`fac[n + m - 1]`。
    
3. 计算分母的逆元：`rev(fac[m])` 和 `rev(fac[n - 1])`。
    
4. 相乘并取模。
    

**代码片段参考：**

C++

```
// 假设 n, m 已经读入
int N = n + m - 1;
int K = n - 1;

if (m == 0) {
    cout << 1 << endl; // 0个苹果只有1种分法：全0
} else {
    int ans = fac[N];
    ans = (ans * rev(fac[K])) % M;
    ans = (ans * rev(fac[N - K])) % M;
    cout << ans << endl;
}
```
