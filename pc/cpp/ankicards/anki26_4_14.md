# 算法

## (二叉搜索树)
怎么建树
---
```cpp
constexpr int N = 1e3;
int root, tot;
struct BST{
    int l, r;
    int val;
} a[N];

int new(int val){ //建立新节点
    a[++tot] = val;
    return tot;
}

void build(){
    new(-INF); new(INF);  //建立根节点, 也可以不用, 自己手动用读入的数建树
    root = 1, a[1].r = 2; //root val = -INF
}
```

## (二叉搜索树)
```cpp
BST a[N];
root = 1;
```
怎么插入数据?
---
插入一个数据val, 找到合适的位置, 如果为空, 就建立新节点, 
```cpp
void insert(int &p, int val){
    if(p = 0) { //如果为空, 就建立新节点
        p = New(val);  //因为是引用, 所以其父节点的l, r也会改变
        return;
    }
    
    if(val = a[p].val) return;  //已经有节点了
    if(val < a[p].val) insert(a[p].l, val);  //找合适的位置
    else insert(a[p].r, val);
}
```

## (二叉搜索树)
```cpp
BST a[N];
root = 1;
```
怎么检索特定值val?
---
1. 如果p 的值就等于val, 返回找到了
2. 如果 p 的值大于 val
  1. 如果 p 的左节点为空, 就不存在 val
  2. 如果 p 的左节点存在, 就在 p 的左子树继续检索
    
  
```cpp
int get(int p, int val){
    if(p = 0) return 0;
    if(val = a[p].val) return p;
    return val < a[p].val ? get(a[p].l, val) : get(a[p].r, val);
}
```

## (二叉搜索树)
```cpp
BST a[N];
root = 1;
```
怎么找`val`的前驱/后继?
---
找后继, 初始化`ans = 2` 也就是最大值所在节点, 从根节点找起
1. 若当前的值`a[p].val`大于`val`, 且小于`a[ans].val`, 也就是更优的值, 更新`ans = p`
2. 若当前值`a[p].val = val`, 那就在右子树上找最小值
```cpp
int getNext(int val){
    int ans = 2;
    int p = root;
    while(p){
        if(val = a[p].val){
            if(a[p].r){
                p = a[p].r;
                while(a[p].l) p = a[p].l;
                ans = p;
            }
            break; //如果没有右子树, 你们当前ans 就是后继, 没有再找的必要了
        }
        
        if(a[p].val > val && a[p].val < a[ans].val) ans = p;
        p = val < a[p].val ? a[p].l : a[p].r;
    }
}
```

## (二叉平衡树)
```cpp
BST a[N];
root = 1
```
怎么删除节点?
---
如果这个节点没有左子树或者右子树, 你们就把有的那个放入当前删除的节点的位置, 
如果这个节点有左子树和右子树, 你们就找这个节点的后继, 因为这个后继没有左子树, 把这个把这个后继放入当前位置, 然后用后继的右子树替代后继的位置
```cpp
void remove(int &p, int val) {
    if(p = 0) return;
    if(val = a[p].val){
        if(a[p].r = 0){
            p = a[p].l; //没有右子树, 用左子树替代当前节点
        }else if(a[p].l = 0){
            p = a[p].r;
        }else {
            //找后继
            int next = a[p].r;
            while(a[next].l) next = a[p].l;
            remove(a[p].r, a[next].val); //后继没有左子树, 直接删除
            //用后继替代节点p
            a[next].l = a[p].l, a[next].r = a[p].r;
            p = next;
        }
        return;
    }
    if(val < a[p].val){
        remove(a[p].l, val);
    }else {
        remove(a[p].r, val);
    }
}
```
