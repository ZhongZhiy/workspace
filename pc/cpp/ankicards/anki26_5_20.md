## [Fraction Floor Sum](https://vjudge.net/problem/AtCoder-abc230_e)
给定 n, 求 $\sum_{i = 1}^n \lfloor \frac{n}{i} \rfloor$, $(n \le 10^{12})$
---
数论分块
如果 $\frac{n}{i} \ge k \Rightarrow \frac{n}{k} \ge i$, 这样就找到了区间$\[i, \frac{n}{k} \]$ , 这个区间的 $\frac{n}{i}$ 都等于 k, 通过分块加速求和
```cpp
for(int i = 1, j; i <= n; i = j + 1){
    j = n / (n / i); //右边界
    sum += (n / i) * (j - i + 1);
}
```

## [向后全速前进](https://acm.hdu.edu.cn/contest/problem?cid=1204&pid=1007)
Mashiro 有一个长度为 n 的实数序列 a ，序列的第 i 个元素 $a_i$ 会在区间 $\[l_i,r_i\]$ 中随机等概率生成（在区间 $\[l_i,r_i\]$上服从均匀分布），且每个元素的生成相互独立。

Mashiro 想知道 $\sum_{i=2}^{n} |a_i - a_{i-1}|$ 的期望是多少。

定义 $M=10^9+7$ ，可以证明最终的期望一定是一个有理数，也就是说答案一定可以写成 $\frac{P}{Q}$ 的形式，因此你需要输出 $P \times Q^{M−2} \bmod M$ 的结果。
Input

第一行输入一个正整数 $T(1 \le T \e 10^5)$ 表示数据组数：

对于每组数据：

第一行输入一个正整数 $n(1\e n\e 2\times 10^5) ，表示序列长度。

接下来 n 行，每行输入两个正整数 $l,r(1 le l le r le 10^9)$，表示每一个区间。

数据保证： $\sum n \le 10^6$
---
这个明显是算出每个的公式, 然后在 $O(1)$的时间算出来, 总共$O(n)$

1. 计算 $E(|x - y|) = \int_{l_i}^{r_i} \int_{l_{i-1}}^{r_{i-1}} |x-y|f(x, y)dxdy$
2. 由于 x, y 是独立的, 所以联合分布 $f(x, y) = f(x) \cdot f(y)$
3. $a_i$ 是均匀分布, 概论密度 $f(x) = \frac{1}{r_i - l_i}$
4. 所以 $E(|x - y|) =  \int_{l_i}^{r_i} \int_{l_{i-1}}^{r_{i-1}} |x - y| \frac{1}{r_{i} - l_i} \frac{1}{r_{i-1} - l_{i-1}} dx dy$
5. 现在计算二重积分
$$

E(|x - y|) =  \int_{l_i}^{r_i} \int_{l_{i-1}}^{r_{i-1}} |x - y| \frac{1}{r_{i} - l_i} \frac{1}{r_{i-1} - l_{i-1}} dx dy = \frac{1}{r_{i} - l_i} \frac{1}{r_{i-1} - l_{i-1}}\int_{l_i}^{r_i} (\int_{l_{i-1}}^{r_{i-1}} |x-y|dx) dy
$$

6. 其中 $\int |x-y| dx = (x - y)|x-y|$, $\int (x-y)|x-y| dy = \frac16 |x-y|^3$
7. 反正最后得到 $$E[|X - Y|] = \frac{|r_1 - l_2|^3 + |l_1 - r_2|^3 - |r_1 - r_2|^3 - |l_1 - l_2|^3}{6 \cdot L_1 \cdot L_2}$$

此外注意这里 $1 \le l, r \le n$, 所以可能 $l = r$ 的情况, 需要单独考虑, 不然 分母为0
```cpp
constexpr int M = 1e9 + 7;

// 修复后的快速幂
int qpow(int base, int pow){
    int res = 1;
    base %= M; // 保证 base 在模范围内
    while(pow){
        if(pow & 1) res = (res * base) % M; // 【已修复】检查二进制最低位
        pow >>= 1;
        base = (base * base) % M;
    }
    return res;
}

// 求逆元
int inv(int x){
    return qpow(x, M - 2);
}

// 计算绝对值的三次方并取模
int thr(int x){
    x = abs(x) % M;
    return (x * x % M) * x % M;
}

// 辅助函数：计算 x * |x| 并在模意义下正确处理负号
int sq_sign(int x) {
    int abs_x = abs(x) % M;
    int res = (abs_x * abs_x) % M;
    if (x < 0) {
        res = (M - res) % M;
    }
    return res;
}

void solve(){
    int n; 
    cin >> n;
    vector<pii> p(n + 1);
    
    fi(n){
        cin >> p[i].first >> p[i].second;
    }

    int ans = 0;

    // 从 2 到 n 开始计算相邻期望
    for(int i = 2; i <= n; ++i) {
        int l1 = p[i-1].first, r1 = p[i-1].second;
        int l2 = p[i].first, r2 = p[i].second;

        int L1 = r1 - l1;
        int L2 = r2 - l2;
        int pair_exp = 0;

        // 【已修复】特判情况 1：两个区间都是点
        if (L1 = 0 && L2 == 0) {
            pair_exp = abs(l1 - l2) % M;
        }
        // 【已修复】特判情况 2：第一个区间是正常区间，第二个是点
        else if (L1 > 0 && L2 = 0) {
            int num = (sq_sign(r1 - l2) - sq_sign(l1 - l2) + M) % M;
            int den = (2 * L1) % M;
            pair_exp = num * inv(den) % M;
        }
        // 【已修复】特判情况 3：第一个区间是点，第二个是正常区间
        else if (L1 = 0 && L2 > 0) {
            int num = (sq_sign(r2 - l1) - sq_sign(l2 - l1) + M) % M;
            int den = (2 * L2) % M;
            pair_exp = num * inv(den) % M;
        }
        // 情况 4：两个都是普通区间，使用通用的二重积分公式
        else {
            int t = thr(r1 - l2) + thr(l1 - r2) - thr(r1 - r2) - thr(l1 - l2);
            t = (t % M + M) % M; // 【已修复】防止取模出现负数

            // 防止 L1 * L2 溢出，先取模
            int den = (6 * (L1 % M) % M) * (L2 % M) % M;
            int q = inv(den);
            
            pair_exp = t * q % M;
        }

        ans = (ans + pair_exp) % M;
    }

    cout << ans << endl; // 【已修复】移到循环外面，每组数据只输出一次
}

signed main() {
    hello;
    int t; 
    cin >> t;
    while(t--) {
        solve();
    }
    world;
}
```

## [怪演?二十面?相](https://acm.hdu.edu.cn/contest/problem?cid=1204&pid=1009)
Mutsumi 和她的好朋友 Mortis 正在玩一个跑酷游戏，这个跑酷游戏的规则比较特殊：

游戏中有 $n+2$ 个格子，格子的编号从 0 到 $n+1$ ，每个格子的颜色是红、黑、白中的一个，其中第 i 个格子的颜色为 $s_i$ ，在第 i 个格子进行跳跃可以跳到第 $j(i \le j \le n+1)$个格子上。

现在，Mutsumi 和 Mortis 操纵着同一个游戏角色，Mutsumi 操纵时游戏角色只能跳到红色、白色的格子上，Mortis 操纵时游戏角色只能跳到黑色、白色的格子上，每进行一次跳跃都需要切换玩家（即游戏角色的操纵者，且切换玩家时游戏角色的位置不会修改），初始时操纵游戏角色的玩家是 Mutsumi 。

每一轮游戏初始时 Mutsumi 在第 0 个格子，跳到第 $n+1$ 个格子后一轮就会结束，第 0 个格子和第 $n+1$ 个格子的颜色都为白色。每一个红色或黑色的格子在所有轮次中只能经过一次，也就是说不能有两轮或更多轮经过同一个红色或黑色的格子。

Mutsumi 和 Mortis 想知道，至少需要几轮游戏才能经过所有的格子至少一次？
Input

第一行输入一个正整数 $T(1 \le T \le 2×10^5)$，表示数据组数。

对于每一组数据：

第一行输入一个仅包含 ′R′、′B′、′W′ 三种字符的字符串 s ， $s_i=′R′,s_i=′B′,s_i=′W′$ 分别表示第 i 个格子颜色为红色、黑色、白色。

数据保证 $\sum n \le 2×10^6$ 。
---
也就是从 R 可以到 W 和 B, 从 B 可以到 R 和 W, 且可能没有注意到的一点 **可以跳到$j(i \le j \le n+1)$, 也就是可以跳到同一个格子, 也就是 在白色格子的可以原地跳一跳换人**

由于 红色和黑色都只能跳一次, 我们考虑一个人, 又长又一次从 0 到 $n+1$, 也可以考虑是 **多个人同时跳, 并且经过所有的格子**, 遇到红色格子的时候, 只有从黑色/白色格子跳过来, 遇到白色格子, 只有从黑色/白色格子跳过来, 而遇到白色格子的话, 白色格子可以站多个人, 那么所有红色/黑色格子的人都可以到白色的格子上, 如果遇到没有足够的已有的人, 就添加人, 这样就得到最少需要多少人能经过一次的情况下占领所有的格子 
```cpp
void solve(){
    string s; cin >> s;
    int cntr = 0, cntb = 0, cntw = 0, ans = 0;//在i之前, r, b, w的个数
    for(int i = 0;i < s.size(); ++i){
        if(s[i] = 'R'){  //遇到红色, 优先选择黑色格子移动过来, 其次黑色, 再次新增一个
            if(cntb) cntr++, cntb--;
            else if(cntw) cntr++, cntw--;
            else cntr++, ans++;
        }else if(s[i] = 'B'){
            if(cntr) cntb++, cntr--;
            else if(cntw) cntb++, cntw--;
            else cntb++, ans++;
        }else {
            if(cntw || cntb || cntr) cntw += cntb + cntr , cntb = 0, cntr = 0;
            else cntw++, ans++;
        }
    }
    cout << ans << endl;
}
```

## [组合数学]
怎么算组合数?
---
1. 预处理 **阶乘和阶乘逆元**, $O(n)$
```cpp
constexper N = 2e6 + 10;
int fact[N], invf[N];
void init(){
    fact[0] = 1;
    for(int i = 1;i < N; ++i) fact[i] = fact[i-1] * i;

    invf[N-1] = inv(fact[N-1]); //因为 n! 的逆元, 相当于 1/(n!) = (n + 1) * (1/((n+1)!)), 也就是 invf[n] = (n + 1) * invf[n+1];
    for(int i = N-2; i >= 0; --i) invf[i] = (i + 1) * invf[i+1];
}
```

2. 计算组合数 `combine(n, m)`, 处理边界
```cpp
int combine(int n, int m){
    if(n < 0 || m < 0 || n < m) return 0; //边界, 一定注意
    return fact[n] * invf[m] * invf[n - m];
}
```

## [E-Count 123](https://atcoder.jp/contests/abc458/tasks/abc458_e)
### 题目描述

求满足以下所有条件的长度为 $X_1+X_2+X_3$ 的序列 $A = (a_1, \cdots, a_{X_1 + X_2 + X_3})$ 的个数，对 $998244353$ 取模。

-   $A$ 中恰好包含 $X_1$ 个 $1$、恰好包含 $X_2$ 个 $2$，以及恰好包含 $X_3$ 个 $3$。
-   相邻元素的绝对差至多为 $1$。也就是说，对于每个满足 $1 \leq i \leq X_1+X_2+X_3-1$ 的整数 $i$，都有 $|a_{i+1} - a_i| \leq 1$。

-   $1 \leq X_1, X_2, X_3 \leq 10^6$
-   All input values are integers.
---
题目要求相邻之差不超过 1, 意味着, 1 和 3不能相邻, 1 和 3之间需要用 2 分割, 

`_2_2_ ... _2_`, 有 x2 + 1 个位置, 可以选其中 i 个空位插入 1, 选其中 j 个空位插入 3, 

代数表达 $\binom{x2 + 1}{i} \binom{x2 + 1 - i}{j}$, 然后把 1 分成 i 份, 把 3 分成 j 份, 代数表达为 $\binom{x1-1}{i-1} \binom{x3-1}{j-1}$

总的表达式:
$$\sum_{i=1}^{x1} \sum_{j=1}^{x3} \binom{x2 + 1}{i} \binom{x2 + 1 - i}{j}\binom{x1-1}{i-1} \binom{x3-1}{j-1}$$

双层循环会超时, 利用范德蒙德恒等式优化, 
根据范德蒙德恒等式（Vandermonde's Convolution）的变形：$\sum_k \binom{n}{k}\binom{m}{r-k} = \binom{n+m}{r}$，我们可以将这个内层求和直接坍缩为一个单一的组合数：

$$\sum_{j=1}^{X_3} \binom{X_2 + 1 - i}{j} \binom{X_3 - 1}{X_3 - j} = \binom{(X_2 + 1 - i) + (X_3 - 1)}{X_3} = \binom{X_2 + X_3 - i}{X_3}$$

将化简后的内层项代回原式，我们得到了一个仅需单层循环的终极公式：$$\text{Total Sequences} = \sum_{i=1}^{X_1} \binom{X_2 + 1}{i} \binom{X_1 - 1}{i - 1} \binom{X_2 + X_3 - i}{X_3}$$

```cpp
constexpr int M = 998244353;
int inv(int x){
    int pow = M - 2;
    int res = 1;
    while(pow){
        if(pow & 1) res = (res * x) % M;
        x = (x * x) % M;
        pow >>= 1;
    }
    return res;
}
constexpr int N = 3e6 + 10;
int fact[N], invfact[N];
int combine(int n, int m){
    if(n < 0 || m < 0 || n < m) return 0;
    return fact[n] * invfact[n-m] % M * invfact[m] % M;
}
void init(){
    fact[0] = 1; invfact[0] = 1;
    for(int i = 1; i < N; ++i) fact[i] = (fact[i-1] * i) % M;
    invfact[N-1] = inv(fact[N-1]);
    for(int i = N - 2; i >= 0;--i) invfact[i] = invfact[i+1] * (i + 1) % M;
}
void solve(){
    init();
    int x1, x2, x3; cin >> x1 >> x2 >> x3;

    int res = 0;
    for(int i = 1;i <= x1; ++i){
        res = (res + combine(x2+1, i) % M * combine(x1- 1, i - 1) % M * combine(x2+x3-i, x3) % M) % M;
    }
    cout << res << endl;
}
```

## [狄利克雷卷积]
数论函数 $f(x)$ 和 $g(x)$ 的狄利克雷卷积记作 $f * g$, 定义为数论函数:
$$(f * g)(n) = \sum_{kl = n}f(k)g(l) = ?$
---
$$(f * g)(n) = \sum_{k | n}f(k)g(\frac{n}{k} = \sum_{kl = n}f(k)g(l))$$
