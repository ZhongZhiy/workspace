# 算法
## 什么是“隐式分层图”？

<!-- notecardId: 1768023363370 -->
不实际建立物理上的多层图，而是在 Dijkstra 算法运行过程中通过增加“状态维度”来模拟分层的技术。

## 在分层图中，`dist[u][k]` 数组的含义通常定义为？

<!-- notecardId: 1768023363382 -->
到达节点 $u$ 时，已经使用了 $k$ 次优惠券（或处于第 $k$ 层状态）的最短路径长度。

## 为了支持分层图，优先队列中的节点结构体（Node）除了包含 `u` 和 `dist`，还需要增加哪个关键变量？

<!-- notecardId: 1768023363386 -->
`k`（记录当前已使用的优惠券数量或当前所处的层数）。



## 在分层图 Dijkstra 中，状态转移主要分为哪两类？

<!-- notecardId: 1768023363390 -->
1. 层内转移（不使用优惠券，状态不变）；
2. 跨层转移（使用优惠券，跳转到下一层状态）。

## 情况 A：这一站不使用优惠券（层内松弛）。对应的更新逻辑是？

<!-- notecardId: 1768023363393 -->
若 `dist[u][k] + w < dist[v][k]`，则更新 `dist[v][k]` 并将新状态入队。

## 情况 B：这一站使用优惠券（跨层松弛）。对应的更新逻辑是？

<!-- notecardId: 1768023363397 -->
若 `k == 0` 且 `dist[u][0] + w / 2 < dist[v][1]`，则更新 `dist[v][1]` 并将新状态 `(v, 1)` 入队。

## 分层图 Dijkstra 的核心逻辑填空：

<!-- notecardId: 1768023363401 -->
```cpp
// 情况 B: 在这条边用券 (从层 0 跳到层 1)
if(k == 0 && {{c1::dist[u][0] + w/2 < dist[v][1]}}) {
    dist[v][1] = {{c2::dist[u][0] + w/2}};
    pq.push({v, 1, dist[v][1]});
}

```




## 为什么说分层图最短路是“最短路 + DP”的结合？

<!-- notecardId: 1768023363405 -->

因为它在最短路寻优的过程中，利用 多维数组 维护了不同决策阶段（如用了几次券）的 最优子结构。


## 隐式分层图 Dijkstra 的初始化逻辑：

<!-- notecardId: 1768023363409 -->

除了 `dist[起点][0]` 设为 0，其余所有 `dist[i][j]` 均应初始化为 {{c1::无穷大 (INF)}}。
