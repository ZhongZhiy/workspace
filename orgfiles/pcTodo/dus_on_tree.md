同学，你能顺藤摸瓜，在学完概念后立刻索要树上启发式合并（DSU on Tree）的实战例题，这种“举一反三”的驱动力绝对是顶级选手的标配！

DSU on Tree 的应用场景非常明确：**“没有修改操作（离线），全都是对子树信息的查询，且强依赖于颜色、频次或深度”**。

为了让你从入门到彻底打通任督二脉，教练为你精心挑选了 **4 道必刷经典母题**，难度从基础模板到终极 Boss 递进。

---

### 🟢 级别一：绝对的启蒙与模板题

**🏆 Codeforces 600E - Lomsat gelral**

* **题目大意：** 给定一棵 $N$ 个节点的树（$N \le 10^5$），每个节点有一个颜色 $c_i$。对于每一个节点 $u$，求其子树中**出现次数最多**的所有颜色的编号之和。
* **为什么是它：** 这是全世界公认的 DSU on Tree “原教旨”母题！它完全没有任何弯弯绕绕，就是最纯粹的求子树众数。
* **破局思路：**
1. 如果每个节点暴力开一个 `map` 然后向上合并，常数极大。
2. 真正的 DSU on Tree 工业写法是：**维护一个全局的计数数组 `cnt[]` 和一个全局答案变量**。
3. **核心 DFS 签名：** `void dfs(int u, int p, bool keep)`。
* 先遍历所有轻儿子（`keep = false`），遍历完后**把它们对全局 `cnt[]` 的贡献清空**（抹除痕迹）。
* 最后遍历重儿子（`keep = true`），遍历完后**不清空**。
* 再把轻儿子和自己的颜色重新加回全局 `cnt[]` 里，此时全局数组里的状态恰好就是 $u$ 子树的完整状态，直接记录答案！
* 如果当前处于轻儿子的分支，退出前清空全局状态。

### 🟡 级别二：深度与状态结合

**🏆 Codeforces 1009F - Dominant Indices**

* **题目大意：** 给定一棵 $N$ 个节点的树。对于每个节点 $u$，定义 $d(u, x)$ 为节点 $x$ 到 $u$ 的距离。设 $c_k$ 为 $u$ 的子树中距离 $u$ 恰好为 $k$ 的节点数量。你需要为每个 $u$ 找到一个最小的 $k$，使得 $c_k$ 最大。
* **为什么是它：** 级别一统计的是“颜色”，级别二统计的是“深度”。这道题教你如何用 DSU on Tree 处理与树的深度（层数）相关的统计。
* **破局思路：**
和 600E 几乎一模一样，只是把统计颜色的 `cnt[color]` 换成了统计深度的 `cnt[depth]`。当你在全局数组里动态维护各个深度的节点数量时，随时更新当前子树的“众数深度”。重儿子的深度数组直接保留，轻儿子的暴力加入。

### 🟠 级别三：离线查询与位运算降维

**🏆 Codeforces 570D - Tree Requests**

* **题目大意：** 一棵 $N$ 个节点的树，每个节点上有一个英文字母。给定 $M$ 次查询（$M \le 5 \times 10^5$），每次查询给出一个节点 $v$ 和一个深度 $h$。问：在 $v$ 的子树中，所有深度为 $h$ 的节点上的字母，能否**重新排列组合成一个回文串**？
* **为什么是它：** DSU on Tree 不仅能算答案，还能**回答离线查询**！
* **破局思路：**
1. **回文判定降维：** 能够重组成回文串，等价于“最多只有一个字母出现了奇数次”。我们可以用一个 26 位的**二进制整数 (Bitmask)** 来表示各个字母出现的奇偶性。如果这个整数等于 0 或者恰好是 2 的整数次幂（利用 `x & (x - 1) == 0` 判断），就能构成回文。
2. **离线：** 把所有查询按照节点 $v$ 挂载起来。
3. **合并：** 在 DSU on Tree 的过程中，全局维护 `mask[h]` 表示当前子树下深度为 $h$ 的字母状态。处理完 $v$ 节点（包括继承重儿子、加上轻儿子）后，直接回答挂在 $v$ 上的所有查询！

### 🔴 级别四：终极 Boss 战（大厂高频困难题）

**🏆 Codeforces 741D - Arpa’s letter-marked tree and Mehrdad’s magic**

* **题目大意：** 一棵边上带字母的树。对于每个节点 $v$，求其子树中**最长的一条简单路径**，使得路径上经过的边上的字母可以重新排列成一个回文串。
* **为什么是它：** 这道题结合了 DSU on Tree 的最高阶用法——不仅要求单个节点的信息，还要求**跨越根节点（LCA）的路径组合最优解**！如果你能独立 AC 这道题，说明你对树上启发式合并已经登峰造极了。
* **破局思路：**
1. 根节点到 $x$ 路径的字母奇偶状态设为 $mask[x]$。两点 $x, y$ 之间路径的回文条件是：$mask[x] \oplus mask[y]$ 等于 0 或 $2^k$。
2. 在遍历到节点 $u$ 时，我们需要在它的子树里找两个分属不同分支的点，拼接成最长路径。
3. 全局维护 `max_depth[mask]`。遍历轻儿子时，先用轻儿子里的节点去和全局 `max_depth` 匹配更新答案，然后再把轻儿子加入到全局状态中。完美体现了“边组合，边合并”的思想！

### 💡 教练的建议：该如何刷？

不要一上来就去用 `map` 的 `swap`，虽然好写，但常数极大，容易超时。
**我强烈建议你先去写 Codeforces 600E。** 尝试用 **“全局数组 + `keep` 标记位”** 的工业级标准写法。

**标准模板的大纲（供你在脑海中推演）：**

```cpp
void add(int u, int p, int val) {
    // 将 u 及其子树的所有节点加入或移出全局数组
    cnt[color[u]] += val;
    // ...更新最大值等...
    for(int v : adj[u]) {
        if(v != p && v != heavy_child_of_current_root) 
            add(v, u, val);
    }
}

void dfs(int u, int p, bool keep) {
    // 1. 先递归处理轻儿子，不保留它们的数据 (keep=false)
    for(int v : adj[u]) 
        if(v != p && v != heavy[u]) dfs(v, u, false);
        
    // 2. 递归处理重儿子，保留数据 (keep=true)
    if(heavy[u]) {
        dfs(heavy[u], u, true);
        heavy_child_of_current_root = heavy[u]; // 标记当前重儿子，防止在 add 里被重复遍历
    }
    
    // 3. 把轻儿子和自己暴力加进全局数组
    add(u, p, 1);
    
    // 4. 此时全局数组就是 u 的完整子树状态，记录答案
    ans[u] = current_best_sum;
    
    // 5. 收尾：如果当前是轻儿子分支，清理现场，深藏功与名
    heavy_child_of_current_root = 0; 
    if(!keep) {
        add(u, p, -1);
        current_best_sum = 0;
        current_max_cnt = 0;
    }
}

```

先拿 600E 练手，把这个 `keep` 传参的思想融会贯通，你会发现树上启发式合并实际上是一种极其暴力但被数学规律（重链剖分）完美约束的暴力美学！
