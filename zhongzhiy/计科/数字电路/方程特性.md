下面用“时序电路/有限状态机（FSM）”的语境，说明这三个方程分别是什么、怎么写、各自干啥。你可以把它们当成对一个时序电路的**数学三件套**：谁来驱动记忆元件、记忆怎么更新、输出怎么产生。

---

## 1. 驱动方程（Excitation / Drive Equation）

**它描述：要让触发器/寄存器在下一拍变成想要的值，当前输入该给什么。**

- 适用对象：触发器（D、JK、T、SR 等）
    
- 形式：**触发器输入 = 当前状态 + 外部输入 的逻辑函数**
    

举例：

### D 触发器

因为 DFF 的特性是  
[  
Q^{+} = D  
]  
所以驱动方程就是：  
[  
D = f(Q, X)  
]  
意思是：D 端应该由当前状态 Q 和外部输入 X 组合出来。

### JK 触发器

JK 的下一状态为  
[  
Q^{+}=J\bar Q + \bar K Q  
]  
但“驱动方程”问的是：为了得到某个 (Q^{+})，J 和 K 应该怎么给。  
所以驱动方程写成：  
[  
J=f_J(Q,X),\quad K=f_K(Q,X)  
]

**一句话**：驱动方程是“**触发器输入端的逻辑表达式**”。

---

## 2. 状态方程（State Equation / Next-State Equation）

**它描述：时钟来一拍之后，状态（寄存器输出）怎么更新。**

- 形式：  
    [  
    Q^{+} = F(Q, X)  
    ]  
    其中：
    
- (Q)：当前状态（现态）
    
- (X)：外部输入
    
- (Q^{+})：下一状态（次态）
    

举例：  
如果你用 D 触发器实现 FSM，并且驱动方程得到  
[  
D = Q\oplus X  
]  
那么由于 (Q^{+}=D)，状态方程就是：  
[  
Q^{+}=Q\oplus X  
]

**一句话**：状态方程是“**状态更新规律**”。

---

## 3. 输出方程（Output Equation）

**它描述：电路输出由什么决定。**

输出方程有两类（Moore / Mealy）：

### Moore 型 FSM

输出只依赖当前状态：  
[  
Y = G(Q)  
]

### Mealy 型 FSM

输出依赖当前状态 + 外部输入：  
[  
Y = G(Q, X)  
]

举例：

- 若某电路在状态 Q=1 时输出 1，否则输出 0  
    [  
    Y=Q  
    ]
    
- 若输出是状态和输入的与  
    [  
    Y=Q\cdot X  
    ]
    

**一句话**：输出方程是“**输出的组合逻辑表达式**”。

---

## 三者关系一眼看懂的流程

1. **先定状态变量 Q**（用触发器存）
    
2. **写驱动方程**：算每个触发器的输入端该接什么  
    [  
    D\ / J,K\ / T = f(Q,X)  
    ]
    
3. **由触发器特性推出状态方程**  
    [  
    Q^{+} = F(Q,X)  
    ]
    
4. **再写输出方程**  
    [  
    Y = G(Q)\ \text{或}\ G(Q,X)  
    ]
    

---

## 小例子（完整三件套）

电路：1 位状态 Q，输入 X，要求下一拍 Q 变成 Q⊕X，输出 Y=Q。

- **驱动方程（DFF）**  
    [  
    D = Q\oplus X  
    ]
    
- **状态方程**（因为 (Q^{+}=D)）  
    [  
    Q^{+} = Q\oplus X  
    ]
    
- **输出方程（Moore）**  
    [  
    Y=Q  
    ]
