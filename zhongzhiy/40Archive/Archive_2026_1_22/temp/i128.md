在 C++ 标准中，最大的整数类型是 `long long`（64 位）。但在竞赛编程和高精度计算中，我们经常需要处理超过 $10^{18}$ 但在 $10^{38}$ 范围内的数字。

这时，GCC 和 Clang 编译器提供的 **`__int128`** 就派上用场了。它占据 128 位（16 字节），范围约在 $-1.7 \times 10^{38}$ 到 $1.7 \times 10^{38}$ 之间。

---

## 1. 基础定义与范围

`__int128` 并不是 C++ 标准的一部分，而是编译器的扩展。

- **有符号型**：`__int128` 或 `__int128_t`
    
    - 范围：$-2^{127} \sim 2^{127}-1$（约 $3.4 \times 10^{38}$）
        
- **无符号型**：`unsigned __int128`
    
    - 范围：$0 \sim 2^{128}-1$
        

> **注意**：由于它不是标准类型，你不能直接使用 `cin >> x` 或 `cout << x`，也不能直接写 `128LL` 这样的后缀字面量。

---

## 2. 自定义输入与输出 (I/O)

这是使用 `__int128` 最麻烦的地方。你需要手写快读（Fast I/O）或使用字符串转换。

### 核心代码模板

C++

```
#include <iostream>
#include <string>
#include <algorithm>

using namespace std;

// 处理 __int128 的读入
__int128 read() {
    __int128 x = 0, f = 1;
    char ch = getchar();
    while (ch < '0' || ch > '9') {
        if (ch == '-') f = -1;
        ch = getchar();
    }
    while (ch >= '0' && ch <= '9') {
        x = x * 10 + ch - '0';
        ch = getchar();
    }
    return x * f;
}

// 处理 __int128 的输出
void print(__int128 x) {
    if (x < 0) {
        putchar('-');
        x = -x;
    }
    if (x > 9) print(x / 10);
    putchar(x % 10 + '0');
}

int main() {
    __int128 a = read();
    __int128 b = read();
    __int128 sum = a + b;
    
    printf("Sum is: ");
    print(sum);
    putchar('\n');
    
    return 0;
}
```

## 3. 使用技巧与陷阱

### 字面量赋值

由于没有 128 的后缀，如果直接写 __int128 x = 12345678901234567890123; 编译器会报错（因为它先当成 long long 处理）。

正确做法：使用字符串转换或先通过基础类型组合。

C++

```
__int128 x = (__int128)1e18 * 1e18; // 这样是可以的
```

### 运算性能

- **加减法**：非常快，几乎和 `long long` 一样。
    
- **乘除法**：由于 CPU 通常没有 128 位的原生指令，乘除法是通过软件模拟实现的，速度会比 `long long` 慢不少，但远快于你自己写的高精度类（BigInt）。
    

### 标准库支持

- **`std::abs`**：不支持。请手动实现：`x < 0 ? -x : x`。
    
- **`std::max / std::min`**：支持，因为它们是模板。
    
- **`std::sort` / `std::vector`**：完美支持。
    

---

## 4. 什么时候该用它？

1. 防止中间结果溢出：
    
    比如计算 $(a \times b) \pmod m$，如果 $a, b, m$ 都是 $10^{18}$ 级别，a * b 会爆 long long。此时用 (__int128)a * b % m 可以在不写快速乘的情况下直接得出正确结果。
    
2. 几何运算：
    
    计算三点共线的向量叉积（Cross Product）时，坐标如果是 $10^9$，平方后是 $10^{18}$，差值可能会略微超过 long long。
    

---

## 5. 常见错误：printf 格式化

你不能用 %d 或 %lld 来打印 __int128。

如果你非要用 printf，可以先转成字符串：

C++

```
string to_str(__int128 x) {
    if (x == 0) return "0";
    string s = "";
    while (x > 0) {
        s += (char)(x % 10 + '0');
        x /= 10;
    }
    reverse(s.begin(), s.end());
    return s;
}
```
