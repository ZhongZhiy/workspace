# 算法



## KMP 算法在最坏情况下的时间复杂度是多少？相比于暴力解法的 $O(nm)$ 有何优势？
$O(n+m)$；它将时间复杂度优化到了线性时间。

## Border 的定义：对于字符串的一个子串，如果它既是该子串的 {{c1::真前缀}}，又是该子串的 {{c2::真后缀}}，则称其为该子串的一个 Border。

<!-- notecardId: 1767857779493 -->

## KMP中前缀函数 $\pi[i]$ 的定义是什么？
子串 $s[0 \dots i]$ 的最长 Border 的长度。



## KMP 算法的核心原理是：在发生失配时，利用已匹配部分的 {{c1::Border 信息}} 来滑动模式串，从而避免了 {{c2::文本串指针的回溯}}。

<!-- notecardId: 1767857779501 -->

## 在计算前缀函数时，若 $s[i] \neq s[j]$（$j$ 为当前匹配长度），应如何调整 $j$？
`j = pi[j - 1]`，利用已知的失配信息向前回跳，寻找更短的 Border。

## 拼接字符串技巧：为了查找模式串 $P$ 在文本串 $T$ 中的位置，可以构造新串 {{c1::$P + \# + T$}}，并计算其 {{c2::前缀函数（Next 数组/pi 数组）}}。

## 在使用 $P + \# + T$ 技巧时，若 $\pi[i] = |P|$，则表示在当前位置找到了一个完整的模式串，其在原文本串中的起始下标为 {{c1::$i - 2 \cdot |P|$}}。

## KMP 算法代码实现填空（计算 pi 数组）：

<!-- notecardId: 1767857779518 -->
```cpp
for (int i = 1; i < n; i++) {
    int j = pi[i - 1];
    while (j > 0 && s[i] != s[j])
        {{c1::j = pi[j - 1]}};
    if (s[i] == s[j])
        j++;
    pi[i] = j;
}

```

## KMP 中的 `next` 指针（前缀函数）与 AC 自动机中的哪个概念异曲同工？

fail 指针（失配指针），它们都指向当前状态匹配到的最长后缀。
