## [GCD](https://acm.hdu.edu.cn/contest/problem?cid=1231&pid=1005)

给定一个 $n(1 \le n \le 10^18)$ , 每次操作把 $n$ 分成两个数 $a, b$, 其中 $n = a \times b \text{且} max{a, b} > 1$, 然后把 $a, b$ 作为新的数来操作, 求最多进行多少次操作?

---

根据算术基本定理 $n = \prod_{i=1}^k p_i^{c_i}$, 其中 $p_i$ 为质数, $c_i$ 为指数.

那么每次操作就是把最大的素数的指数分成两份, 求能分成多少次, 那么就需要求 $n$ 的最大素因数指数

可以算出 $\sqrt[3]{n}$, 内的数, 剩下的$n$, 要不是一个大素数, 要不是一个大素数的平方

```cpp
void solve(){
    int x; cin >> x;
    int mx = 1;
    for(int i = 2; i * i * i <= x; ++i){
        int cnt = 0;
        while(x%i=0) x/= i, cnt++;
        mx = max(cnt, mx);
    }

    int sq = sqrt(x);
    while((sq+1) <= x / (sq+1)) sq--;
    while(sq < x/sq) sq++;
    if(sq * sq = x) mx = max(mx, 2LL);

    int ans = 0;
    while(mx) mx>>=1, ans++;
    cout << ans << endl;
}
```

## [构造题](https://icpc.upc.edu.cn/problem.php?cid=4581&pid=3)

构造 $n$ 个点 $m$ 条边的有向无环图, 1 是起点, n 是终点, 满足对于 $0~p$中的每个数都能通过保留部分边使得从 1 到 n 的不同路径数等于 $i$, 

输出构造的边和 对于 $i$ 需要保留哪些边

确保 $n \le 24, m \le 65, p \le 75000$ 

---

如果构造二分类似
```sh
1  2    4   6   8   10  12  14.......24
   3    5   7   9   11  13  15.......
```

点和边都能对应上, 但是总数是不够的, 因为点边消耗过多, 

因此要构造斐波拉契数列, 23 到 24 一个边, 22 到 23, 24 一个边, 一直, 2 到 3, 4 一个边, 这样 23 到 24 有 1 个边, 22 到 24 有 2 个边, 21 到 24 有 $1 + 2 = 3$ 个边

> 齐肯多夫定理（Zeckendorf's theorem）：任何正整数都可以表示为若干个不连续的斐波那契数之和。

只要每次贪心选择最大的斐波拉契数列就可以了

```cpp
void solve(){
    int p; cin >> p;
    cout << 24 << ' ' << 65 << endl;
    vector<pii> e;
    for(int i = 2;i <= 23; ++i){
        e.push_back({1, i});
    }

    for(int i = 23; i >= 2; --i){
        e.push_back({i, i+1});
        if(i+2 <= 24)e.push_back({i, i+2});
    }

    for(auto [u, v] : e) {
        cout << u << ' ' << v << endl;
    }

    vector<int> w(25, 0);
    w[24] = 1;
    w[23] = 1;
    for(int i = 22; i >= 2; --i) w[i] = w[i+1]+w[i+2];

    for(int i = 0;i <= p; ++i){
        string ans(65, '1');
        int cur = i;

        for(int node = 2; node <= 23; ++node) {
            int edge_idx = node-2;
            if(cur >= w[node]) {
                cur -= w[node];
                ans[edge_idx] = '1';
            }else {
                ans[edge_idx] = '0';
            }
        }
        cout << ans << endl;
    }
}
```

## [甲苯先生的字符串]

# P5337 [TJOI2019] 甲苯先生的字符串(https://www.luogu.com.cn/problem/P5337)

### 题目背景


时间限制: 1s 内存限制: 128M

### 题目描述

一天小甲苯得到了一条神的指示，他要把神的指示写下来，但是又不能泄露天机，所以他要用一种方法把神的指示记下来。神的指示是一个字符串，记为字符串 $s_1$，$s_1$ 仅包含 $26$ 个小写字母。现在小甲苯想要写下神的指示，记为字符串 $s_2$，$s_2$ 仅包含 $26$ 个小写字母，要求 $s_1$ 中的相邻的两个字母不能在 $s_2$ 中相邻地出现。现在给定 $s_2$ 的长度，小甲苯想知道他有多少种方法可以将神的指示写下来。输出种类数结果对 $10^9+7$ 取模。

### 输入格式

第一行只有一个正整数 $n$，代表字符串 $s_2$ 的长度。 

第二行是一个字符串，代表字符串 $s_1$。

### 输出格式

输出一个整数，表示小甲苯可以写出的字符串的总数。结果对 $10^9+7$ 取模。

### 输入输出样例 #1

### 输入 #1

```
2
ab

```

### 输出 #1

```
675

```

### 说明/提示

对于 $30\%$ 的数据 $n\le100000$。

对于 $100\%$ 的数据 $1 \le n\le10^{15}$，$|s_1| \le 10^5$。

说明：相邻要求顺序相同，如样例中的 $s_2$ 里不能出现 $\text{ab}$，且仅不能出现 $\text{ab}$，但可以出现 $\text{ba}$。

---

怎么识别从DP到矩阵快速幂

### 第一步：朴素 DP 的“步步为营”（识别线性递推）

如果题目中的长度 $N$ 只有 $10^5$，我们一定会毫不犹豫地写出这样的动态规划：

* **状态定义**：设 $dp[i][j]$ 表示长度为 $i$，且最后一个字符是 $j$ 的合法字符串总数。
* **转移方程**：要想知道长度为 $i$ 且以 $j$ 结尾的方案数，就要把上一步（长度 $i-1$）所有能接上 $j$ 的字符 $k$ 的方案数加起来。

$$dp[i][j] = \sum_{k=0}^{25} dp[i-1][k] \times \text{valid}(k \to j)$$



*(其中如果 $k$ 后面能接 $j$，$\text{valid}$ 就是 1，否则是 0)*。

**痛点**：这个过程是一层套一层的 `for` 循环，时间复杂度是 $O(N \times 26^2)$。当 $N=10^{15}$ 时，直接超时。

___

### 第二步：发现破局的“不变量”（提取转移矩阵）

遇到超大 $N$ 时，教练教你的第一反应应该是**盯着转移方程，寻找“不变量”**。
在这个方程中，什么是从头到尾绝对不会变的？——**是那张表示能不能相连的规则表（$\text{valid}$ 函数）！**

无论你是从第 2 个字符推第 3 个，还是从第 100 万个推第 100 万零 1 个，“谁能接谁”的规则是永恒固定的。
既然规则固定，我们完全可以把这套规则打包成一个 $26 \times 26$ 的**状态转移矩阵 $M$**。

把第 $i$ 步的所有状态打包成一个一维行向量 $V_i = [dp[i][0], dp[i][1], \dots, dp[i][25]]$。
这时候，神奇的维度转换发生了，DP 的求和公式在数学上完美等价于**向量乘以矩阵**：


$$V_i = V_{i-1} \times M$$

___

### 第三步：结合律带来的“降维打击”（引入快速幂）

既然每往前走一步，就等于在数学上乘一次矩阵 $M$，那么我们把它展开：

* 走 2 步：$V_2 = V_1 \times M$
* 走 3 步：$V_3 = V_2 \times M = (V_1 \times M) \times M = V_1 \times M^2$
* 走 $N$ 步：
$$V_N = V_1 \times M^{N-1}$$



走到这一步，我们完成了最核心的跨越：**把一个需要执行 $N-1$ 次的 DP 循环，变成了一个纯粹的数学求幂公式。**

为什么求幂就快？因为矩阵乘法满足**结合律**（即 $A \times (B \times C) = (A \times B) \times C$）。
这就意味着我们不需要傻傻地乘 $N-1$ 次。我们可以算 $M^2$，再拿 $M^2 \times M^2$ 得到 $M^4$，再得到 $M^8 \dots$
利用**二进制拆分（快速幂算法）**，我们可以把 $O(N)$ 的时间复杂度，瞬间降维打击到 $O(\log N)$。
对于 $10^{15}$ 的数据，$\log_2(10^{15})$ 仅仅只有 50 左右。这就是从“跑一万年”到“一毫秒出答案”的底层逻辑。

___

### 第四步：物理意义的最终缝合（图论视角的验证）

为了让你更加确信这种做法的正确性，我们可以用图论的视角再看一眼：

* **初始状态**：把 26 个字母看作图上的 26 个顶点。
* **矩阵 $M$ 的意义**：如果两个字母可以相连，对应顶点之间就有一条长度为 1 的有向边（矩阵中填 1），否则没边（填 0）。
* **矩阵 $M^K$ 的意义**（离散数学经典定理）：邻接矩阵的 $K$ 次幂，其结果矩阵中的元素 $M^K[i][j]$，严格等于**从顶点 $i$ 走到顶点 $j$，恰好经过 $K$ 条边的路径总数**。

因为长度为 $N$ 的字符串恰好包含 $N-1$ 个字符间隙（即走 $N-1$ 条边），所以我们求出 $M^{N-1}$ 后，矩阵里所有的数字加起来，就是全图所有合法的路径总数，也就是题目要求的合法字符串总数。

### 💡 考场条件反射总结（你的“外脑”插件）

以后在赛场上，只要看到满足以下**三个特征**的题：

1. **状态数极少**：比如字母表 26 个，或者状态数在 100 以内。
2. **转移规则恒定**：当前状态只跟前驱状态有关，没有随时间/步数变化的常数项或系数。
3. **步数（规模 $N$）大得离谱**：比如 $N \ge 10^9$ 或 $N \le 10^{18}$。

## [K - Stones](https://atcoder.jp/contests/dp/tasks/dp_k)

### 题目描述

有一个由 $N$ 个正整数构成的集合 $A = \\{ a &#95; 1, a &#95; 2, \ldots, a &#95; N \\}$。太郎和次郎将按照以下规则进行游戏。

初始时，有一堆包含 $K$ 块石子的石堆。两名玩家从太郎开始，交替执行以下操作：

-   从 $A$ 中选择一个元素 $x$，并从石堆中恰好移除 $x$ 块石子。

当一名玩家无法进行操作时，该玩家判负。假设双方均采取最优策略，请确定获胜者。

### Constraints

-   All values in input are integers.
-   $1 \leq N \leq 100$
-   $1 \leq K \leq 10^5$
-   $1 \leq a_1 < a_2 < \cdots < a_N \leq K$

---
对博弈的不太熟练, 设 `dp[i]` 表示当前还有 i 个石头的时候能不能赢, 

那么初始化 `dp[0] = 0`, 没有石头必败

而 NP 博弈, **任何能转移到必败态的, 都是必胜态**, 所有转移是 `if(dp[i-a[j]] = 0) dp[i] = 1`

```cpp
void solve(){
    int n, k; cin >> n >> k;
    vi a(n + 1);
    fi(n) cin >> a[i];
    sort(a.begin()+1, a.end());

    vi dp(k + 1);
    dp[0] = 0;
    for(int i = 1;i <= k; ++i){
        for(int j = 1;j <= n; ++j){
            if(i >= a[j] && dp[i-a[j]] = 0) {
                dp[i] = 1;
                break;
            }
        }
    }
    if(dp[k]) cout << "First\n";
    else cout << "Second\n";
}
```

## [Deque](https://atcoder.jp/contests/dp/tasks/dp_l)

### 题目描述

太郎和次郎将进行如下游戏。

初始时，他们获得一个序列 $a = (a &#95; 1, a &#95; 2, \ldots, a &#95; N)$。在 $a$ 变为空之前，两名玩家从太郎开始交替执行以下操作：

-   移除 $a$ 开头或结尾的元素。该玩家获得 $x$ 分，其中 $x$ 是被移除的元素。

设游戏结束时太郎的总得分为 $X$，次郎的总得分为 $Y$。太郎的目标是最大化 $X - Y$，而次郎的目标是最小化 $X - Y$。

假设两名玩家均采取最优策略，求最终的 $X - Y$ 值。

### Constraints

-   All values in input are integers.
-   $1 \leq N \leq 3000$
-   $1 \leq a_i \leq 10^9$

---

博弈, 区间DP, 

因为 $n \le 3000$ 可以用 O(n^2) 的 DP 解决, 而每次都从两端取值, 所以考虑区间DP

状态定义应该统一, 就不用考虑谁取的, A 最大化 $X - Y$, B 最小化 $X - Y$, 其实就是相当于 **最大化** $Y - X$, 所以统一DP状态为 `dp[i][j]` 是在区间 `[i, j]` 上当前这个人分数 - 前一个人的分数的 **净最大值**, 

因此状态转移为 `dp[i][j] = max(a[i] - dp[i+1][j], a[j] - dp[i][j-1])`

```cpp
void solve(){
    int n; cin >> n;
    vi a(n + 1);
    fi(n) cin >> a[i];

    vector<vi> dp(n + 1, vi(n + 1+1));
    fi(n) dp[i][i] = a[i];
    for(int len = 2;len <= n; ++len){
        for(int i = 1;i + len -1<= n; ++i) {
            dp[i][i+len-1] = max(a[i] - dp[i+1][i+len-1], a[i+len-1] - dp[i][i+len-2]);
        }
    }
    cout << dp[1][n] << endl;
}

```

```cpp
dp[i][j] = dp[i-1][j] + dp[i-1][j-1] + ... + dp[i-1][j-a[i]]
```

是个前缀和, 可以用前缀和优化一下, 但是我在转移的时候考虑到 `j - a[i]` 可能小于 `0` ，取错了,

```cpp
void solve(){
    int n, k; cin >> n >> k;
    vi a(n + 1);
    fi(n) cin >> a[i];

    vector<vi> dp(n + 1, vi(k + 1));

    vi sum(k + 1);
    dp[0][0] = 1;

    constexpr int M = 1e9 + 7;

    for(int i = 1;i <= n;++i){
        sum[0] = dp[i-1][0];

                dp[i][j] = sum[j];
            }
        }
    }

}
```

## [J - Sushi](https://atcoder.jp/contests/dp/tasks/dp_j)

### 题目描述

有 $N$ 个盘子，编号为 $1, 2, \ldots, N$。初始时，对于每个 $i$（$1 \leq i \leq N$），第 $i$ 个盘子上有 $a &#95; i$（$1 \leq a &#95; i \leq 3$）片寿司。

太郎将重复执行以下操作，直到所有寿司都被吃完：

-   掷一个均匀的骰子，其可能结果为 $1, 2, \ldots, N$，设出现的数字为 $i$。如果第 $i$ 个盘子上还有寿司，则吃掉其中一片；如果没有，则什么也不做。

求在吃完所有寿司之前，操作执行次数的数学期望。

### Constraints

-   All values in input are integers.
-   $1 \leq N \leq 300$
-   $1 \leq a_i \leq 3$

---

### 首先明确在这里期望是什么

例如, 一枚硬币, 投中正面就赢, 投中反面就输, 那么期望是多少?
$$
E = 1 + \frac{1}{2} \times 0 + \frac{1}{2} \times E  \\
E = 2
$$

现在你站在起点，手里拿着硬币，准备抛第 1 次：$$E = \underbrace{1}_{\text{第 1 步成本}} + \underbrace{\frac{1}{2} \times 0}_{\text{情况 A：成功}} + \underbrace{\frac{1}{2} \times E}_{\text{情况 B：失败}}$$

- $+1$ 的含义：不管这次抛出正面还是反面，你都已经消耗了 1 次抛硬币的机会。这个 $1$ 是固定付出的成本。
- $\frac{1}{2} \times 0$ 的含义（情况 A）：你有 $\frac{1}{2}$ 的概率抛出正面。一旦抛出正面，你就立刻通关了！后续还需要抛 $0$ 次。所以这种情况后续的贡献是 $\frac{1}{2} \times 0 = 0$。
- $\frac{1}{2} \times E$ 的含义（情况 B，最关键的一步！）：你有 $\frac{1}{2}$ 的概率抛出反面。如果抛出反面，你原地不动。重点来了：因为硬币没有记忆，你现在的状态和 1 分钟前刚站在起点时一模一样！既然和刚开始一模一样，那么从现在这个瞬间开始算起，你平均还需要抛的次数，依然是 $E$ 次！所以这种情况后续的期望贡献是 $\frac{1}{2} \times E$。

### 对应到这道题中:

我们把四种可能（3片盘、2片盘、1片盘、空盘）全部加起来，列出包含 $E(i, j, k)$ 的全期望方程：
$$E(i, j, k) = \underbrace{1}_{\text{掷 1 次骰子}} + \underbrace{\frac{i}{N} E(i-1, j+1, k) + \frac{j}{N} E(i, j-1, k+1) + \frac{k}{N} E(i, j, k-1)}_{\text{成功砸中非空盘（状态变小了，前面已经算好了）}} + \underbrace{\frac{N - (i+j+k)}{N} E(i, j, k)}_{\text{【重点】砸中空盘（原地不动，还剩 E(i,j,k) 次）}}
$$

### 解这个方程:

就像刚才把 $\frac{1}{2}E$ 移到等式左边一样，我们把右边的 $\frac{N - (i+j+k)}{N} E(i, j, k)$ 移到左边:
- 移项：
$$E(i, j, k) - \frac{N - (i+j+k)}{N} E(i, j, k) = 1 + \frac{i}{N} E(i-1, j+1, k) + \frac{j}{N} E(i, j-1, k+1) + \frac{k}{N} E(i, j, k-1)$$
- 提公因式 $E(i, j, k)$：$$\left(1 - \frac{N - (i+j+k)}{N}\right) \cdot E(i, j, k) = 1 + \frac{i}{N} E(i-1, j+1, k) + \frac{j}{N} E(i, j-1, k+1) + \frac{k}{N} E(i, j, k-1)$$
- 通分化简括号里项：$$1 - \frac{N - (i+j+k)}{N} = \frac{N - (N - (i+j+k))}{N} = \mathbf{\frac{i+j+k}{N}}$$
- 代回原式：$$\frac{i+j+k}{N} \cdot E(i, j, k) = 1 + \frac{i}{N} E(i-1, j+1, k) + \frac{j}{N} E(i, j-1, k+1) + \frac{k}{N} E(i, j, k-1)$$
- 两边同时乘以 $\frac{N}{i+j+k}$，解出 $E(i, j, k)$：$$E(i, j, k) = \frac{N}{i+j+k} + \frac{i \cdot E(i-1, j+1, k) + j \cdot E(i, j-1, k+1) + k \cdot E(i, j, k-1)}{i+j+k}$$

### 注意
- 如果取得的是 3个面包的盘子, 取后会变成 2 个面包
- 盘子间没区别, 也就是只用统计 1, 2, 3 的个数

### 编码

定义: `dp[i][j][k]` 表示有 `i` 个 3 片面包, `j` 个 2 片面包, `k` 个 1 片面包时的期望步数.

为什么要倒着呢, 因为状态转移公式 `dp[i][j][k] = n/(i+j+k) + i* dp[i-1][j+1][k]/(i+j+k) + j* dp[i][j-1][k+1]/(i+j+k)+k*dp[i][j][k-1]/(i+j+k)`, 中, 需要用到 `j+1, k+1`, 如果倒着来就算需要未来的数了, 

最后优化, 只用到来 `i, i-1`两层, 所以可以用滚动数组优化

```cpp
                if(j > 0) res += j*dp[i%2][j-1][k+1]/m;
```

### 题目描述

-   $N$ is an integer.
-   $2 \leq N \leq 3000$
-   $s$ is a string of length $N - 1$.
-   $s$ consists of `<` and `>`.

---
插入DP:
> 这类题目的核心特征是：要求构造一个 $1 \sim N$ 的排列，且条件只与相邻元素（或相对位置）的比较关系相关。

怎么想的?

不需要关心“用了哪些具体数字”，只需要关心当前数字在已填入数字中的“相对排名”。

定义状态 $dp[i][j]$：$dp[i][j]$ 表示已经填好了前 $i$ 个数字（形成的相对排列），且第 $i$ 个数字 $p_i$ 在这 $i$ 个数字中处于相对第 $j$ 小（$1 \leq j \leq i$）时的合法方案数。

现在，我们要从前 $i-1$ 个数字的状态 $dp[i-1][k]$（其中 $1 \leq k \leq i-1$），转移到第 $i$ 个数字的状态 $dp[i][j]$：

当我们把第 $i$ 个新数字放入序列时，我们将它置为前 $i$ 个数字中的第 $j$ 小。此时，原本在前 $i-1$ 个数字中处于相对第 $k$ 小的 $p_{i-1}$：

如果原先 $k < j$，那么加入第 $j$ 小的 $p_i$ 后，$p_i$ 严格大于 $p_{i-1}$（即满足 $p_{i-1} < p_i$）。

如果原先 $k \ge j$，那么加入第 $j$ 小的 $p_i$ 后，原本的 $k$ 被挤到了后面（变成了第 $k+1$ 小），即满足 $p_{i-1} > p_i$。


## [U - Grouping](https://atcoder.jp/contests/dp/tasks/dp_u)

### 题目描述

有 $N$ 只兔子，编号为 $1, 2, \ldots, N$。

对于每一对 $i, j$ （$1 \leq i, j \leq N$），兔子 $i$ 与 $j$ 的相容性由一个整数 $a &#95; {i, j}$ 描述。其中，对于每个 $i$ （$1 \leq i \leq N$），有 $a &#95; {i, i} = 0$；且对于任意 $i$ 和 $j$ （$1 \leq i, j \leq N$），有 $a &#95; {i, j} = a &#95; {j, i}$。

太郎要将这 $N$ 只兔子分成若干组。这里，每只兔子必须恰好属于一个组。分组完成后，对于每一对 $i$ 和 $j$ （$1 \leq i &lt; j \leq N$），如果兔子 $i$ 和 $j$ 属于同一组，太郎将获得 $a &#95; {i, j}$ 分。

求太郎可能获得的最大总分数。

### Constraints

-   All values in input are integers.
-   $1 \leq N \leq 16$
-   $|a_{i, j}| \leq 10^9$
-   $a_{i, i} = 0$
-   $a_{i, j} = a_{j, i}$

---
数据量极小, 子集枚举是可行

### 数据范围

兔子数量 $N$：$1 \le N \le 16$。$N \le 16$ 是极具代表性的信号：$2^{16} = 65,536$。

如果枚举所有掩码（Mask）的所有子集（Submask），运算次数为：

$$\sum_{k=0}^{N} \binom{N}{k} 2^k = (1 + 2)^N = 3^N$$

当 $N = 16$ 时，$3^{16} = 43,046,721 \approx 4.3 \times 10^7$ 次运算。

定义 DP 状态 $dp[S]$：$dp[S]$ 

表示将集合 $S$ 中的兔子进行任意合法分组所能获得的最大总得分。

为了计算 $dp[S]$，我们可以考虑拆分集合 $S$：

从集合 $S$ 中剥离出某一个单独的小组 $sub$（$sub \subseteq S$ 且 $sub \neq \emptyset$），剩下的兔子集合为 $S \setminus sub$（即 S ^ sub）。

根据加法原理与最优子结构：$$dp[S] = \max_{sub \subseteq S, \; sub \neq \emptyset} \Big( cost[sub] + dp[S \setminus sub] \Big)$$物理意义：

把集合 $S$ 切成两部分——一部分 $sub$ 作为一个整体小组（得分为 $cost[sub]$），剩下的 $S \setminus sub$ 则交由子问题 $dp[S \setminus sub]$ 去寻找其最优分组。

边界条件（Base Case）：$dp[0] = 0$（没有兔子时得分为 0）。对于任意非空集合 $S$， $dp[S]$ 可以初始化为 $cost[S]$（即“不拆分，全员一组”的基础方案）。

```cpp
void solve(){
    int n; cin >> n;
    vector<vi> a(n, vi(n));
    fi0(n)fj0(n) cin >> a[i][j];

    int mask = (1LL<<n);
    vector<int> s(mask);
    //计算所有掩码的得分
    for(int i = 0;i < mask; ++i){
        for(int j = 0;j < n; ++j){
            if(i>>j&1){
                for(int k = j+1;k < n; ++k){
                    if(i>>k&1){
                        s[i] += a[j][k];
                    }
                }
            }
        }
    }

    vector<int> dp(mask);
    for(int i = 0;i < mask ;++i){
        dp[i] = s[i];
        for(int sub = i; sub > 0; sub = (sub-1)&i){
            dp[i] = max(dp[i], s[sub]+dp[i^sub]);
        }
    }
    cout << dp[mask-1] << endl;
}
```

## [V - Subtree](https://atcoder.jp/contests/dp/tasks/dp_v)

### 题目描述

有一棵包含 $N$ 个顶点的树，顶点编号为 $1, 2, \ldots, N$。对于每个 $i$（$1 \leq i \leq N - 1$），第 $i$ 条边连接顶点 $x &#95; i$ 和 $y &#95; i$。

Taro 决定将每个顶点涂成白色或黑色，要求任意两个黑色顶点之间仅通过黑色顶点即可相互到达。

给定一个正整数 $M$。对于每个 $v$（$1 \leq v \leq N$），回答以下问题：

-   假设顶点 $v$ 必须为黑色，求顶点涂色方案的数量，结果对 $M$ 取模。

### Constraints

-   All values in input are integers.
-   $1 \leq N \leq 10^5$
-   $2 \leq M \leq 10^9$
-   $1 \leq x_i, y_i \leq N$
-   The given graph is a tree.

---



* **题目本质**：在一棵包含 $N$ 个节点的树上，给顶点涂成黑色或白色。要求**所有黑色节点必须构成树上的一个连通块**（即任意两个黑节点之间的路径上全都是黑节点）。
* **核心任务**：对于每个顶点 $v \in \{1, 2, \ldots, N\}$，**强制要求 $v$ 染成黑色**，求满足条件的合法染色方案数，结果对 $M$ 取模。
* **注意**：模数 $M$ 是一个任意给定的正整数（$2 \leq M \leq 10^9$），**不保证是质数**！

___


### 1. 局部点出发（单根视角：DFS1）

假设我们先任意选定节点 **1** 作为整棵树的根。

定义 $dp[u]$：

> **表示在以 $u$ 为根的子树中，当 $u$ 强制为黑色时，子树内部形成合法连通黑块的方案数。**

对于节点 $u$ 的任意一个子节点 $v$：

* **若 $v$ 染成白色**：由于黑色节点必须连通，一旦 $v$ 为白，$v$ 子树内部的所有节点**都不能再出现黑色**，否则无法连回 $u$。因此整个 $v$ 子树只有 **1 种全白方案**。
* **若 $v$ 染成黑色**：$v$ 子树内部必须形成包含 $v$ 的连通黑块，方案数为 **$dp[v]$**。

根据乘法原理，子节点 $v$ 提供的选择因子为 $(dp[v] + 1)$（其中 $+1$ 代表子树全白）。把所有子节点累乘起来：

$$dp[u] = \prod_{v \in \text{children}(u)} (dp[v] + 1) \pmod M$$

___

### 2. 全局换根推导（自顶向下：DFS2）

如果我们想求出每个节点 $v$ 的全局答案，就需要知道“$v$ 上方（父节点方向）”的贡献。

定义 $dp_{up}[u]$：

> **表示在 $T \setminus T_u$（即砍掉 $u$ 的子树后剩下的部分）中，当 $u$ 的父节点 $p$ 强制为黑色时，上方形成的合法连通黑块方案数。**

当我们把决策视角从父节点 $u$ 传递给它的第 $i$ 个子节点 $v_i$ 时，$v_i$ 接收到的上方总贡献由两部分组成：

1. **来自 $u$ 祖先方向的贡献**：$(dp_{up}[u] + 1)$；
2. **来自 $v_i$ 的兄弟节点方向的贡献**：$\prod_{j \neq i} (dp[v_j] + 1)$。

因此，转移方程为：

$$dp_{up}[v_i] = \underbrace{(dp_{up}[u] + 1)}_{\text{祖先贡献}} \times \underbrace{\prod_{j \neq i} (dp[v_j] + 1)}_{\text{兄弟贡献}} \pmod M$$

最终，对于任何节点 $u$，以它为黑节点的全图总方案数为：

$$ans[u] = dp[u] \times (dp_{up}[u] + 1) \pmod M$$

___

### 3. 破局关键：如何优雅计算“除去 $v_i$ 后的兄弟乘积”？

由于 $M$ 不是质数，我们不能用 $\frac{dp[u]}{dp[v_i] + 1}$ 来算兄弟乘积。

**解决方案**：
对节点 $u$ 的所有子节点 $[v_1, v_2, \ldots, v_k]$：

1. 预处理**前缀积数组** $pref[i] = \prod_{j=1}^{i} (dp[v_j] + 1) \bmod M$；
2. 预处理**后缀积数组** $suff[i] = \prod_{j=i}^{k} (dp[v_j] + 1) \bmod M$；
3. 对于第 $i$ 个子节点 $v_i$，其“其他兄弟节点的乘积”直接等于：

$$pref[i - 1] \times suff[i + 1] \pmod M$$



完全避开了除法与逆元！

___

```cpp
constexpr int N = 1e5 + 10;
int n, m; vi e[N]; int dp[N], dp_up[N];

void dfs(int u, int fa){
    dp[u] = 1;
    for(auto v : e[u]){
        if(v = fa) continue;
        dfs(v, u);
        dp[u] = (dp[u] * (dp[v]+1))%m;
    }
}

int ans[N];
void dfs2(int u, int fa){
    ans[u] = (dp[u] * (1 + dp_up[u])) % m;
    vi child;
    for(auto v : e[u]){
        if(v = fa)continue;
        child.push_back(v);
    }

    int sz  = child.size();

    vi pre(sz+2), suf(sz + 2);

    for(int i = 0;i < sz; ++i){
        pre[i] = (i?pre[i-1]:1)*(dp[child[i]]+1)%m;
    }
    for(int i = sz-1;i >= 0;--i){
        suf[i] = (i=sz-1?1:suf[i+1])*(dp[child[i]]+1)%m;
    }

    for(int i = 0;i < sz; ++i){
        int v = child[i];
        dp_up[v] = (dp_up[u]+1)%m;
        if(i > 0) dp_up[v] = dp_up[v] * (pre[i-1])%m;
        if(i < sz-1) dp_up[v] = dp_up[v] * (suf[i+1])%m;
        dfs2(v, u);
    }
}

void solve(){
    cin >> n>> m;
    fi(n-1) {
        int u, v; cin >> u >> v;
        e[u].push_back(v);
        e[v].push_back(u);
    }
    dfs(1, 0);
    dfs2(1, 0);
    fi(n){

    }
}
```

### 直觉的诞生：从朴素的 $O(N^2)$ DP 开始

考虑从左到右逐个确定字符串的字符。决定当前字符填 `1` 还是 `0` 时，我们唯一关心的是：**上一个 `1` 在哪？**（因为只有 `1` 才能触发区间的得分）。

我们可以定义状态：
设 $DP[i][j]$ 表示处理完前 $i$ 个字符，且**最后一个 `1` 放在了位置 $j$**（$0 \leq j \leq i$，$j=0$ 表示全 0）时的最大得分。

当从 $i-1$ 推导到 $i$ 时：

* **情况 A（第 $i$ 位填 `0`）：** 最后一个 `1` 的位置 $j$ 不变。
* **情况 B（第 $i$ 位填 `1`）：** 最后一个 `1` 的位置变成了 $i$。此时 $DP[i][i] = \max_{0 \leq j < i} DP[i-1][j]$。

**分数的结算（核心难点）：**
一个区间 $[l, r]$ 何时能确定是否得分？
**扫描线思想登场：** 当我们枚举到区间的右端点 $i = r$ 时，这个区间的命运就彻底定了。
如果最后一个 `1` 的位置 $j \geq l$，那么区间内必然有 `1`，获得 $a$ 分；
如果最后一个 `1` 的位置 $j < l$，那么区间内全是 `0`，不得分。

所以，当来到第 $i$ 个字符时，对于所有右端点 $r = i$ 的区间 $[l, i, a]$，我们只需要给所有 $DP[i][j]$（其中 $j \in [l, i]$）集体加上 $a$ 即可。

### 降维打击：从 $O(N^2)$ 到 $O(N \log N)$

观察上面的转移，我们发现：

1. 第一维 $i$ 根本没用！我们可以只维护一个一维数组 $DP[j]$。
2. 每次到新的 $i$，我们需要做三件事：
* 查最大值：找到 $DP[0 \dots i-1]$ 的最大值，这就是 $DP[i]$ 的初值。
* 单点修改：把计算好的初值赋给 $DP[i]$。
* 区间修改：对于所有在 $i$ 结束的区间，把 $a$ 加到 $DP[l \dots i]$ 上。



**结论/性质：** 查区间最值 + 区间加法 + 单点修改 $\implies$ 纯正的**线段树**操作！我们直接用一棵维护 $0$ 到 $N$ 的线段树来替代 $DP$ 数组。

___


这类问题属于经典的 **扫描线 DP（Sweep-line DP）** 或 **线段树优化 DP**。

**通用「模板套路」：**

1. **区间排序绑定：** 遇到区间条件，按**右端点**排序，或者用邻接表把区间挂载到右端点上。
2. **状态定义为末态：** 状态定义永远是“最近一次关键操作（如填 1）的位置”。
3. **线段树代打：** 用线段树维护 DP 数组的滚动更新。从左到右遍历 $i$，先用线段树求出当前决策的最优解并单点插入，接着立刻把所有右端点为 $i$ 的区间的贡献以**区间加法**的形式打到线段树上。

### 肌肉记忆触发点

下次在赛场上，只要看到以下三大特征的组合：

* **0/1 序列构造** 或者 **选择若干个点**。
* **区间限制条件**（如区间内至少有 $X$ 个、或者区间包含某个点就有收益）。
* 要求**最大化/最小化总权重**，且数据范围 $\ge 10^5$。
**请立刻条件反射：** 右端点挂载区间 + 枚举当前位置 + 线段树维护 `[最后一个点的位置]` 的收益！

```cpp
#include <iostream>
#include <vector>
#include <algorithm>

using namespace std;

const long long INF = 1e16; // 足够大的无穷小，防止越界或干扰

struct Interval {
    int l;
    long long a;
};

// 线段树节点
struct Node {
    long long max_val;
    long long lazy;
};

vector<Node> tree;

void push_up(int node) {
    tree[node].max_val = max(tree[2 * node].max_val, tree[2 * node + 1].max_val);
}

void push_down(int node) {
    if (tree[node].lazy != 0) {
        long long lz = tree[node].lazy;
        // 下传给左儿子
        tree[2 * node].max_val += lz;
        tree[2 * node].lazy += lz;
        // 下传给右儿子
        tree[2 * node + 1].max_val += lz;
        tree[2 * node + 1].lazy += lz;
        
        tree[node].lazy = 0;
    }
}

// 区间加法
void update(int node, int start, int end, int l, int r, long long val) {
    if (r < start || end < l) return;
    if (l <= start && end <= r) {
        tree[node].max_val += val;
        tree[node].lazy += val;
        return;
    }
    push_down(node);
    int mid = start + (end - start) / 2;
    update(2 * node, start, mid, l, r, val);
    update(2 * node + 1, mid + 1, end, l, r, val);
    push_up(node);
}

// 区间查最大值
long long query(int node, int start, int end, int l, int r) {
    if (r < start || end < l) return -INF;
    if (l <= start && end <= r) return tree[node].max_val;
    push_down(node);
    int mid = start + (end - start) / 2;
    long long left_max = query(2 * node, start, mid, l, r);
    long long right_max = query(2 * node + 1, mid + 1, end, l, r);
    return max(left_max, right_max);
}

int main() {
    ios_base::sync_with_stdio(false);
    cin.tie(NULL);

    int N, M;
    if (!(cin >> N >> M)) return 0;

    // 邻接表将区间挂载到对应的右端点
    vector<vector<Interval>> intervals_ending_at(N + 1);
    for (int i = 0; i < M; ++i) {
        int l, r;
        long long a;
        cin >> l >> r >> a;
        intervals_ending_at[r].push_back({l, a});
    }

    // 线段树维护的索引范围是 0 到 N。0 表示全填 0（目前还没出现过 1）
    tree.assign(4 * (N + 1), {-INF, 0});

    // 初始化：没有任何字符时，最后一个 '1' 的位置只能算作 0（边界），此时得分为 0。
    // 使用区间加法的小技巧将 -INF 变成 0
    update(1, 0, N, 0, 0, INF); 

    for (int i = 1; i <= N; ++i) {
        // 第一步：计算 DP[i]。
        // DP[i] 代表当前第 i 位强制填 '1'。
        // 上一个 '1' 的位置 j 可以是 0 到 i-1 之间的任意位置，我们取其最大值。
        long long max_prev = query(1, 0, N, 0, i - 1);
        
        // 单点赋值 DP[i] = max_prev。
        // 因为 tree 中 i 位置初始化是 -INF，所以加上 (max_prev + INF) 刚好抵消成 max_prev
        update(1, 0, N, i, i, max_prev + INF);

        // 第二步：结算所有在 i 结束的区间。
        // 循环体不变量维护：对于每一个刚结束的区间，所有 j >= l 的 DP 状态都满足了该区间条件，必须获得加分 a。
        for (const auto& inter : intervals_ending_at[i]) {
            // j 在 [inter.l, i] 范围内的状态，都能获得 inter.a 的加分
            update(1, 0, N, inter.l, i, inter.a);
        }
    }

    // 全局最优解就是最后 1 的位置在 0 到 N 中的得分最大值
    long long ans = query(1, 0, N, 0, N);
    cout << ans << "\n";

    return 0;
}
```

### 避坑指南（Edge Cases & Common Pitfalls）

1. **`-INF` 的界定问题（极其重要）：** 因为 $a_i$ 可能是负的，如果初值简单设为 `0` 或只设一个比较小的负数，无效状态（比如没赋值的 $DP[i]$）可能会被不断加上正权值，从而成为假的最优解。一定要用绝对值大于 $\sum \vert{}a_i\vert{}$ 的常数作为 `-INF`（如 $10^{16}$）。
2. **单点赋值操作的线段树技巧：** 我们并没有单独写一个 `PointUpdate` 函数，而是巧妙地用 `update(1, 0, N, i, i, max_prev + INF)`。这是因为节点 $i$ 此时仍然保留着初始的 `-INF`，加上 `+ INF` 正好将其归零，再接上 `max_prev`。这一手非常优雅，但千万别写漏了那个 `+ INF`。


## [X - Tower](https://atcoder.jp/contests/dp/tasks/dp_x)

### 题目描述

有 $N$ 个积木，编号为 $1, 2, \ldots, N$。对于每个 $i$（$1 \leq i \leq N$），积木 $i$ 具有重量 $w &#95; i$、坚固度 $s &#95; i$ 和价值 $v &#95; i$。

太郎决定从这 $N$ 个积木中选取一部分，并按某种顺序垂直堆叠成一座塔。此处，塔必须满足以下条件：

-   对于塔中包含的每个积木 $i$，堆叠在它上方的所有积木的重量之和不大于 $s &#95; i$。

求塔中包含的积木的价值之和的最大可能值。

### Constraints

-   All values in input are integers.
-   $1 \leq N \leq 10^3$
-   $1 \leq w_i, s_i \leq 10^4$
-   $1 \leq v_i \leq 10^9$

---

背包DP

### 核心思想/定理：临项交换法（Exchange Argument）
假设我们正在从上往下堆叠（先放顶层，再放底层）。假设有两块相邻的积木，上面的叫 $A$，下面的叫 $B$。目前它们上方已经堆了总重量为 $W$ 的积木。为了让这个局部是合法的，必须满足：

$W \leq s_A$$W + w_A \leq s_B \implies W \leq s_B - w_A$综合起来，如果 $A$ 在上、$B$ 在下，系统能承受的上方最大重量是 $\min(s_A, s_B - w_A)$。

如果我们把 $A$ 和 $B$ 交换位置（$B$ 在上，$A$ 在下），系统能承受的上方最大重量变成 $\min(s_B, s_A - w_B)$。

为了让塔尽可能坚固（即上方能放更多东西），我们希望这种承重上限越大越好。如果 $A$ 在上优于 $B$ 在上，那么必须有：
$$s_B - w_A < s_A - w_B$$

移项可得：
$$s_B + w_B < s_A + w_A$$

确定性的「结论/性质」：从上往下堆叠时，必须将 $w_i + s_i$ 较小的积木放在上面！所以，我们可以直接按照 $w_i + s_i$ 从小到大对所有积木进行预排序。排序后，顺序就被锁死了，问题瞬间退化成一道普通的 0-1 背包题。

## [Z - Frog 3](https://atcoder.jp/contests/dp/tasks/dp_z)

### 题目描述

有 $N$ 块石头，编号为 $1, 2, \ldots, N$。对于每个 $i$（$1 \leq i \leq N$），石头 $i$ 的高度为 $h &#95; i$。此处满足 $h &#95; 1 &lt; h &#95; 2 &lt; \cdots &lt; h &#95; N$。

有一只青蛙初始位于石头 $1$ 上。为了到达石头 $N$，它将重复以下操作若干次：

-   若青蛙当前位于石头 $i$ 上，则跳往以下石头之一：石头 $i + 1, i + 2, \ldots, N$。此处会产生代价 $(h &#95; j - h &#95; i)^2 + C$，其中 $j$ 为落脚的石头。

求青蛙到达石头 $N$ 之前可能产生的最小总代价。

### Constraints

-   All values in input are integers.
-   $2 \leq N \leq 2 \times 10^5$
-   $1 \leq C \leq 10^{12}$
-   $1 \leq h_1 < h_2 < \cdots < h_N \leq 10^6$

---

没想到斜率优化DP
$$dp[i] = dp[j] + (h_i - h_j)^2 + C$$
第 1 步：展开平方式$$dp[i] = dp[j] + h_i^2 - 2h_ih_j + h_j^2 + C$$

第 2 步：极其冷酷地“划清界限”我们现在要人为地把这些项分为三类：
纯 $j$ 派： 只跟 $j$ 有关的项 $\implies dp[j] + h_j^2$

纯 $i$ 派（含常数）： 只跟 $i$ 有关的项 $\implies dp[i] - h_i^2 - C$

混合派： $i$ 和 $j$ 纠缠在一起的项 $\implies -2h_ih_j$

这样我们要求的就是最小化的 斜率 $dp[i]-h_i^2-C$

$$dp[j] + h_j^2 = 2h_i \cdot h_j + (dp[i] - h_i^2 - C)$$

$$\underbrace{dp[j] + h_j^2}_{Y} = \underbrace{2h_i}_{k} \cdot \underbrace{h_j}_{X} + \underbrace{(dp[i] - h_i^2 - C)}_{B}$$

```cpp
const int N = 2e5 + 10;
int n, c;
int h[N], dp[N];
// 核心几何映射：将历史状态抽象为二维平面上的点 (X, Y)
inline int X(int j) {
    return h[j];
}

inline int Y(int j) {
    return dp[j] + h[j] * h[j];
}

void solve() {
    cin >> n >> c;
    for(int i = 1; i <= n; ++i) {
        cin >> h[i];
    }

    deque<int> dq;
    
    // 初始状态：站在第 1 块石头上
    dp[1] = 0;
    dq.push_back(1);

    for(int i = 2; i <= n; ++i) {
        // 当前查询的斜率标尺：k = 2 * h[i]
        int k = 2 * h[i];

        // =
        // 1. 查最优解：队头淘汰过时状态 (查询自变量单调增)
        // =
        while(dq.size() >= 2) {
            int a = dq[0];
            int b = dq[1];
            // 比较斜率 slope(a, b) <= k
            // 即: (Y(b) - Y(a)) / (X(b) - X(a)) <= k
            // 因为高度单调递增，X(b) - X(a) 必定 > 0，可以直接乘过去，不用改变不等号方向
            if (Y(b) - Y(a) <= k * (X(b) - X(a))) {
                dq.pop_front();
            } else {
                break; // 只要第一个没被淘汰，后面的必然更没被淘汰
            }
        }

        // =
        // 2. 状态转移：此时队头必然是完美的最优解
        // =
        int opt_j = dq.front();
        dp[i] = dp[opt_j] + (h[i] - h[opt_j]) * (h[i] - h[opt_j]) + c;

        // =
        // 3. 维护下凸壳：队尾淘汰凹陷点 (斜率单调减)
        // =
        while(dq.size() >= 2) {
            int a = dq[dq.size() - 2];
            int b = dq.back();
            int cur = i;
            
            // 我们需要保证下凸壳的斜率单调递增：slope(a, b) < slope(b, cur)
            // 即判断是否出现了凹陷：slope(a, b) >= slope(b, cur)
            // 移项变形： (Y(b) - Y(a)) / (X(b) - X(a)) >= (Y(cur) - Y(b)) / (X(cur) - X(b))
            // 【极其危险】：Y 的极值可能达到 10^17，X 的极值是 10^6。
            // 交叉相乘会达到 10^23，直接捅穿 unsigned long long 的极限！
            // 【绝杀武器】：强制转型为 __int128_t 进行交叉乘法，降维打击精度问题。
            
            __int128 dy1 = Y(b) - Y(a);
            __int128 dx1 = X(b) - X(a);
            __int128 dy2 = Y(cur) - Y(b);
            __int128 dx2 = X(cur) - X(b);

            if (dy1 * dx2 >= dy2 * dx1) {
                dq.pop_back(); // 破坏了下凸壳，这个 b 点成了废点，踢出！
            } else {
                break;
            }
        }
        
        // 维护完完美的凸壳后，把新产生的点 i 压入队尾
        dq.push_back(i);
    }
    cout << dp[n] << endl;
}
```

## [D. Two Digit Strings](https://codeforces.com/problemset/problem/2242/D)

给定两个仅由数字组成的字符串 $$$a$$$ 和 $$$b$$$。每次操作中，你可以选择这两个字符串中任意一个的两个相邻字符，并将它们替换为它们的和对 $$$10$$$ 取模的结果。例如，对于字符串 $$$57246$$$，通过一次操作可以得到以下字符串：

-   $$$\mathbf{57}246 \rightarrow 2246$$$；
-   $$$5\mathbf{72}46 \rightarrow 5946$$$；
-   $$$57\mathbf{24}6 \rightarrow 5766$$$；
-   $$$572\mathbf{46} \rightarrow 5720$$$；

注意，此类操作后字符串的长度总是**恰好减少 $$$1$$$**。

你可以执行任意多次此类操作（包括零次）。你需要使这两个字符串相等（满足 $$$|a| = |b|$$$ 且对所有从 $$$1$$$ 到 $$$|a|$$$ 的 $$$i$$$ 有 $$$a &#95; i = b &#95; i$$$）。计算最终可能的相等字符串的最大长度。


**输入**

第一行包含一个整数 $$$t$$$（$$$1 \le t \le 2 \cdot 10^3$$$）—— 表示测试用例的数量。

每个测试用例的第一行包含一个字符串 $$$a$$$（$$$1 \le |a| \le 5 \cdot 10^3$$$），仅由数字组成。

每个测试用例的第二行包含一个字符串 $$$b$$$（$$$1 \le |b| \le 5 \cdot 10^3$$$），仅由数字组成。

输入数据的额外约束：所有测试用例的 $$$\sum (|a| + |b|)$$$ 总和不超过 $$$10^4$$$。


---

注意到操作特点: 两数之和模10, 删除后结果相当于模10前缀和删除一个数字, 除了最后一个数字

所以现在相当于求两个数组的最大公共子序列

```cpp
void solve(){
    string a, b; cin >> a >> b;
    int n = a.size(), m = b.size();
    vector<int> pa(n + 1), pb(m + 1);
    for(int i = 0;i < n; ++i) pa[i+1] = (pa[i] + a[i]-'0')%10;
    for(int i = 0;i < m; ++i) pb[i+1] = (pb[i] + b[i]-'0')%10;
    
    if(pa[n] != pb[m]){
        cout << -1 << endl;
        return;
    }
    vector<vi> dp(n + 1, vi(m + 1));
    for(int i = 1;i <= n; ++i){
        for(int j = 1;j <= m; ++j){
            if(pa[i] = pb[j]) dp[i][j] = dp[i-1][j-1]+1;
            else dp[i][j] = max(dp[i-1][j], dp[i][j-1]);
        }
    }
    cout << dp[n][m] << endl;
}
```
