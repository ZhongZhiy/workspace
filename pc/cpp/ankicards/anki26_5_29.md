
# java

## [泛型]

卖票函数, 可能返回卖票成功(购票成功，返回 HTTP 200 状态码和订单的完整 JSON 数据), 也可能返回卖票失败(重点：如果没票了或车次找不到，捕获 Service 抛出的异常，返回 HTTP 400（错误请求）和错误提示), 所以返回类型是什么

```java

public ResponseEntity<放什么> sellTicket(@RequestBody TicketOrder order){}
```
---
`ResponseEntity<?>` 是泛型包装盒, <?> 是个通配符, 什么类型都快可以

## 

用 `post` 方法向 `localhost/sell`发送json, 怎么把这个 json字符串 **反序列化** 为 `TicketOrder` 对象作为参数传递给 `sellTicket()` 函数中
---
使用 `@RequestBody`标签,  放在参数前面, 就会把 json 自动反序列化为这个对象

必须键值对中键名和对象中的变量名一致
```java
@Postmapping("/sell")
public ResponseEntity<?> sellTicket(@RequestBody TicketOrder order){}
```
