这道题是组合数学中极其经典的问题，其答案对应的数列被称为 **卡特兰数 (Catalan Numbers)**。

### 1. 核心前提：$n$ 必须为偶数

一个合法的括号序列必须包含相等数量的左括号 `(` 和右括号 `)`。

- 如果 $n$ 是奇数，合法的括号序列数量直接为 **0**。
    
- 如果 $n$ 是偶数，令 $n = 2k$，其中 $k$ 是括号的对数。
    

### 2. 数学公式

第 $k$ 个卡特兰数 $C_k$ 的计算公式为：

$$C_k = \frac{1}{k+1} \binom{2k}{k} = \frac{(2k)!}{(k+1)! k!}$$

对于 $n=6$（即 $k=3$ 对括号）：

$$C_3 = \frac{1}{3+1} \binom{6}{3} = \frac{1}{4} \times 20 = 5$$

这正好对应了你例子中提到的 5 种序列。

---

### 3. 解题思路与建模

我们可以通过两种方式来理解为什么要用这个公式：

#### A. 折线法（容斥原理）

想象在坐标系中，从 $(0,0)$ 出发：

- 遇到 `(` 向上走一步 $(+1, +1)$。
    
- 遇到 `)` 向下走一步 $(+1, -1)$。
    
- **合法要求：** 路径最终到达 $(2k, 0)$，且过程中**永不降至 $x$ 轴以下**（即任意时刻左括号数 $\ge$ 右括号数）。
    
- 总路径数是 $\binom{2k}{k}$，减去所有越过 $y=-1$ 线的非法路径，得到的结果就是卡特兰数。
    

#### B. 递推关系（动态规划）

任何一个合法的括号序列都可以表示为：`(A)B`。

其中 `A` 和 `B` 都是合法的括号序列（可能为空）。

如果总对数为 $k$，`A` 的对数为 $i$，则 `B` 的对数为 $k-1-i$。

$$C_k = \sum_{i=0}^{k-1} C_i \cdot C_{k-1-i}$$

---

### 4. 算法实现 (C++)

由于你之前的代码模板已经处理了取模和阶乘，直接套用公式 $\binom{2k}{k} \cdot \text{inv}(k+1)$ 是最高效的（$O(n)$）。

C++

```
// 假设 n 是总长度
if (n % 2 != 0) {
    cout << 0 << endl;
    return 0;
}

int k = n / 2;
// 预处理阶乘 fac[] 见你之前的代码
// 计算 C(2k, k)
int ans = fac[2 * k];
ans = (ans * rev(fac[k])) % M;
ans = (ans * rev(fac[k])) % M;

// 最后除以 k + 1，即乘上 k + 1 的逆元
ans = (ans * rev(k + 1)) % M;

cout << ans << endl;
```

### 5. 复杂度分析

- **时间复杂度：** $O(n)$ 用于预处理阶乘或计算组合数。
    
- **空间复杂度：** $O(n)$ 用于存储阶乘数组。
    

### 常见应用场景

卡特兰数不仅解决括号匹配，还出现在以下问题中：

1. **出栈序列：** $n$ 个元素按顺序入栈，有多少种不同的出栈顺序？
    
2. **二叉树计数：** $n$ 个节点能组成多少种不同形态的二叉树？
    
3. **凸多边形三角剖分：** 将 $n+2$ 边形分割成三角形的方法数。
