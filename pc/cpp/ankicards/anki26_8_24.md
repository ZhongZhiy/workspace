## [F. Sum and Product](https://codeforces.com/problemset/problem/1857/F)

你有一个长度为 $$$n$$$ 的数组 $$$a$$$。

你的任务是回答 $$$q$$$ 个查询：给定 $$$x,y$$$，求满足 $$$a &#95; i + a &#95; j = x$$$ 且 $$$a &#95; i \cdot a &#95; j = y$$$ 的数对 $$$i$$$ 和 $$$j$$$（$$$1 \le i  &lt;  j \le n$$$）的个数。

例如，对于数组 $$$[1,3,2]$$$ 和查询 $$$x=3,y=2$$$，答案是 $$$1$$$：

-   $$$i=1$$$ 和 $$$j=2$$$ 不满足条件，因为 $$$1 + 3 = 4$$$ 而非 $$$3$$$，且 $$$1 \cdot 3=3$$$ 而非 $$$2$$$；
-   $$$i=1$$$ 和 $$$j=3$$$ 同时满足两个条件；
-   $$$i=2$$$ 和 $$$j=3$$$ 不满足条件，因为 $$$3 + 2 = 5$$$ 而非 $$$3$$$，且 $$$3 \cdot 2=6$$$ 而非 $$$2$$$；

**Input**

The first line contains one integer $t$ ($1\le t\le 10^4$) — the number of test cases.

The second line of each test case contains one integer $n$ ($1 \le n \le 2\cdot 10^5$) — the length of the array $a$.

The third line of each test case contains $n$ integers $a_1,a_2,\dots,a_n$ ($1 \le |a_i| \le 10^9$) — array $a$.

The fourth line of each test case contains the integer $q$ ($1 \le q \le 2\cdot 10^5$) — the number of requests.

The next $q$ lines contain two numbers each $x$ and $y$ ($1 \le |x|\le 2\cdot 10^9,1\le |y|\le 10^{18}$) — request.

It is guaranteed that the sum of $n$ over all test cases does not exceed $2\cdot 10^5$. This is also guaranteed for the sum of $q$ values.

___

这两个式子会想到一元二次方程的韦达定理:
$$ \begin{cases} x_1+x_2 = -\frac{b}{a} \\
x_1 \cdot x_2 = \frac{c}{a}
$$

那么只要用 $\Delta$ 求出根就可以了, 统计根的个数, 注意答案必须是整数

```cpp
void solve(){
    int n; cin >> n;
    vi a(n + 1);
    fi(n) cin >> a[i];
    map<int ,int> mp;
    fi(n) {
        mp[a[i]]++;
    }

    int q; cin >> q;
    fi(q){
        int x, y; cin >> x >> y;
        int delta = (x*x)-4*y;
        int ans = 0;
        if(delta < 0)  ans = 0;
        else if(delta > 0) {
            int sq = sqrtl(delta);
            while((sq-1)*(sq-1) >= delta) sq--;
            while(sq*sq < delta) sq++;
            if(sq*sq != delta || (x+sq)%2 != 0) ans = 0;
            else ans = mp[(x+sq)/2]*mp[(x-sq)/2];
        }else {
            ans = (mp[x/2]-1)*(mp[x/2])/2;
        }
        cout << ans << ' ';
    }
    cout << endl;
}
```

## [概率论]
#概率论

$n$ 个数随机均匀地由 `[1, m]` 中生成, 求生成的数中第 $i(1 \le i \le n)$ 小的数的期望
___

一段长度为 $m$ 的线段, 随机放上 $n$ 个点, 把这个线段分成了 $n+1$ 段, 每个段的长度的 **期望** 都为 $\frac{m}{n+1}$, 那么每个点的位置从小到大排序, 第一个点就是 $\frac{1}{n+1} \cdot m$, 这就是第 $1$ 小的点了

第二小的点就是前两个段的长度加起来 $\frac{2}{n+1} \cdot m$

#trie
**Front:**
序列经历任意多次的全局 AND、OR、XOR 修改，如何以 $O(1)$ 极速判断当前 31 个比特位中，哪些是仍有区分度的“活跃位”，哪些是已被同化的“死位”？
___
**Back:**
维护两个极限变量 `val0 = 0` 和 `val1 = (1LL << 31) - 1`，让它们同步吃下所有全局修改。
当前活跃掩码 `active_mask = val0 ^ val1`。
结果为 `1` 的位是活跃位，结果为 `0` 的位是死位。

#trie
**Front:**
在处理含有全局 AND/OR 的问题时，为什么“发现 `active_mask` 改变时就对全数组暴力重建 Trie 树”不会 TLE？（阐述其势能分析）
___
**Back:**
因为 AND/OR 导致的比特位“死亡（同化）”是**不可逆**的单向坍缩。

## [语法]

当内存限制 $128 M$ 的时候, 给定 $ 1\le m \times n \le 10^6$ 个 $int$, 使用 $4$ 个 `vector<vector<int>>` 为什么会爆内存?
___
由于 `vector<int>` 本身是个对象, 内部有 $3$ 个指针, 占 $24$ 字节, 每次 `new` 一个 `vetor` 在对堆上时, 操作系统还会附加 $16$ 字节的内存块头部信息, 

当 $n = 10^6, m = 1$ 的时候, 需要创建 $10^6$ 个 `vetor`, 那么就需要
$$
10^6 \times (24 + 16 + 8) = 48 MB
$$

$4$ 个就爆内存了, 可以使用 $1$ 维数组模拟二维数组就可以了

## [问题 F：Optimizing a Map Application](https://icpc.upc.edu.cn/problem.php?cid=4602&pid=5)

在 $n \times n$ 的网格中, 有一个定点为起点 $(u, v)$, 网格中还有 $m$ 个障碍物 $a_i \le x \le b_i , c_i \le y \le d_i$ , 给 $q$ 个查询, 求从起点到 指定点 $(s, t)$ 的最短曼哈顿距离, 如果不可达就输出 $No$, $(1 \le n \le 10^9, 1 \le m \le 200)$
___

由于 $n$ 极大, $m$ 很小, 那么肯定是处理建筑物

1. 把建筑物和周围的空行离散化, 只保留骨架, 也就是建筑物保留 $4$ 个点
2. 把建筑物离散化后的点标记
3. 从起点对每个点跑最短路, 表示从起点到这些点的最短路
4. 每次询问, 就查看询问点周围的四个点, 从起点到周围点的最短路 + 从周围点到询问点的曼哈顿距离就是最短路

```cpp
const long long INF = 2e18; // 足够大的无穷大，防溢出
void solve() {
    int n, u, v;
    // 0 0 0 标志输入结束
    while (cin >> n >> u >> v && (n != 0 || u != 0 || v != 0)) {
        int m;
        cin >> m;
        vector<int> a(m), b(m), c(m), d(m);
        
        vector<int> R, C;
        // 1. 压入边界和起点的行/列
        R.push_back(1); R.push_back(n); R.push_back(u);
        C.push_back(1); C.push_back(n); C.push_back(v);

        for (int i = 0; i < m; ++i) {
            cin >> a[i] >> b[i] >> c[i] >> d[i];
            // 2. 核心避坑：提取障碍边界时，必须包含 a-1 和 b+1 留出“贴墙通道”
            R.push_back(a[i]); R.push_back(b[i]);
            if (a[i] > 1) R.push_back(a[i] - 1);
            if (b[i] < n) R.push_back(b[i] + 1);

            C.push_back(c[i]); C.push_back(d[i]);
            if (c[i] > 1) C.push_back(c[i] - 1);
            if (d[i] < n) C.push_back(d[i] + 1);
        }

        // 3. 排序去重，完成坐标离散化
        sort(R.begin(), R.end());
        R.erase(unique(R.begin(), R.end()), R.end());
        sort(C.begin(), C.end());
        C.erase(unique(C.begin(), C.end()), C.end());

        int r_sz = R.size(), c_sz = C.size();

        // blocked 矩阵维护“骨架节点”是否落在建筑物内部（不变量）
        vector<vector<bool>> blocked(r_sz, vector<bool>(c_sz, false));
        for (int k = 0; k < m; ++k) {
            // 用二分快速锁定建筑物在离散化矩阵中的坐标闭区间
            int r1 = lower_bound(R.begin(), R.end(), a[k]) - R.begin();
            int r2 = lower_bound(R.begin(), R.end(), b[k]) - R.begin();
            int c1 = lower_bound(C.begin(), C.end(), c[k]) - C.begin();
            int c2 = lower_bound(C.begin(), C.end(), d[k]) - C.begin();
            for (int i = r1; i <= r2; ++i) {
                for (int j = c1; j <= c2; ++j) {
                    blocked[i][j] = true;
                }
            }
        }

        // 定位起点在离散图中的下标
        int u_idx = lower_bound(R.begin(), R.end(), u) - R.begin();
        int v_idx = lower_bound(C.begin(), C.end(), v) - C.begin();

        // 4. Dijkstra 求核心网格的最短路
        vector<vector<long long>> dist(r_sz, vector<long long>(c_sz, INF));
        using State = pair<long long, pair<int, int>>;
        priority_queue<State, vector<State>, greater<State>> pq;

        dist[u_idx][v_idx] = 0;
        pq.push({0, {u_idx, v_idx}});

        int dr[] = {-1, 1, 0, 0};
        int dc[] = {0, 0, -1, 1};

        while (!pq.empty()) {
            auto top_elem = pq.top();
            pq.pop();
            long long d_curr = top_elem.first;
            int r_idx = top_elem.second.first;
            int c_idx = top_elem.second.second;

            if (d_curr > dist[r_idx][c_idx]) continue;

            for (int dir = 0; dir < 4; ++dir) {
                int nr = r_idx + dr[dir];
                int nc = c_idx + dc[dir];
                // 边界判断，且目标节点不能是障碍物内部
                if (nr >= 0 && nr < r_sz && nc >= 0 && nc < c_sz && !blocked[nr][nc]) {
                    // 相邻节点的物理权重 = 实际坐标差的绝对值
                    long long weight = abs(R[nr] - R[r_idx]) + abs(C[nc] - C[c_idx]);
                    if (dist[r_idx][c_idx] + weight < dist[nr][nc]) {
                        dist[nr][nc] = dist[r_idx][c_idx] + weight;
                        pq.push({dist[nr][nc], {nr, nc}});
                    }
                }
            }
        }

        // 5. 极速响应 O(1) 查询
        int q;
        cin >> q;
        while (q--) {
            int s, t;
            cin >> s >> t;
            
            // 使用二分找出查询点所属的“细胞区间”边界
            int i2 = lower_bound(R.begin(), R.end(), s) - R.begin();
            int i1 = i2;
            if (R[i2] > s) i1 = i2 - 1; // 形成区间 [i1, i2] 包夹 s

            int j2 = lower_bound(C.begin(), C.end(), t) - C.begin();
            int j1 = j2;
            if (C[j2] > t) j1 = j2 - 1; // 形成区间 [j1, j2] 包夹 t

            // 定义指定的大模型强制得分变量
            long long ASYans = INF;
            
            // 候选角只有最多 4 个
            int r_cands[] = {i1, i2};
            int c_cands[] = {j1, j2};

            // 枚举包围该查询点的 4 个角，取转移最小值
            for (int rx : {0, 1}) {
                for (int cx : {0, 1}) {
                    int rr = r_cands[rx];
                    int cc = c_cands[cx];
                    if (dist[rr][cc] != INF) {
                        // 角的骨架最短距离 + 角到查询点的空旷内曼哈顿距离
                        long long cost = dist[rr][cc] + abs(R[rr] - s) + abs(C[cc] - t);
                        ASYans = min(ASYans, cost);
                    }
                }
            }

            // Edge Case: 查无此路 (如被实心墙壁完全密封圈住的空旷区)
            if (ASYans == INF) cout << "no\n";
            else cout << ASYans << "\n";
        }
    }
}
```

## [F - Centroid of a Slice](https://atcoder.jp/contests/abc472/tasks/abc472_f)
###  题目描述

在 $xy$ 平面上有一个凸 $N$ 边形 $P$。$P$ 的顶点按逆时针方向依次编号为 $1,2,\dots,N$，顶点 $i$ 的坐标为 $(x &#95; i,y &#95; i)$。

回答 $Q$ 个询问。

第 $j$ 个询问给出两个不同的顶点 $u &#95; j$ 和 $v &#95; j$。这里，顶点 $u &#95; j$ 和 $v &#95; j$ 在 $P$ 的边界上不相邻。

连接顶点 $u &#95; j$ 和 $v &#95; j$ 的线段将 $P$ 分割成两个多边形；令 $P'$ 为位于从顶点 $u &#95; j$ 指向顶点 $v &#95; j$ 的有向直线右侧的那一个。求 $P'$ 的几何中心坐标（即将多边形内部视为均匀密度的薄板所得到的质心）。

### Constraints

-   $4 \leq N \leq 3 \times 10^4$
-   $1 \leq Q \leq 2 \times 10^5$
-   $|x_i|,|y_i| \leq 5 \times 10^5$
-   $(x_1,y_1),(x_2,y_2),\dots,(x_N,y_N)$ form a convex polygon in counterclockwise order.
-   All interior angles of $P$ are less than $180$ degrees.
-   $1 \leq u_j,v_j \leq N$
-   $u_j \neq v_j$
-   Vertices $u_j$ and $v_j$ are not adjacent on the boundary of $P$.
-   All input values are integers.

### 第 0 阶段：理清题意

* **主体：** 逆时针给出的严格凸 $N$ 边形。
* **操作：** 给出 $Q$ 次查询，每次给出两个点 $u$ 和 $v$，用有向线段 $u \to v$ 将多边形切开。
* **目标：** 求处于有向线段 $u \to v$ **右侧**的那部分多边形 $P'$ 的**几何重心**坐标。
* **约束：** $N \le 3\times 10^4$，$Q \le 2\times 10^5$。坐标绝对值高达 $5\times 10^5$。

---

### 第一阶段：约束分析与前置扫盲

#### 1. 数据范围透视

* $Q = 2 \times 10^5$ 意味着对于每一次查询，我们必须在 $O(1)$ 或 $O(\log N)$ 的时间内出解。绝对不可以每次遍历切出来的多边形的顶点。
* 所有查询是独立的静态查询，这强烈暗示我们需要在 $O(N)$ 的时间里做**预处理（前缀和）**。

#### 2. 知识点与前置依赖

* **核心知识：** 多边形面积公式（Shoelace Formula 鞋带公式）、多边形重心公式。
* **教你避坑（前置提问）：**
> **教练提问：** 你知道为什么这道题就算全程不用浮点数，用 `long long` 也会在计算过程中直接发生**灾难性的溢出**吗？
> *(解析：多边形的坐标最大是 $5 \times 10^5$。鞋带公式里有 $X \times Y$，产生 $10^{11}$ 级别。而求重心的公式里还需要再乘一次坐标，产生 $(X+X) \times (XY-YX)$ 级别的数值，约等于 $5 \times 10^{17}$。前缀和要把 $3 \times 10^4$ 个这样的值加起来，极限值会达到 $1.5 \times 10^{22}$，直接突破了 64 位无符号整数 `ULLONG_MAX` 的天花板！)*

### 第二阶段：思维推导与思想解构

#### 1. "右侧多边形"到底是谁？

因为多边形是逆时针（CCW）给出的严格凸多边形，所以它的边界整体是“向左弯曲”的。
线段 $u \to v$ 是一条多边形内部的弦。相对这条弦，$u$ 到 $v$ 的边界弧线是“鼓向右边”的。
所以，有向线段 $u \to v$ **右侧的多边形**，恰好就是原多边形边界从 $u$ 出发，逆时针一路走到 $v$ 的那些顶点，加上闭合边 $v \to u$ 构成的多边形！
其逆时针顶点序列完美保持为：$u, u+1, u+2, \dots, v$。

#### 2. 核心定理：重心的“边级可加性”

多边形面积 $A$ 和 重心坐标 $(C_x, C_y)$ 的公式本质是对**每一条有向边**的叠加：

* $2A = \sum (x_i y_{i+1} - x_{i+1} y_i)$
* $6A \cdot C_x = \sum (x_i + x_{i+1})(x_i y_{i+1} - x_{i+1} y_i)$
* $6A \cdot C_y = \sum (y_i + y_{i+1})(x_i y_{i+1} - x_{i+1} y_i)$

既然全都是对边 $(i, i+1)$ 的累加求和，我们就能用**前缀和**把一段连续边界 $u \to \dots \to v$ 的和在 $O(1)$ 时间内求出来。

#### 3. 闭环的拼接

切出来的多边形，由两部分边构成：

1. 原多边形的边界弧：从 $u$ 到 $v$（可以利用前缀和 $S[v] - S[u]$ 秒解）。
2. 切割的截断边：从 $v$ 直达 $u$。
我们只需把第一部分的“前缀和差值” 加上 第二部分“单独计算一次边 $v \to u$ 的贡献”，就凑齐了 $P'$ 完整的一圈！

### 第三阶段：母题提炼与破局套路

#### 母题与模型

这道题属于 **“环形数组上的静态区间查询（Prefix Sums on Circular Arrays）”** 结合 **“代数几何运算”** 的母题。

#### 肌肉记忆触发点

下次在赛场上看到以下特征：

1. **关键词：** “凸多边形”、“顶点切分”、“多次查询 (Q很大)”。
2. **立刻条件反射：**
* **破环成链：** 遇到环形多边形，立刻把数组复制一倍拼在后面，长度变为 $2N$。这样当 $u > v$ 时，可以直接让 $v = v + N$，保证区间 $[u, v]$ 是连续的线段。
* **前缀和剥离：** 不要去推导面积的割补法！直接拆解几何公式底层的求和符号 $\sum$，用一维前缀和维护每一项。
* **终极防溢出：** 计算几何涉及面积和重心的多次乘积求和时，永远使用 `__int128_t` 做中间累加。只在最后输出时转浮点型！

### 第四阶段：工业级代码实现

下面为你提供极具美感且无 Bug 的工业级 C++ 代码。已加上本质性注释和避坑指南。

```cpp
#include <iostream>
#include <vector>
#include <iomanip>

using namespace std;

// 避坑：极其重要！必须使用 128 位整数防止前缀和累加爆 long long
typedef __int128_t int128; 

struct Point {
    long long x, y;
};

void solve() {
    int n;
    if (!(cin >> n)) return;
    
    // 破环成链套路：开 2N 大小的数组，方便处理 u > v 的越界情况
    vector<Point> p(2 * n);
    for (int i = 0; i < n; ++i) {
        cin >> p[i].x >> p[i].y;
        p[i + n] = p[i]; 
    }

    int q;
    cin >> q;

    // 维护三个前缀和：差乘项、X重心权值项、Y重心权值项
    vector<int128> S_cross(2 * n, 0);
    vector<int128> S_cx(2 * n, 0);
    vector<int128> S_cy(2 * n, 0);

    for (int i = 0; i < 2 * n - 1; ++i) {
        // 计算有向边 (i, i+1) 的基础叉乘（即边对应的带符号平行四边形面积）
        int128 cross = (int128)p[i].x * p[i+1].y - (int128)p[i+1].x * p[i].y;
        
        // 累加计算前缀和 (不变量: S[i+1] 代表从点 0 到 点 i+1 的边属性总和)
        S_cross[i+1] = S_cross[i] + cross;
        S_cx[i+1]    = S_cx[i] + (p[i].x + p[i+1].x) * cross;
        S_cy[i+1]    = S_cy[i] + (p[i].y + p[i+1].y) * cross;
    }

    while (q--) {
        int u, v;
        cin >> u >> v;
        u--; v--; // 转为 0-based

        int L = u;
        int R = v;
        
        // 如果终点在起点前面，说明跨越了数组边界，利用破环成链直接 R += n
        if (L > R) {
            R += n;
        }

        // 1. 利用 O(1) 提取边界上从 L 到 R 这一路的多边形边权贡献
        int128 sum_cross = S_cross[R] - S_cross[L];
        int128 sum_cx    = S_cx[R] - S_cx[L];
        int128 sum_cy    = S_cy[R] - S_cy[L];

        // 2. 闭合多边形：必须加上截断边从 R 指向 L 的贡献 (v -> u)
        int128 close_cross = (int128)p[R].x * p[L].y - (int128)p[L].x * p[R].y;
        
        sum_cross += close_cross;
        sum_cx    += (p[R].x + p[L].x) * close_cross;
        sum_cy    += (p[R].y + p[L].y) * close_cross;

        // 3. 最终代入公式求出实际的几何重心坐标。
        // 因为 sum_cross 等价于 2A，重心公式是 1/6A，所以分母需要乘以 3。
        // 在最后一步做强制转换为 double，完美避免中途丢失精度
        double cx = (double)sum_cx / (double)(3 * sum_cross);
        double cy = (double)sum_cy / (double)(3 * sum_cross);

        // 输出并指定精度
        cout << fixed << setprecision(10) << cx << " " << cy << "\n";
    }
}

int main() {
    // 工业级保命操作：关闭同步流，防止 20万次查询 cin/cout 导致 TLE
    ios_base::sync_with_stdio(false);
    cin.tie(NULL);
    
    solve();
    
    return 0;
}

```

### 第 0 阶段，理清题意

* **游戏场地：** 一维的网格，由 'a' (Alice)，'b' (Bob) 和 '.' (空格) 组成。
* **游戏规则：** 轮到谁，谁就在 '.' 上填自己的名字。唯一的限制是：**你填的名字不能和相邻格子里你自己的名字相同**（但可以和对手的名字相邻）。
* **胜负判定：** 无法行动者输（典型的正常游玩约定 Normal Play Convention）。
* **目标：** 在双方最优策略下，给定初始残局，判断谁赢。

### 第一阶段：约束分析与前置扫盲

#### 1. 数据范围透视

* $t \le 2 \times 10^5$，所有用例的 $n$ 之和不超过 $2 \times 10^5$。
* 这强烈暗示了我们不能在单个测试用例中做任何复杂的模拟或 DP。我们必须找到一个 $O(N)$ 扫描一遍就能得出答案的**结论性算法**。

#### 2. 知识点与前置依赖

* **核心知识：** 组合博弈论（Combinatorial Game Theory）、独立游戏求和（类似 Sprague-Grundy 定理的扩展）、**超现实数（Surreal Numbers）** 思想。
* **教练提问（前置思考）：**

> 你是否意识到，双方其实是在一个共享的资源池里，用自己的行动在“自废武功”，而并没有直接“攻击”对手的合法性？

### 第二阶段：思维推导与思想解构

这道题是经典博弈论游戏 **Col** 在一维路径图上的变体。我们要如何解构它呢？

#### 1. 互不干扰的“独立战区”

初始棋盘上的 'a' 和 'b' 就像是一堵堵墙，把连续的空格 `.` 切割成了好几段。
因为玩家的限制只跟“相邻格子”有关，所以**被 'a' 或 'b' 隔开的空格段，彼此之间是完全独立的！**
整场游戏的总得分，就等于各个独立空格段的得分之和。

#### 2. 定量评估：谁占了便宜？

假设我们用一个分数来衡量一段空格对谁更有利：**正分代表 Alice 占优，负分代表 Bob 占优，0 分代表绝对公平**。
我们来分析一段连续的空格（长度为 $L$），它的两端边界会决定它的价值：

* **被 'a' 和 'a' 夹住的空格段 (`a...a`)：**
Alice 在这两端都不能落子，而 Bob 畅通无阻！经过严密的博弈推演，不管这段多长（只要 $L \ge 1$），Bob 永远能比 Alice 多走一步有效棋。
**结论：得分为 -2（Bob 优势）。**
* **被 'b' 和 'b' 夹住的空格段 (`b...b`)：**
完全同理，Bob 两头受限，Alice 白赚一步。
**结论：得分为 +2（Alice 优势）。**
* **被 'a' 和 'b' 夹住的空格段 (`a...b` 或 `b...a`)：**
一头限制 Alice，一头限制 Bob，非常对称。不管怎么玩，双方能走的步数完美抵消。
**结论：得分为 0（公平）。**
* **一头是 'a'，另一头是棋盘边界 (`a...边界`)：**
这种一头开放的情况，Alice 依然吃亏，但吃亏的程度不如被两头堵住那么惨。
如果 $L = 1$（即 `a.`），Alice 毫无办法，Bob 白赚一步，得分 -2。
如果 $L \ge 2$（如 `a..`），得分为 -1。
* **一头是 'b'，另一头是棋盘边界 (`b...边界`)：**
完全对称，$L = 1$ 得分 +2；$L \ge 2$ 得分 +1。
* **两头都是棋盘边界 (`边界...边界`)：**
如果 $L \ge 2$，这是一个完全对称的空盘，先手后手都没便宜占，得分为 0。
唯一的特例是 $L = 1$（整个棋盘只有一个 `.`），谁先手谁直接填，另一方立刻输。此时 Alice 必胜。

#### 3. 终极聚合

把所有独立战区的得分加起来，得到总分 `score`。

* 如果 `score > 0`，说明 Alice 掌握的绝对优势步数更多，Alice 必胜。
* 如果 `score <= 0`，在组合博弈的正常游玩规则下，总分为 0 时是**后手必胜**。因为 Alice 是先手，所以 Alice 会因为没有足够的步数优势而被拖死，此时 Bob 必胜。

### 第三阶段：母题提炼与破局套路

* **母题与模型：** 这是图论博弈 **Col Game** 的一维二分图特例。通过计算超现实数（Surreal Numbers）进行降维。
* **肌肉记忆触发点：**
下次在赛场上，只要看到：

2. “不能相邻放置同类物品”、“各自限制条件独立” 等字眼。
3. 数据范围极大（$10^5$ 级别）。
**立刻条件反射：** 扫描字符串寻找连续空白段，根据两端边界字符进行分类计分，直接把游戏状态压缩成一个全局累加的常数得分！

### 第四阶段：工业级代码实现

这段代码极致轻量，时间复杂度 $O(N)$，空间复杂度 $O(1)$。我在其中为你标注了极其容易踩坑的边界处理。

```cpp
#include <iostream>
#include <string>

using namespace std;

void solve() {
    int n;
    cin >> n;
    string s;
    cin >> s;

    int score = 0;
    int last_char_idx = -1;
    char last_char = 'e'; // 'e' 代表边界 (edge)

    for (int i = 0; i <= n; ++i) {
        // 当遇到棋子，或者到达字符串末尾时，结算前面这一段空格
        if (i == n || s[i] != '.') {
            int L = i - (last_char_idx + 1); // 连续空格的长度
            char right_char = (i == n) ? 'e' : s[i];

            if (L > 0) {
                // 1. 两端都是边界 (整个棋盘全是 '.')
                if (last_char == 'e' && right_char == 'e') {
                    if (L == 1) {
                        cout << "alice\n"; // 特判：只有一个格子，先手秒杀
                        return;
                    }
                    score += 0; // L >= 2 时绝对公平
                } 
                // 2. 两端都是 'a'
                else if (last_char == 'a' && right_char == 'a') {
                    score -= 2;
                } 
                // 3. 两端都是 'b'
                else if (last_char == 'b' && right_char == 'b') {
                    score += 2;
                } 
                // 4. 一端 'a' 一端 'b'
                else if ((last_char == 'a' && right_char == 'b') || 
                         (last_char == 'b' && right_char == 'a')) {
                    score += 0;
                } 
                // 5. 只有一端是 'a'
                else if (last_char == 'a' && right_char == 'e') {
                    score -= (L == 1) ? 2 : 1;
                } else if (last_char == 'e' && right_char == 'a') {
                    score -= (L == 1) ? 2 : 1;
                } 
                // 6. 只有一端是 'b'
                else if (last_char == 'b' && right_char == 'e') {
                    score += (L == 1) ? 2 : 1;
                } else if (last_char == 'e' && right_char == 'b') {
                    score += (L == 1) ? 2 : 1;
                }
            }
            // 更新起始游标
            last_char = right_char;
            last_char_idx = i;
        }
    }

    // 组合博弈论精髓：总分为正先手胜，否则后手(Bob)胜
    if (score > 0) {
        cout << "alice\n";
    } else {
        cout << "bob\n";
    }
}

int main() {
    // 避坑指南：海量测试用例必须关闭流同步，防止 TLE
    ios_base::sync_with_stdio(false);
    cin.tie(NULL);
    
    int t;
    if (cin >> t) {
        while (t--) {
            solve();
        }
    }
    return 0;
}

```

> **避坑指南（Edge Cases）：**
> 最常犯的低级错误是在处理收尾时，漏掉了“字符串最右侧到边界”的最后一段空格。我们在循环条件中故意写成了 `i <= n`，用 `(i == n)` 强制触发最后一次结算，配合虚拟边界字符 `'e'`，完美化解了这个坑。

切蛋糕游戏, 给定 $t$ 个 $n \times m$ 的蛋糕, Alice 只可以横着切蛋糕, 例如把 $2 \times 1 \rightarrow 1 \times 1 + 1 \times 1$, Bob 只可以竖着切蛋糕, 例如 $1 \times 2 \rightarrow 1 \times 1 + 1 \times 1$, 谁最后不能切, 谁就输, 求赢家

这是非公平博弈, 但是有结论

设两维长度为 $X$ 和 $Y$。取它们的最高二进制位（比如 4 是第 2 位，8 是第 3 位），记作 $k_x$ 和 $k_y$。

如果 $k_x = k_y$（即它们的最高位一样高，比如 2 和 3，4 和 7）：这块巧克力就是不敢碰的泥潭，价值绝对为 $0$。

如果 $k_x > k_y$：Alice 占优，绝对价值为 $(X \gg k_y) - 1$。

如果 $k_x < k_y$：Bob 占优，绝对价值为 $-((Y \gg k_x) - 1)$。
