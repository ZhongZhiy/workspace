这道题是组合数学中非常著名的一个模型，称为**错排问题 (Derangements)**。

它的定义是：将 $n$ 个元素重新排列，使得每一个元素都不在它原本的位置上。

---

### 1. 核心思路：递推推导

我们可以用 $D_n$ 表示 $n$ 个人的错排方案数。

假设有 $n$ 个孩子，编号为 $1, 2, \dots, n$，礼物也对应编号。

1. **第 1 个孩子** 拿走了 **第 $i$ 个孩子** 的礼物（$i$ 有 $n-1$ 种选择）。
    
2. 现在看 **第 $i$ 个孩子**，他有两种选择：
    
    - **情况 A：** 第 $i$ 个孩子正好拿了 **第 1 个孩子** 的礼物。
        
        - 这相当于 1 和 $i$ 互换了礼物。剩下的 $n-2$ 个孩子需要进行错排，方案数为 $D_{n-2}$。
            
    - **情况 B：** 第 $i$ 个孩子拿了 **除了第 1 个之外** 的其他人的礼物。
        
        - 这意味着第 $i$ 个孩子不能拿第 1 个礼物的限制，等价于 $n-1$ 个人的错排问题。方案数为 $D_{n-1}$。
            

### 2. 递推公式

根据上面的逻辑，我们可以得到递推关系：

$$D_n = (n-1)(D_{n-1} + D_{n-2})$$

**基础状态：**

- $D_1 = 0$ （只有一个人，不可能拿到别人的礼物）
    
- $D_2 = 1$ （两个人只能互相交换）
    

---

### 3. 通项公式（容斥原理）

如果你需要直接计算，也可以通过容斥原理得到：

$$D_n = n! \left( \frac{1}{0!} - \frac{1}{1!} + \frac{1}{2!} - \dots + (-1)^n \frac{1}{n!} \right)$$

即：

$$D_n = n! \sum_{k=0}^{n} \frac{(-1)^k}{k!}$$

---

### 4. 编程实现 (C++)

在算法竞赛中，通常题目会要求结果对 $10^9 + 7$ 取模。由于公式涉及减法，取模时要特别注意加上 `M` 防止出现负数。

你可以延续之前的代码风格，直接用循环预处理出结果：

C++

```
const int M = 1e9 + 7;
const int N = 1e6 + 10;
int D[N];

void solve_derangement(int n) {
    D[1] = 0;
    D[2] = 1;
    for (int i = 3; i <= n; ++i) {
        // D[i] = (i - 1) * (D[i-1] + D[i-2]) % M
        D[i] = (i - 1) * (D[i - 1] + D[i - 2]) % M;
    }
}
```

### 5. 复杂度分析

- **时间复杂度：** $O(n)$，只需要遍历一遍即可。
    
- **空间复杂度：** $O(n)$，用于存储 $D$ 数组。
    

**小结：**

- 如果是**所有人都拿不到自己的礼物**，直接用上面的错排公式。
    
- 如果有 **$k$ 个人拿到了自己的礼物，剩下 $n-k$ 个人没拿到**，方案数则是：$C_n^k \times D_{n-k}$。
