
## 参考代码

```cpp fold
ll mut(ll a, ll b) {
	a = a % M;
	b = b % M;
	ll res = 0;
	while(b) {
		if(b&1) res = (res + a) % M;
		a = (a + a) % M;
		b >>= 1;
	}
	return res;
}
```
### 1. 核心数学原理：维护一个“等式”

在 while 循环的每一步，代码其实都在维护这样一个恒等式：

$$\text{初始的 } a \times b = \text{res} + (\text{当前的 } a \times \text{当前的 } b)$$

- 当 $b$ 是偶数时：
    
    依据 $a \times b = (2a) \times (b/2)$。此时 res 不变，等式依然成立。
    
- 当 $b$ 是奇数时：
    
    我们将 $b$ 拆成 $(b-1) + 1$，那么：
    
    $$a \times b = a \times (b-1) + a$$
    
    代码中的 res = (res + a) % M 就是把这多出来的那个 $a$ 存入了 res 中。剩下的部分变成了 $a \times (b-1)$，由于 $b-1$ 是偶数，下一步又可以继续进行 $(2a) \times (b-1)/2$ 的翻倍操作。
    

当循环结束时：

$b$ 变成了 $0$。此时等式变为：

$$\text{初始的 } a \times b = \text{res} + (a \times 0) = \text{res}$$

这就是为什么最后 res 就是我们要的完整结果，而此时的 $a$ 已经变成了 $2^k \times a$，它已经不再重要了。

---

### 2. 跑一个例子：$5 \times 6$

假设我们要算 $5 \times 6$（不取模），初始 `res = 0`。

|**步骤**|**a (当前值)**|**b (当前值)**|**b 的奇偶**|**res (累加结果)**|**恒等式：res+a×b**|
|---|---|---|---|---|---|
|**初始**|5|6|偶数|0|$0 + 5 \times 6 = 30$|
|**第一轮**|$5 \times 2 = 10$|$6 / 2 = 3$|**奇数**|$0 + 10 = 10$|$10 + 10 \times 2 = 30$（此时 $b$ 变 2 后加的）|
|**第二轮**|$10 \times 2 = 20$|$2 / 2 = 1$|**奇数**|$10 + 20 = 30$|$30 + 20 \times 0 = 30$|
|**第三轮**|$20 \times 2 = 40$|$1 / 2 = 0$|结束|**30**|**结果为 30**|

---

### 3. 为什么你觉得 $a$ 没用到？

你可能会觉得最后一次 $a$ 变成了 $40$，好像没加进结果里。但其实：

- 当 $b=1$ 时（奇数），代码执行了 `res = (res + a)`，也就是把当时的 $a=20$ 加进去了。
    
- 加完之后，`a` 确实又执行了一次 `a = a + a` 变成了 $40$，但随后 `b >>= 1` 变成了 $0$，循环直接结束了。
    
- 所以这个 $40$ 是多算的，**它确实没被用到**，因为任务已经完成了。
    

### 总结

这个算法其实就是把 $b$ 拆解成了二进制。例如 $b=6$ ($110_2$)：

$$5 \times 6 = 5 \times (2^2 \times 1 + 2^1 \times 1 + 2^0 \times 0)$$

$$5 \times 6 = (5 \times 4) \times 1 + (5 \times 2) \times 1 + (5 \times 1) \times 0$$

res 依次加上的就是这些二进制位对应的权重。

### 你的代码修正建议

既然你已经理解了 `mut` 的原理，回到你的题目。由于 $n \le 10^{12}$，**你只需要在进入 `mut` 之前确保参数不溢出**：

C++

```
// 传入 mut 的时候，记得对大的项先取模
cnt = (cnt + mut(k, mut(inv, mut((r - l + 1) % M, (l + r) % M)))) % M;
```

不过还是那句话，因为 $M=10^9+7$，你完全可以直接用 `*` 代替 `mut`，这样代码会快很多：

C++

```
int sum_lr = (l + r) % M * ((r - l + 1) % M) % M * inv % M;
cnt = (cnt + k % M * sum_lr) % M;
```
