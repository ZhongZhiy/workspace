`～/.config/user.dirs`
你看到的这个文件，名字其实有一个小小的输入误触——它的正确名字应该少一个 `.dirs`，叫做：

Plaintext

```
~/.config/user-dirs.dirs
```

它是现代 Linux 桌面生态（包括你的 Arch Linux + Hyprland 环境）中一个非常核心、却经常在幕后默默工作的**标准配置文件**。

大白话来说：**它是你整个系统家目录下那几个“公共大件文件夹”的官方花名册。**

## 🛠️ 1. 这个文件里面写了什么？

如果你用 Neovim 打开 `~/.config/user-dirs.dirs`，你会发现里面的内容长得非常整齐，基本都是下面这样的键值对：


```
# ~/.config/user-dirs.dirs

XDG_DESKTOP_DIR="$HOME/Desktop"
XDG_DOWNLOAD_DIR="$HOME/Downloads"
XDG_TEMPLATES_DIR="$HOME/Templates"
XDG_PUBLICSHARE_DIR="$HOME/Public"
XDG_DOCUMENTS_DIR="$HOME/Documents"
XDG_MUSIC_DIR="$HOME/Music"
XDG_PICTURES_DIR="$HOME/Pictures"
XDG_VIDEOS_DIR="$HOME/Videos"
```

## 🧭 2. 它到底有什么用？（为什么存在？）

在 Linux 中，如果没有一个统一的规范，软件开发者就会各行其是。比如 Firefox 浏览器下载文件时想放在“下载”目录，有的软件叫 `Downloads`，有的软件叫 `Download`，中文系统下还可能叫 `下载`。

为了让所有软件达成共识，Freedesktop 组织制定了 **XDG User Directories 规范**。这个文件的核心作用有两点：

### ① 给所有图形软件提供统一的“路径导航”

当你打开浏览器下载软件、打开文件管理器（如 Thunar）查看图片、或者在 QQ 里发送文件时，软件在底层会去读取这个文件。

- 浏览器一读 `XDG_DOWNLOAD_DIR`，哦，知道该把文件默认存到 `~/Downloads` 了。
    
- 截图工具一读 `XDG_PICTURES_DIR`，哦，知道截图该默认塞进 `~/Pictures` 了。
    

### ② 完美支持系统国际化（多语言本地化）

如果你装 Arch Linux 的时候系统语言选的是英文，这个文件里指向的就是 `Downloads`、`Pictures`；如果你选的是中文，系统级的工具（`xdg-user-dirs-update`）会自动把这个文件修改为：

Ini, TOML

```
XDG_DOWNLOAD_DIR="$HOME/下载"
XDG_PICTURES_DIR="$HOME/图片"
```

这样，不管系统换成什么语言，软件只需要在代码里调用 `xdg-user-dir DOWNLOAD` 这个命令，就能永远精准找到用户的下载目录，而不需要硬编码英文名字。

## 👑 3. 极客怎么玩转这个文件？（强迫症的福音）

作为追求极致极简、并且在用 `xdg-ninja` 净化家目录的 Hyprland 玩家，这个文件是你**规范系统目录**的核弹级武器。

很多极客极其讨厌软件在系统开机时，自动在物理家目录下创建一堆他们根本用不到的空文件夹（比如 `Templates`、`Public` 这种一辈子都用不上的垃圾目录）。

### 🛠️ 终极魔改：让不想要的文件夹彻底消失！

1. **第一步：** 用 Neovim 打开它：
    
    Bash
    
    ```
    nvim ~/.config/user-dirs.dirs
    ```
    
2. **第二步：** 如果你想彻底废掉某个目录（比如 `Templates` 和 `Public`），**直接把它的路径改成指向你的家目录 `$HOME` 本身**：
    
    Ini, TOML
    
    ```
    XDG_TEMPLATES_DIR="$HOME"
    XDG_PUBLICSHARE_DIR="$HOME"
    ```
    
3. **第三步：** 去你的家目录下，把原本自动生成的物理空文件夹彻底干掉：
    
    代码段
    
    ```
    rm -rf ~/Templates ~/Public
    ```
    

**🌟 奇妙的效果：** 由于你把变量指向了 `$HOME`，以后任何流氓软件尝试去寻找“模板”或“公共共享”目录时，都会直接定位到你的家目录，而**再也不会在你的家目录下顽固地自动生成 `Templates/` 和 `Public/` 文件夹了**！

配合你之前学到的 `set -gx` 环境变量和 `xdg-ninja` 清理，把这个花名册调教好，你的 Arch Linux 目录结构就能达到真正的“干净、极简、丝滑”境界。
