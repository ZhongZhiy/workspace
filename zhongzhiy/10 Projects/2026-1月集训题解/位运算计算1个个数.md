# 内置函数
`__builtin_popcount(usize) -> int`

# 稀疏算法

```
int count = 0;
while (n > 0) {
    n &= (n - 1); // 关键：这一步会消除二进制中最右侧的一个 1
    count++;
}
```

# 压缩算法
```cpp
int popcount(uint32_t n) {
    n = n - ((n >> 1) & 0x55555555);                    // 每2位一组，计算这2位里1的个数
    n = (n & 0x33333333) + ((n >> 2) & 0x33333333);     // 每4位一组...
    n = (n + (n >> 4)) & 0x0F0F0F0F;                    // 每8位一组...
    n = n + (n >> 8);                                   // 每16位一组...
    n = n + (n >> 16);                                  // 每32位一组...
    return n & 0x3F;
}
```
