## [第二类斯特林数] 把把 n 个不同的小球，放入 m 个完全相同的盒子里，且没有空盒子的方案数
递推公式$S(n, m) = S(n-1, m-1) + m * s(n-1, m)$
解释:
考虑单独 1 个小球的情况, 
1. 如果这个小球单独放入一个盒子, 那么, 剩下的所有 $n- 1$个小球放入 $m-1$个盒子就可以了, 即$S(n-1, m-1)$
2. 如果这个小球放入有小球的盒子中, 那么就相当于$n-1$个小球已经占据了 $m$ 个盒子, 这个小球可以放入任意一个, 所以有 $m * S(n-1, m)$种
这两种互斥的情况就可以递推出所有的第二类斯特林数

## 找到最接近给定值 `t` 的子数组和
直接对原数列使用滑动窗口不行, 因为没有单调性
但是可以考虑到, 子串和就相当于前缀和的差, 可以用前缀和排序, 这样就有单调性了, 每次滑动窗口记录`sum = head[r] - head[l]`的值, 当`sum < t`就`r++`, 当`sum > t`就`l++`, 这样不断逼近, 每次记录原始的下标, 但是值得注意的是更新`l`和`r`的时候会产生`l >= r`, 需要特别处理

## 在数组中, 计算每个长度为 k 的窗口, 求最小的 cost 使得窗口中的数字相等, 对每个数增减 1 的 cost 都为 1
中位数肯定是窗口中变化的最优值, 怎么维护中位数,
使用对顶堆, 维护两个堆, 一个记录大于中位数的数字**小根堆**, 一个记录小于中位数的**大根堆**, 让小根堆或者大根堆对顶为中位数, 同时分别记录两个堆的和, 
这样, 大于中位数的堆的和 $supper$, 和小于中位数的堆的和 $slower$ 与中位数和个数的积的差就是所需的 cost 的
对顶堆的维护:
一个`balance`函数每次检查两个堆的大小, 维护始终平衡
每次增添, 删除都调用这个函数

## 十进制转 R 进制?
除 R 取余数, 最后把得到的数字倒过来
```cpp
string getR(int d){
    string r = "";
    while(d){
        r += d % r + '0';
        d /= r;
    }
    reverse(r.begin(), r.end());
    return r;
}
```
