## [赛马](https://acm.hdu.edu.cn/contest/problem?cid=1201&pid=1004)

2026 丙午马年，某赛马场举办一场盛大的赛马会，共有编号 $1$ 到 $n$ 的 $n$ 匹骏马参赛。

对于每一对骏马 $(l,r)$（$1≤l≤r≤n$），裁判组以 $\lfloor\log_2(r-l)\rfloor$ 来衡量二者的驰力差。请你计算所有骏马对的驰力差之和，即 $\sum_{l=1}^n\sum_{r=l}^n\lfloor\log_2(r-l)\rfloor$。

### Input

本题有多组测试数据。输入 $T (1≤T≤5×10^4)$，表示数据组数。

接下来 $T$ 行，每行输入一个数 $n (1≤n≤10^9)$。

---

### 教授的硬核数学推导

我们需要求的总和为：


$\sum_{l=1}^{n} \sum_{r=l}^{n} \lfloor \log_2(r/l) \rfloor$

首先，我们利用一个极其绝妙的**指示函数（Indicator Function）**的拆分技巧。对于任意正整数，$\lfloor \log_2(x) \rfloor$ 的物理意义就是**它能被多少个 $2^k$ 所包含**。因此，我们可以把它拆解为：


$\lfloor \log_2(r/l) \rfloor = \sum_{k=1}^{\infty} [ \frac{r}{l} \ge 2^k ] = \sum_{k=1}^{\infty} [ r \ge l \cdot 2^k ]$


*(注：中括号 $[\text{condition}]$ 表示如果条件为真则值为 $1$，否则为 $0$)*

我们将这个拆分代入原式，并改变求和顺序：


$\sum_{l=1}^{n} \sum_{r=l}^{n} \sum_{k=1}^{\infty} [ r \ge l \cdot 2^k ] = \sum_{k=1}^{\infty} \sum_{l=1}^{\lfloor n/2^k \rfloor} \sum_{r = l \cdot 2^k}^{n} 1$

现在，最内层的求和（对 $r$ 求和）变得非常简单了。符合 $r \ge l \cdot 2^k$ 且 $r \le n$ 的 $r$ 一共有：


$n - l \cdot 2^k + 1 \text{ 个}$

我们令 $m = \lfloor \frac{n}{2^k} \rfloor$，中间层对 $l$ 的求和就变成了一个极简的等差数列求和：


$\sum_{l=1}^{m} (n - l \cdot 2^k + 1)$


把它拆开，得到终极公式：


$m(n+1) - 2^k \cdot \frac{m(m+1)}{2}$


化简为：


$\mathbf{m(n+1) - 2^{k-1} m(m+1)}$

### 算法时间与空间评估

通过这个公式，对于每一个给定的 $n$，我们只需要让 $k$ 从 $1$ 枚举到 $\lfloor \log_2 n \rfloor$ 即可算出答案。

* **时间复杂度**：每一组测试数据只需要执行 $\log_2(10^9) \approx 30$ 次计算。总时间复杂度为 $O(T \log n)$。对于 $5 \times 10^4$ 组数据，总计算量仅为 $1.5 \times 10^6$ 次，几毫秒就能跑完！
* **空间防溢出**：当 $n = 10^9$ 且 $k=1$ 时，$m = 5 \times 10^8$。中间项乘积最大约为 $2.5 \times 10^{17}$。它完全处于 64 位带符号整数 `long long` 的安全上限（$9 \times 10^{18}$）之内，绝对不会溢出。

---

### 💻 工业级神仙代码

```cpp
#pragma GCC optimize("Ofast")
#include <iostream>

using namespace std;

void solve() {
    long long n;
    cin >> n;
    
    long long ans = 0;
    // 只要 2^k <= n，就继续累加
    for (int k = 1; (1LL << k) <= n; ++k) {
        long long m = n >> k; // m = n / 2^k
        
        // 套用终极公式： m * (n + 1) - 2^{k-1} * m * (m + 1)
        long long term1 = m * (n + 1);
        long long term2 = (1LL << (k - 1)) * m * (m + 1);
        
        ans += (term1 - term2);
    }
    
    cout << ans << "\n";
}

int main() {
    // 拔掉 C++ 输入输出流的塞子，极大提升 I/O 速度
    ios_base::sync_with_stdio(false);
    cin.tie(NULL);
    
    int t;
    if (cin >> t) {
        while (t--) {
            solve();
        }
    }
    return 0;
}

```

## [E. New Year's Gifts](https://codeforces.com/contest/2182/problem/E)

Monocarp 有 $n$ 个朋友，并决定为每人送一份新年礼物。他还准备了 $m$ 个盒子用来装礼物；第 $i$ 个盒子的美观度为 $a &#95; i$。每个盒子最多能容纳一份礼物。

Monocarp 希望送给第 $i$ 位朋友的礼物价值不低于 $y &#95; i$ 枚硬币。此外，他知道只要满足以下**至少一个**条件，第 $i$ 位朋友就会感到开心：

-   礼物被放置在美观度至少为 $x &#95; i$ 的盒子中；
-   礼物的价值至少为 $z &#95; i$（其中 $z &#95; i \gt y &#95; i$）。

你的任务是帮助 Monocarp 计算，在拥有 $k$ 枚硬币的情况下，他最多能让多少位朋友感到开心。**注意：Monocarp 必须为每位朋友购买礼物，且礼物不一定装在盒子中**。

**Input**

The first line contains a single integer $t$ ($1 \le t \le 10^4$) — the number of test cases.

The first line of each test case contains three integers $n$, $m$ and $k$ ($1 \le n, m \le 2 \cdot 10^5$; $1 \le k \le 10^{15}$).

The second line contains $m$ integers $a_1, a_2, \dots, a_m$ ($1 \le a_i \le m$).

Then $n$ lines follow; the $i$\-th of them contains three integers $x_i$, $y_i$ and $z_i$ ($1 \le x_i \le m$; $1 \le y_i \lt z_i \le 10^9$).

Additional constraints on the input:

-   $\sum\limits_{i=1}^{n} y_i \le k$.
-   the sum of $n$ over all test cases doesn't exceed $2 \cdot 10^5$;
-   the sum of $m$ over all test cases doesn't exceed $2 \cdot 10^5$;


---

每个人先支付 $y_i$ 枚硬币，这时候, 想让他们开心还需要再支付 $z_i - y_i$ 枚硬币

双重贪心: 

1. 礼品盒从小到大排序, 每次选最小的盒子, 因为用了最小的盒子再挑选更大的盒子, 这样总是最优的
2. 在遍历到每个礼品盒的时候, 挑选当前盒子能装的礼品中, $z_i - y_i$, 最大的, 这样剩下的才能花钱最少, 

这两个贪心都可以验证, 如果不这样做, 结果不会更优

用优先队列维护


**重要的二维偏序贪心思想**

```cpp
void solve(){
    int n, m, k; cin >> n >> m >> k;
    vi gift(m);
    fi0(m) cin >> gift[i];
    sort(all(gift)); //礼盒排序

    vector<pii> fir(n);
    int total = k;
    fi0(n){
        int x, y, z; cin >> x >> y >> z;
        total -= y;
        fir[i]= {x, z-y};
    }
    sort(all(fir)); //按照礼盒排序
    auto cmp_by_x = [&](const pii& a, const pii& b)->bool{
        return a.S <= b.S;
    };
    priority_queue<pii, vector<pii>, decltype(cmp_by_x)> pq(cmp_by_x);

    int idx = 0, happy = 0;
    for(int i = 0;i < m; ++i) {
        //将所有能装下当前礼盒的盒子加入优先队列
        while(idx < n && fir[idx].F <= gift[i]) pq.push(fir[idx]), idx++;
        if(!pq.empty()) {
            pq.pop();
            happy++;
        }
    }

    vector<pii> rem;
    while(!pq.empty()){
        rem.push_back(pq.top());
        pq.pop();
    }

    for(;idx < n; ++idx){
        rem.push_back(fir[idx]);
    }
    sort(all(rem), [&](const pii&a, const pii& b)->bool{
       return a.S < b.S;
    });

    for(auto c : rem){
        if(total >= c.S){
            total-= c.S;
            happy++;
        }
    }
    cout << happy << endl;
}
```

## [C2. Potions](https://codeforces.com/contest/1526/problem/C2)


有 $n$ 瓶药水排成一行，药水 $1$ 位于最左端，药水 $n$ 位于最右端。每瓶药水饮用后会使你的生命值增加 $a_i$。$a_i$ 可能为负数，这意味着药水会减少你的生命值。

你初始生命值为 $0$，将从左向右移动，从第一瓶药水走到最后一瓶。每经过一瓶药水，你可以选择饮用或忽略它。**你必须确保生命值始终为非负数**。

你最多能饮用多少瓶药水？

**Input**

The first line contains a single integer $n$ ($1 \leq n \leq 200000$) — the number of potions.

The next line contains $n$ integers $a_1$, $a_2$, ... ,$a_n$ ($-10^9 \leq a_i \leq 10^9$) which represent the change in health after drinking that potion.

---
反悔贪心, 每次取药水, 只要生命值大于 $0$ 就饮用, 否则就在过去饮用过的药水中挑选一个最小值, 并将其替换为当前药水.

用优先队列维护这这个饮用过的列表

```cpp
void solve(){
    int n; cin >> n;
    vi a(n + 1);
    fi(n) cin >> a[i];

    priority_queue<int , vector<int>, greater<int>> q;

    int health = 0, cnt = 0;
    fi(n){
        if(health + a[i] >= 0) {
            health += a[i];
            q.push(a[i]);
            cnt++;
        }else {
            if(!q.empty()&&q.top() < a[i]) {
                health -= q.top();
                q.pop();
                health += a[i];
                q.push(a[i]);
            }
        }
    }
    cout << cnt << endl;
}
```

## [D. Buy Low Sell High](https://codeforces.com/problemset/problem/865/D)

你可以精准预测某支股票未来 $N$ 天的价格。你希望利用这一信息获利，但每天仅能交易一股。也就是说，每天你可以选择买入一股、卖出一股或不进行任何操作。初始时你持有零股，且无法在未持有股票时进行卖出操作。在这 $N$ 天结束时，你需要重新保持零持股状态，同时力求获得最大收益。

**Input**

Input begins with an integer $N (2 ≤ N ≤ 3·10^5)$, the number of days.

Following this is a line with exactly $N$ integers $p_1, p_2, ..., p_N (1 ≤ p_i ≤ 10^6)$. The price of one share of stock on the $i-th$ day is given by $pi$.

---

在第 $j$ 天卖出股票 $p_i$ 相当于挣了 $p_j - p_i$, 假设每天买入一股, 让后从之前买入个股票中挑选最少的一个, 挣 $p_j - p_i$ 的钱, 再把 $p_j$ 加入队列中, 这就相当于反悔券, 可以在未来某一天 $k$ 还可以卖出, $p_k - p_j$, 综合两次卖出, 就相当于 $p_k - p_k + p_k - p_i = p_k - p_i$, 

```cpp
void solve(){
    int n; cin >> n;
    vi op(n);
    fi0(n) cin >> op[i];
    priority_queue<int, vector<int>, greater<int>> q;

    int earn = 0;
    fi0(n){
        q.push(op[i]);
        if(!q.empty() && q.top() < op[i]){
            earn += op[i] - q.top();
            q.pop();
            q.push(op[i]);
        }
    }
    cout << earn << endl;
}
```

$lcm(x, y)$ 表示 $x$ 和 $y$ 的最小公倍数（即最小的正整数，使得 $x$ 和 $y$ 都是该数的约数）。

___
**Input**

The first line of the input contains one integer $n$ ($2 \le n \le 10^6$) — the number of elements in $a$.

The second line of the input contains $n$ integers $a_1, a_2, \dots, a_n$ ($1 \le a_i \le 10^7$), where $a_i$ is the $i$\-th element of $a$.

---

如果找每个数的倍数, 那么没有上限, 不可取


因为 $lcm(a, b) = a \times b / \gcd(a, b)$, 而 $\gcd$ 是天然有上限的, 可以枚举 $\gcd$ 的倍数, 找到最小的两个 $gcd$ 的倍数, 

```cpp
int freq[N + 1];
void solve() {
    int n; if (!(cin >> n)) return;

    vector<int> a(n + 1);
    for (int i = 1; i <= n; ++i) {
        cin >> a[i];
        freq[a[i]]++;
    }
    // 1. 修正溢出：答案和极值都使用 long long
    ll ans = LLONG_MAX;
    int best_val1 = 0, best_val2 = 0;

    for (int i = 1; i <= N; ++i) {
        int m1 = 0, m2 = 0;
        for (int j = i; j <= N; j += i) {
            if (freq[j] > 0) {
                if (m1 = 0) {
                    m1 = j;
                    // 如果这个数字有多个，它自己就可以作为第二个倍数！
                    if (freq[j] > 1) {
                        m2 = j;
                        break; // 找齐两个了，立刻退出内层循环
                    }
                } else if (m2 = 0) {
                    m2 = j;
                    break; // 找齐两个了，立刻退出内层循环
                }
            }
        }
        // 如果成功找到了两个倍数
        if (m2 != 0) {
            // LCM 公式：a / gcd * b。保证先除后乘防止中间溢出
            ll current_lcm = 1LL * m1 / i * m2;
            if (current_lcm < ans) {
                ans = current_lcm;
                best_val1 = m1;
                best_val2 = m2;
            }
        }
    }
    // 3. 修正下标逻辑：防止相同的数字覆盖下标
    int id1 = 0, id2 = 0;
    for (int i = 1; i <= n; ++i) {
        if (a[i] = best_val1 && id1 = 0) {
            id1 = i;
        } else if (a[i] = best_val2 && id2 = 0) {
            // 使用 else if 极其关键：防止 best_val1 = best_val2 时，id1 和 id2 抢同一个位置
            id2 = i;
        }
    }
    // 题目可能要求输出顺序（从小到大），如果平台严格可以排个序
    if (id1 > id2) swap(id1, id2);
    cout << id1 << " " << id2 << endl;
}
```

int popcount(int x){
    return __builtin_popcountll(x);
}
int clz(int x){
    if(x = 0) return 1;
    return 64 - __builtin_clzll(x);
}
int get_cost(int x){
    if(x = 0) return 0;
    return popcount(x) + clz(x) - 1;
}
void solve(){
    int n;cin >> n;
    vi a(n + 1);
    fi(n) cin >> a[i];

    int sum = LLONG_MAX;

    for(int k = 0;k <= 20; ++k){
        int total = k;
        for(int i = 1;i <= n; ++i){
            int mn = LLONG_MAX;
            int p = 1LL<<k;
            int min_rem = (a[i]+p-1)/p;  // k 之上的高位数

            for(int v = min_rem; v <= min_rem + 40; ++v){
                mn = min(mn, v*p - a[i] + get_cost(v));
            }
            total += mn;
        }
        sum = min(total, sum);
    }

## [D. Social Circles](https://codeforces.com/problemset/problem/1060/D)

你邀请了 $n$ 位客人共进晚餐！你计划安排一个或多个环形座位区。每把椅子要么由一位客人使用，要么空置。你可以设置任意数量的环形座位区。

你的客人有些害羞，因此第 $i$ 位客人希望在他椅子的左侧至少有 $l &#95; i$ 把空椅子，右侧至少有 $r &#95; i$ 把空椅子。这里“左”和“右”的方向是基于所有客人都面向圆圈中心就坐而确定的。注意，当某位客人是所在环形座位区的唯一就坐者时，他左侧的 $l &#95; i$ 把椅子与右侧的 $r &#95; i$ 把椅子可能会重叠。

你需要使用的最少椅子总数是多少？

**Input**

First line contains one integer $n$  — number of guests, ($1 \leqslant n \leqslant 10^5$).

Next $n$ lines contain $n$ pairs of space-separated integers $l_i$ and $r_i$ ($0 \leqslant l_i, r_i \leqslant 10^9$).

---

### 第 0 阶段：理清题意

你要安排 $n$ 位客人入座，可以分成一个或多个环形。
每位客人 $i$ 有两个需求：

1. 左边至少需要 $l_i$ 把空椅子。
2. 右边至少需要 $r_i$ 把空椅子。

我们的终极目标是：通过合理地将这 $n$ 个人分组连成环，使得**使用的总椅子数最小**。

___

### 第一阶段：约束分析与前置扫盲

#### 1. 代价的物理意义

假设客人 $A$ 的右边紧挨着坐着客人 $B$（即 $B$ 在 $A$ 的右侧）。

* $A$ 要求右边至少有 $r_A$ 个空位。
* $B$ 要求左边至少有 $l_B$ 个空位。
为了满足两人，他们之间到底需要插多少把空椅子？显然是两者取最大值，即 $\max(r_A, l_B)$ 把空椅子。

那么对于任何一个包含 $k$ 个人的圆环，它所消耗的椅子总数是确定的：
**$k$ 个人自己的座位 + 环上相邻两人之间的空椅子数**。
推广到全部 $n$ 个人，总椅子数 $S$ 的公式为：


$$S = n + \sum \max(r_i, l_{\pi(i)})$$


*(其中 $\pi(i)$ 表示排在 $i$ 右边的那位客人)*

#### 2. 教练的前置定理扫盲

你可能会担心：“如果我把客人随便匹配，他们还能连成合法的圆环吗？”
**定理（排列的环分解）：** 在离散数学中，**任意**一个从集合到自身的双射（全排列），都可以唯一地分解为若干个不相交的循环（Cycles）。
这就意味着，不管你指定谁的右边必须坐谁，只要每个人的左边和右边都恰好匹配了一个人，他们**必定**会在物理上形成一个或多个合法的闭合圆环。
**结论：我们彻底抛弃掉“圆环拼图”的束缚，直接进入纯代数匹配！**

___

### 第二阶段：思维推导与思想解构

现在的终极问题变成了：如何排列客人，才能让 $\sum \max(r_i, l_{\pi(i)})$ 这个和最小？

#### 核心思想：绝对值展开与重排不等式

在数学上，两个数的最大值可以用绝对值恒等式展开：


$$\max(a, b) = \frac{a + b + \vert{}a - b\vert{}}{2}$$

我们将这个恒等式代入我们的总代价求和公式中：


$$\sum \max(r_i, l_{\pi(i)}) = \frac{1}{2} \left( \sum r_i + \sum l_{\pi(i)} + \sum \vert{}r_i - l_{\pi(i)}\vert{} \right)$$

请注意观察括号里的前两项：

* $\sum r_i$ 就是所有客人的右侧需求总和，是一个定值（常数）。
* $\sum l_{\pi(i)}$ 就是所有客人的左侧需求总和，无论你怎么排，总和依然是定值（常数）。

**破局点诞生：**
整个式子中，唯一能被我们改变的变量，只有 $\sum \vert{}r_i - l_{\pi(i)}\vert{}$！
我们要让总代价最小，等价于**让两两匹配的差值的绝对值之和最小**。

想象一条数轴，上面有红点（代表 $r_i$）和蓝点（代表 $l_i$）。你要用线把红蓝点一对一连起来，要求线的总长度最短。
最直观、也是绝对最优的策略是什么？
**当然是把最靠左的红点连最靠左的蓝点，从小到大依次对应连接！** （这在数学上可以通过贪心反证法严格证明）。

___

### 第三阶段：母题提炼与破局套路

#### 母题与模型

这道题属于极度经典的「数组独立排序匹配模型」。
在竞技编程中，只要遇到形如 $\sum \max(A_i, B_j)$ 或者 $\sum \vert{}A_i - B_j\vert{}$ 求最小值的题目，其本质都是脱离元素原本的绑定关系，将维度独立排序。

#### 肌肉记忆触发点

* **特征**：个体有“左/右”、“进/出”、“买/卖”两个独立属性，求将它们首尾相连组成闭环的最小代价。
* **条件反射**：
1. 立刻将左属性存为一个数组，右属性存为另一个数组。
2. 彻底无视它们原本属于同一个人，**将两个数组分别从小到大排序**。
3. 同行下标一对一匹配，计算代价累加即为全局最优解。

void solve(){

    constexpr int N = 22;
    constexpr int M = (1LL<<22);

    vector<int> dp(M, -1), a(n);

    fi0(n){
        cin >> a[i];
        dp[a[i]] = a[i];

    for(int i = 0;i < N; ++i){
        for(int mask = 0;mask < M; ++mask){
            if(mask>>i&1 && dp[mask^(1LL<<i)] != -1){ //子集存在
                dp[mask] = dp[mask^(1LL<<i)];

## [SOS DP]
求使得子序列的**按位与 (AND)** 或 **按位或 (OR)** 等于特定值的组合数。应如何转化为 SOS DP 的模型？

---
* **按位与 (AND)** $\implies$ 转化为求 **超集 (Supersets)**。
*(要让 AND 结果包含 mask 的所有 1，团队每个成员都必须是 mask 的超集)*
* **按位或 (OR)** $\implies$ 转化为求 **子集 (Subsets)**。
*(要让 OR 结果不超过 mask 的范围，团队每个成员都必须是 mask 的子集)*
最终答案通常套用容斥原理：`ans += (-1)^popcount * (2^C - 1)`。



## [SOS DP]
题眼：寻找数组中使得 $x \ \& \ y = 0$（按位与为 0）的一对元素。如何用 SOS DP 降维打击？

---
**转化公式**：$x \ \& \ y = 0 \iff y \subseteq \sim x$（$y$ 是 $x$ 取反后的子集）。
**解题三步**：

## [C - Inc, Dec, Xor](https://atcoder.jp/contests/abc470/tasks/abc470_c)

### 题目描述

给定一个长度为 $N$ 的整数序列 $A=(A &#95; 1,A &#95; 2,\ldots,A &#95; N)$。初始时，$A$ 的所有元素均为 $0$。

接下来按顺序处理 $Q$ 次询问。询问有两种类型，分别以下列格式给出：

-   `1 x`：将 $A &#95; x$ 的值增加 $1$。
-   `2`：对于每个 $i=1,2,\ldots,N$，如果 $A &#95; i \geq 1$，则将 $A &#95; i$ 的值减少 $1$。

请在每次处理完询问后，求出 $A &#95; 1,A &#95; 2,\ldots,A &#95; N$ 的按位异或值。

什么是按位异或？

非负整数 $A$ 与 $B$ 的按位异或记作 $A \oplus B$，定义如下：

-   在 $A \oplus B$ 的二进制表示中，$2^k$（$k \geq 0$）位上的数字为 $1$ 当且仅当 $A$ 和 $B$ 的二进制表示中该位上的数字恰好有一个为 $1$，否则为 $0$。

例如，$3 \oplus 5 = 6$（二进制表示为：$011 \oplus 101 = 110$）。  
更一般地，$k$ 个非负整数 $p &#95; 1, p &#95; 2, p &#95; 3, \dots, p &#95; k$ 的按位异或定义为 $(\dots ((p &#95; 1 \oplus p &#95; 2) \oplus p &#95; 3) \oplus \dots \oplus p &#95; k)$，可以证明该值与 $p &#95; 1, p &#95; 2, p &#95; 3, \dots, p &#95; k$ 的顺序无关。


### Constraints

-   $1\le N\le 5\times 10^5$
-   $1\le Q\le 5\times 10^5$
-   $1\le x\le N$
-   All input values are integers.

---
均摊法

因为最开始所有值为零, 只有操作 $1$ 增添一个值, 整个过程最多增添 $q$ 个值, 那么如果只记录修改过后的下标的话, 操作 $2$ 不会超过 $q$ 次, 直接模拟操作就可以了

```cpp
void solve(){
    int n, q; cin >> n >> q;
    int xor_val = 0;
    vector<int> rem, cnt(N+1);

    fi(q){
        int op; cin >> op;
        if(op = 1){
            int x; cin >> x;
            xor_val ^= cnt[x];
            cnt[x]++;
            xor_val ^= cnt[x];
            if(cnt[x] = 1) rem.push_back(x);
            cout << xor_val << endl;
        }else {
            vector<int> res;
            for(auto v : rem) {
                xor_val ^= cnt[v];
                cnt[v]--;
                xor_val ^= cnt[v];
                if(cnt[v]>0)res.push_back(v);
            }
            rem = std::move(res);
            cout << xor_val << endl;
        }
    }
}
```

## [D - Count Subgrid Sum = K](https://atcoder.jp/contests/abc461/tasks/abc461_d)

### 题目描述

有一个 $H \times W$ 的网格，每个格子中写有一个整数 $0$ 或 $1$。  
每个格子中所写整数的信息由 $H$ 个长度为 $W$ 的字符串 $S &#95; 1, S &#95; 2, \dots, S &#95; H$ 给出。如果 $S &#95; i$ 的第 $j$ 个字符是 `0`，则表示网格中从上往下第 $i$ 行、从左往右第 $j$ 列的格子中写有 $0$；如果 $S &#95; i$ 的第 $j$ 个字符是 `1`，则表示该格子中写有 $1$。

请求出满足格子内所写整数之和等于 $K$ 的矩形区域的数量。  
更正式地说，求出满足以下所有条件的整数四元组 $(r &#95; 1, c &#95; 1, r &#95; 2, c &#95; 2)$ 的数量：

-   $1 \le r &#95; 1 \le r &#95; 2 \le H$
-   $1 \le c &#95; 1 \le c &#95; 2 \le W$
-   对于所有满足 $r &#95; 1 \le i \le r &#95; 2, c &#95; 1 \le j \le c &#95; 2$ 的整数对 $(i, j)$，从上往下第 $i$ 行、从左往右第 $j$ 列的格子中所写整数之和等于 $K$。

### Constraints

-   $H$ and $W$ are integers between $1$ and $500$, inclusive.
-   $K$ is an integer between $0$ and $HW$, inclusive.
-   $S_i$ is a string of length $W$ consisting of `0` and `1`.

---
思路简单, 枚举上边界和下边界, 然后枚举左边界和右边界, 计算子矩阵和是否等于 $K$.

但是怎么计算一个数组中子区间等于 $k$ 的个数呢?

可以使用滑动窗口, 统计 $>k$ 和 $ >= k$ 的区间个数, 然后作差就是 $ =k$ 的区间个数

```cpp
for(int l = 0, r1 = 0, r2 = 0; l < w; ++l){
    r1 = r2 = l;
    while(r1 < w && pre[r1] - pre[l] < k) ++r1;
    while(r2 < w && pre[r2] - pre[l] <= k) ++r2;
    cnt += r2 - r1;
}
```

## [E - Roads and Gates ](https://atcoder.jp/contests/abc463/tasks/abc463_e)

### 题目描述

AtCoder 国有 $N$ 座城市和 $M$ 条道路。第 $i$ 条道路 $(1\le i\le M)$ 双向连接城市 $u  &#95;  i$ 和 $v  &#95;  i$，且通行需要 $T  &#95;  i$ 分钟。

此外，每座城市都安装了一个传送门，你可以使用传送门从城市 $i\\ (1\le i\le N)$ 前往城市 $j\\ (1\le j\le N)$，所需时间为 $X  &#95;  i+X  &#95;  j+Y$ 分钟。

该国没有其他方式在城市间通行。

对于每个 $k=2,3,\ldots,N$，请解决以下问题：

-   求从城市 $1$ 到达城市 $k$ 所需的最短时间。

在同一城市中，从道路或传送门换乘到另一条道路或另一个传送门的时间可以忽略不计。

### Constraints

-   $2\le N\le2\times10 ^ 5$
-   $0\le M\le2\times10 ^ 5$
-   $1\le u _ i\lt v _ i\le N\ (1\le i\le M)$
-   $1\le T _ i\le10 ^ 9\ (1\le i\le M)$
-   $1\le X _ i\le10 ^ 9\ (1\le i\le N)$
-   $1\le Y\le 10 ^ 9$
-   All input values are integers.

---
这是一道极其经典的**图论建图优化**问题（通常出现在 AtCoder 的 E 题或 F 题）。

如果按照题意暴力建图，任意两座城市之间都有传送门，这意味着传送门会构成一个拥有 $O(N^2)$ 条边的**完全图（Dense Graph）**。在 $N = 2 \times 10^5$ 的约束下，即使是时间复杂度极优的 Dijkstra 算法也会瞬间 TLE 且 MLE（内存爆表）。

遇到这种“任意两点间都有特定规则连边”的图论题，在竞技编程中有一种极其优雅的降维打击技巧：**超级源点 / 虚拟节点（Virtual Node）**。

下面我带你拆解这个精妙的建图魔法。

___

### 🧠 核心降维推导：拆分传送门代价

题目中任意两个城市 $i$ 和 $j$ 之间的传送门代价是：


$$\text{Cost} = X_i + X_j + Y$$

我们仔细观察这个式子，它被完美地拆成了两部分，中间由一个常数 $Y$ 连接。
在物理意义上，我们可以把它想象成一次“搭乘航班”的过程：

1. **前往机场（进入传送网络）**：从城市 $i$ 进入传送网络，需要花费 $X_i + Y$ 的时间（我们把基础传送时间 $Y$ 算在安检进站里）。
2. **飞往目的地（离开传送网络）**：从传送网络降落到城市 $j$，需要花费 $X_j$ 的时间。

**见证奇迹的时刻：**
我们凭空创造一座“第 0 号城市”（虚拟中转站）**，代表整个传送门网络的核心。
对于每一座真实的城市 $i \ (1 \le i \le N)$，我们只需要建**两条有向边：

* **入网边**：从城市 $i$ 指向城市 $0$，边权为 $X_i + Y$。
* **出网边**：从城市 $0$ 指向城市 $i$，边权为 $X_i$。

这样一来，从城市 $i$ 经过虚拟节点 $0$ 到达城市 $j$ 的总路径长度，恰好等于：


$$(X_i + Y) + X_j = X_i + X_j + Y$$


完美契合题意！


### 🚀 复杂度魔法

通过引入这个虚拟节点 $0$：

* 我们把原本 $O(N^2)$ 条传送门边，硬生生压缩成了仅仅 **$2N$ 条有向边**。
* 加上原本的 $M$ 条普通双向道路，新图的总边数仅为 $2N + 2M$。
* 在如此稀疏的图上跑一遍标准的 Dijkstra 算法，时间复杂度瞬间从 $O(N^2 \log N)$ 暴降至 **$O((N+M) \log N)$**，直接碾压过题。
