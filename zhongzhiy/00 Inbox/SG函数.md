SG 函数（Sprague-Grundy 函数）是博弈论中处理**公平组合游戏（ICG）**的终极武器。你可以把它理解为一个“翻译官”，能把任何复杂的、各种规则的游戏，统一翻译成“一堆石子数为 $n$ 的 Nim 游戏”。

以下是对 SG 函数的全面总结：

---

### 1. SG 函数的核心定义

对于游戏中的任意状态 $x$，其 SG 函数值定义为：

$$SG(x) = \text{mex}(\{SG(y) \mid x \to y\})$$

- **$x \to y$**：表示从状态 $x$ 经过一次合法操作可以到达的状态 $y$（即后继状态）。
    
- **$\text{mex}(A)$**：最小未出现非负整数（Minimum Excluded value）。例如 $\text{mex}\{0, 1, 3\} = 2$，$\text{mex}\{1, 2\} = 0$。
    
- **终局状态**：如果没有后继状态，则 $SG(x) = 0$。
    

---

### 2. 使用条件（适用范围）

SG 函数专门用于解决**公平组合游戏（Impartial Combinatorial Games）**。这类游戏必须满足以下 4 个条件：

1. **两人游戏**：两人轮流进行操作。
    
2. **操作公平**：在同一个状态下，两名玩家能够采取的操作集合完全相同。
    
3. **信息完全**：玩家知道游戏的所有信息，没有随机性（不掷骰子、不抽牌）。
    
4. **有限性**：游戏必须在有限步内结束，且不存在平局。
    
5. **常规正规规则（Normal Play Convention）**：最后一名移动的玩家获胜（即无法移动者输）。
    

---

### 3. SG 函数的作用

SG 函数将一个复杂的局面“原子化”：

- **判定胜负**：
    
    - 若 $SG(x) \neq 0$，则当前状态为 **必胜态（N-position）**。
        
    - 若 $SG(x) = 0$，则当前状态为 **必败态（P-position）**。
        
- **游戏分解（Sprague-Grundy 定理）**：
    
    如果一个大游戏是由 $n$ 个相互独立的子游戏组成的（例如有 $n$ 个棋子在不同的棋盘上移动，每人每回合只能选一个棋子动一步），那么总局面的 SG 值等于各子游戏 SG 值的**异或和**：
    
    $$SG_{total} = SG(G_1) \oplus SG(G_2) \oplus \dots \oplus SG(G_n)$$
    

---

### 4. 使用方法（算法流程）

在程序实现或题目分析中，通常遵循以下步骤：

#### 第一步：分解游戏

观察问题是否可以分解成多个互不干扰的子部分。例如，Nim 游戏中的每一堆石子就是一个子游戏。

#### 第二步：计算单游戏 SG 值

对单个子游戏的状态进行分析。通常有三种方法：

1. **手动打表找规律**：计算前几个小状态的 $mex$，观察是否出现循环或线性规律（如 Bachet 游戏的 $\pmod{k+1}$）。
    
2. **递归 + 记忆化搜索**：
    
    C++
    
    ```
    int getSG(int x) {
        if (sg[x] != -1) return sg[x];
        set<int> visited;
        for (int next_state : moves[x]) {
            visited.insert(getSG(next_state));
        }
        int res = 0;
        while (visited.count(res)) res++;
        return sg[x] = res;
    }
    ```
    
3. **动态规划**：从终局状态（$SG=0$）开始向上递推。
    

#### 第三步：异或求和

将所有子游戏的 SG 值求异或和。如果结果非 $0$，则先手有必胜策略。

---

### 5. 常见模型举例

|**游戏类型**|**SG 值规律**|
|---|---|
|**标准 Nim 游戏**|$SG(n) = n$|
|**Bachet 游戏（限拿 $1 \sim k$）**|$SG(n) = n \pmod{k+1}$|
|**阶梯 Nim**|奇数阶梯的石子数求异或和（偶数阶梯不影响结果）|
|**图上移动游戏**|节点的 SG 值取决于它能跳向的节点的 SG 值|

---

### 💡 核心直觉总结

- **$SG(x) = k$** 的含义：这个状态等价于一个**大小为 $k$ 的 Nim 石子堆**。
    
- **$mex$ 运算**的含义：它保证了如果 $SG=k$，你一定能走到 $0, 1, \dots, k-1$ 中的任何一个状态，但绝对走不到另一个 $SG=k$ 的状态。这维持了博弈的平衡。
    

作为经常处理算法题的开发者，掌握 SG 函数不仅能解博弈题，更重要的是理解这种**“将复杂状态压缩为单一数值”**的转换思想。

你想尝试解决一个具体的题目来练手吗？比如“在 $N \times M$ 的棋盘上放了几个棋子，每次可以向左或向上移动，不能移动者输”，看看这类二维博弈如何通过 SG 函数分解。
