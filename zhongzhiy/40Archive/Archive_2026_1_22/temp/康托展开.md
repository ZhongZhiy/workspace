这段文字非常专业地揭示了**康托展开（Cantor Expansion）**在数学和计算机科学中的本质：它不仅是一个算法，更是一种**特殊的数制——阶乘进制（Factorial Number System）**。

我们可以从以下三个层面来深入理解这段讲解：

---

### 1. 核心本质：阶乘进制

通常我们使用的十进制或二进制是“固定底数制”，每一位的权重是 $10^i$ 或 $2^2$。而**阶乘进制**的权重是动态变化的阶乘。

对于任意整数 $X$，它都可以被唯一地表示为：

$$X = a_{n-1}(n-1)! + a_{n-2}(n-2)! + \dots + a_1(1)! + a_0(0)!$$

其中系数满足 $0 \le a_i \le i$。

**为什么这个进制能对应排列？**

因为 $n$ 个元素的全排列总数恰好是 $n!$。这种进制正好完美地覆盖了 $[0, n!-1]$ 范围内的所有整数，从而实现了一一映射。

---

### 2. 桥梁：Lehmer 码（Lehmer Code）

文本中提到的 **Lehmer 码** 是连接“排列”与“数字”的关键。

对于排列 $\sigma$ 中的每一个元素 $\sigma(i)$，其对应的 Lehmer 码位 $L_{\sigma}(i)$ 定义为：

> **在该位置之后，比当前元素小的元素个数。**

这个数字本质上是在告诉我们：**“在当前位置，如果我们不选 $\sigma(i)$ 而选一个比它小的数，后面能产生多少种更小的字典序排列？”**

---

### 3. 示例详解：$\sigma = 452631$

我们来复盘一下文本中的计算逻辑：

|**位置 i**|**元素 σ(i)**|**剩余未使用的集合**|**比 σ(i) 小且未使用的数**|**Lσ​(i)**|**贡献权重**|
|---|---|---|---|---|---|
|1|**4**|{1,2,3,4,5,6}|{1,2,3}|**3**|$3 \times 5!$|
|2|**5**|{1,2,3,5,6}|{1,2,3}|**3**|$3 \times 4!$|
|3|**2**|{1,2,3,6}|{1}|**1**|$1 \times 3!$|
|4|**6**|{1,3,6}|{1,3}|**2**|$2 \times 2!$|
|5|**3**|{1,3}|{1}|**1**|$1 \times 1!$|
|6|**1**|{1}|$\emptyset$|**0**|$0 \times 0!$|

最后排名 = $1 + (360 + 72 + 6 + 4 + 1 + 0) = 444$。

---

### 4. 为什么提到“状态压缩”？

在算法竞赛中（尤其是 BFS 搜索或动态规划），如果你需要记录一个 $8$ 数码（$3 \times 3$ 拼图）的状态：

- 如果用 `string` 或 `long long` 直接存，空间开销大且难以作为数组下标。
    
- 如果用康托展开，可以将 $9! = 362,880$ 种排列压缩到 `[0, 362879]` 的整数区间。
    
- 这样你可以直接开一个 `visited[362880]` 的布尔数组，实现 $O(1)$ 的状态查询。

### 5. 进阶：如何实现 $O(n \log n)$？

正如你提供的文本最后一段所述，在 $n$ 较大（如 $n=10^5$）时，找出“后面有多少个比我小”的 $O(n^2)$ 暴力算法会超时。

**解决方案：**

1. **树状数组（BIT）：** 从右往左遍历排列，每遇到一个数 $x$，在 BIT 的 $x$ 位置 $+1$，然后查询 $prefix\_sum(x-1)$。
    
2. **线段树：** 维护当前还有哪些数可用。
    

这种结合了**数制理论**与**高效数据结构**的思路，正是你目前在 CSAPP 中学习的“底层表示”与算法竞赛中“高效实现”的完美交汇。

**既然你提到了 Lehmer 码和状态压缩，我们要不要试着用你之前的 C++ 模板实现一个基于树状数组的 $O(n \log n)$ 康托展开函数？**


通过排名 $k$ 反推排列的过程，本质上就是**将一个十进制数转换成“阶乘进制”数**的过程，然后再根据得到的系数（Lehmer 码）依次挑选数字。

我们可以把这个过程分为三步：

---

### 1. 将排名转换为 0-indexed

通常题目给出的排名是从 1 开始的。为了方便计算，我们先令 $k' = k - 1$。

这样，$k'$ 的范围就在 $[0, n! - 1]$ 之间。

### 2. 计算 Lehmer 码（阶乘进制的系数）

我们要把 $k'$ 分解为：

$$k' = a_{n-1} \cdot (n-1)! + a_{n-2} \cdot (n-2)! + \dots + a_1 \cdot 1! + a_0 \cdot 0!$$

**计算方法：逐位除法取余**

1. 第一位的系数 $a_{n-1} = \lfloor k' / (n-1)! \rfloor$。
    
2. 更新 $k' = k' \pmod{(n-1)!}$。
    
3. 第二位的系数 $a_{n-2} = \lfloor k' / (n-2)! \rfloor$。
    
4. 以此类推，直到算完所有系数。
    

### 3. 根据系数找对应的数字

得到的系数 $a_i$ 代表的含义是：**“在当前剩余可用的数字中，选择第 $a_i$ 小的那个（从 0 开始计数）”**。

#### 举个例子：$n=3$, 求第 $k=3$ 个排列

1. **转换：** $k' = 3 - 1 = 2$。
    
2. **算系数：**
    
    - $n=3$，阶乘序列为 $2!, 1!, 0!$ 即 $2, 1, 1$。
        
    - 第一位：$a_2 = 2 / 2! = 1$；余数 $2 \pmod 2 = 0$。
        
    - 第二位：$a_1 = 0 / 1! = 0$；余数 $0 \pmod 1 = 0$。
        
    - 第三位：$a_0 = 0 / 0! = 0$。
        
    - **Lehmer 码为：$[1, 0, 0]$**。
        
3. **找数字：**
    
    - 可用集合 $\{1, 2, 3\}$。
        
    - 第 1 位系数是 **1**：选集合中第 1 小的数（0-indexed），即 **2**。集合剩余 $\{1, 3\}$。
        
    - 第 2 位系数是 **0**：选集合中第 0 小的数，即 **1**。集合剩余 $\{3\}$。
        
    - 第 3 位系数是 **0**：选集合中第 0 小的数，即 **3**。
        
    - **最终排列为：$[2, 1, 3]$**。
        

---

### 4. C++ 实现（针对 $n \le 20$）

对于 $n$ 较小的情况，我们可以直接用 `std::vector` 的 `erase` 来维护可用集合。

C++

```
vector<int> inverseCantor(int n, int k) {
    k--; // 转为 0-indexed
    vector<int> nums;
    for (int i = 1; i <= n; i++) nums.push_back(i); // 初始化可用数字
    
    vector<int> permutation;
    for (int i = n - 1; i >= 0; i--) {
        int index = k / fac[i]; // fac[i] 是预处理的 i!
        k %= fac[i];
        
        permutation.push_back(nums[index]); // 选出第 index 小的数
        nums.erase(nums.begin() + index);   // 从集合中移除
    }
    return permutation;
}
```

### 5. 高效实现：$O(n \log n)$

在竞赛中，如果 $n=10^5$，`vector::erase` 的 $O(n^2)$ 复杂度会超时。

我们需要在 $O(\log n)$ 时间内完成：**“找到剩余数字中第 $x$ 小的数，并删除它”**。

- **工具：** 树状数组（Binary Indexed Tree）+ 二分查找，或者 **线段树上二分**。
    
- **做法：** 1. 建立一个树状数组，初始每个位置 $1 \dots n$ 都是 1。
    
    2. 当需要找第 $index+1$ 小的数时，在树状数组上二分找到前缀和等于 $index+1$ 的最小位置。
    
    3. 找到后，将该位置的值改为 0（即删除该数）。
