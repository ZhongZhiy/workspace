# 非欧最短路
## 题意

> [!abstract] 题目关键信息
> - **核心考点**： #最短路 #dijstra
> 有 $n \times m$ 的网格空间, 每个网格都有一个虫洞 $a_{i,j}$ 具有相同虫洞的可以互相通往, 通往需要 $c$ 分钟, 相邻网格也可以互相通往, 每次需要 $1$ 分钟, 求从 $1, 1$ 到 $n, m$ 最少需要多少时间. $1\leq n,m\leq 10^3, 0\leq a{i, j} \leq 10^6$

##  题解
如果每个的建边的话会有大量的边, 导致超时, 可以建立虚拟节点, 也就是相同虫洞的可以通往一个虚拟节点, 这个到虚拟节点的边的权重就是 $c$ , 而从虚拟节点到这些可以到达的节点的权值为 $0$ , 这样就大大减少了建边的情况, 最后用dijstra就可以了

    priority_queue<Node> q;

                q.push({iid, dis+1});

           if(!vis[iid] && dist[iid] > dis + w) {
               dist[iid] = dis + w;
               q.push({iid, dis + w});
           }
        }
    }
}
